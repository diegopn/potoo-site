01 · The idea

A clearer start to programming logic

Potoo IDE already lets learners explore algorithms with Portugol family variants, the Calango pseudolanguage, and the Potigol programming language. The project aims to make that process clearer for students and teachers by bringing code and results together in a desktop interface.

ForStudents and teachers

A place to support learning and teaching the foundations of programming.

FocusLogic before syntax

Pseudocode can keep attention on the steps behind an algorithm.

FormatDesktop application

A native IDE planned for Linux, Windows and macOS.

02 · Current features and next steps

A working foundation that keeps growing

Although development is at an early stage, Potoo IDE already offers an editor and execution for Portugol Studio 2.0, VisuAlg, G-Portugol, and Mapler, as well as Calango and Potigol. The learning experience continues to evolve.
