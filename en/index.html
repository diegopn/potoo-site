01 · The idea

A clearer start to programming logic.

Potoo aims to give beginners a simple place to experiment with algorithms. The idea is to bring writing, explanations and results into a desktop interface, without turning learning into a collection of disconnected tools.

ForStudents and teachers

A place to support learning and teaching the foundations of programming.

FocusLogic before syntax

Pseudocode can keep attention on the steps behind an algorithm.

FormatDesktop application

A native IDE planned for Linux, Windows and macOS.

03 · How it could work

Four steps to explore an idea.

This flow describes the experience Potoo is aiming for, not features available today.

01

Choose a language

Start with the pseudocode used in your class or study.

02

Write the algorithm

Arrange your steps in the editor and focus on the logic.

03

Understand the next step

Use contextual help to clarify a line or concept.

04

Read the result

Use the planned output and panels to follow the run.

↗Workflow in planning. The current version does not yet include an editor, code execution or debugging.
