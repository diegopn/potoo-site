01 · Overview

What is Potoo IDE?

Potoo IDE is a desktop environment for students and teachers learning and teaching programming logic with Portugol family variants, the Calango pseudolanguage, and the Potigol programming language. The app brings together an editor, projects, and algorithm execution.

The project is still in development: these options are already available in the app while feature coverage and learning support continue to evolve.

How to read this manual: “Planned” marks a product goal. “Available” describes something available in Potoo IDE.

02 · Current status

What is available

Potoo IDE lets you create and edit projects and run algorithms in Portugol Studio 2.0, VisuAlg, G-Portugol, Mapler, Calango, and Potigol. Portugol Studio 2.0, VisuAlg, G-Portugol, and Mapler are Portugol family variants; Calango is a pseudolanguage, and Potigol is a programming language. Feature coverage continues to evolve.

In development: command coverage and learning support continue to evolve.

03 · Using the app

How to create and run an algorithm

The basic workflow is already available in the app:

  1. Create a project and choose an available language or variant.
  2. Write and arrange the algorithm in the editor.
  3. Run the program and provide any requested input.
  4. Review the output, diagnostics and available debugging features.

Diagnostic and debugging coverage varies by language or variant and continues to improve.

04 · Languages and pseudolanguages

Portugol, Calango, and Potigol are available

Portugol is a family of educational pseudolanguages for writing algorithms in Portuguese; each variant defines its own rules. Potoo IDE includes Portugol Studio 2.0, VisuAlg, G-Portugol, and Mapler. Calango is another available pseudolanguage, while Potigol is a programming language with Portuguese syntax.

Portugol family variants

  • Portugol Studio 2.0: structure, types, operators, control flow, vectors, functions, and libraries.
    Read the complete Portugol Studio 2.0 reference
  • VisuAlg: structure, types, operators, vectors, subprograms, functions, and teaching commands.
    Read the complete VisuAlg reference
  • G-Portugol: structure, types, matrices, operators, input and output, control flow, and functions.
    Read the complete G-Portugol reference
  • Mapler: structure, types, vectors, operators, input and output, decisions, loops, and modules.
    Read the Mapler reference

Calango pseudolanguage

  • Calango: a pseudolanguage for writing algorithms with declarations, expressions, decisions, loops, functions, and procedures. The reference covers structure, types, vectors, operators, input and output, decisions, loops, functions, and procedures.
    Read the Calango reference

Potigol programming language

  • Potigol: a programming language with Portuguese syntax, static typing, and inference. It combines imperative and functional features, collections, pattern matching, and the Jerimum game library; its reference details these features.
    Read the Potigol reference

Other options under evaluation

PSeInt, Linotte, C0 (Simplified C), Égua, Logic Basic, and Karel the Robot remain future options under evaluation. Their references describe the original projects and do not indicate current support in Potoo IDE.

  • PSeInt: structure, types, operators, arrays, and built-in functions.
    Read the PSeInt reference
  • Linotte: actors, collections, conditions, functions, and graphical events.
    Read the Linotte reference
  • Égua: an interpreted programming language with Portuguese syntax.
    Read the Égua reference
  • Logic Basic: a programming language for visual applications, with memory, graphical components, and data commands.
    Read the Logic Basic reference
  • Karel the Robot: commands, sensors, methods, and scenario solving.
    Read the Karel the Robot reference

05 · Interpreters

A dedicated interpreter for each available option

Each option that Potoo IDE runs has an interpreter maintained in its own repository. The list separates Portugol family dialects from the other available options.

Dialects of the Portugol family

  • Portugol Studio 2.0: runs programs, functions, and libraries, with file services and interactive features provided by the app.
    Learn about the interpreter
  • VisuAlg: runs algorithms for the classic 3.0.5.2 version, with input and output, helper commands, and debugging events.
    Learn about the interpreter
  • G-Portugol: covers types, vectors, matrices, and functions from the 1.4.0 reference, with diagnostics and debugging.
    Learn about the interpreter
  • Mapler: runs documented structures, vectors, modules, and input/output operations, with type checking and debugging.
    Learn about the interpreter

Calango pseudolanguage

  • Calango: runs algorithms with typed data, vectors, routines, and control structures, with diagnostics and debugging.
    Learn about the interpreter

Potigol programming language

  • Potigol: interprets the documented language core and connects Jerimum game-library features to app services.
    Learn about the interpreter

06 · App features

What you can do

  • Algorithm editor: create and edit program files within projects.
  • Execution: run algorithms, provide input, and review the output.
  • Diagnostics: messages associated with the source of code issues.
  • Debugging: follow execution with the controls available for each pseudolanguage or language.
Compatibility: rules and features vary across the variants and pseudolanguages. Consult the corresponding reference for documented syntax; feature coverage in Potoo IDE continues to evolve.

09 · FAQ

Common questions

Yes. You can create and edit projects and run algorithms in Portugol Studio 2.0, VisuAlg, G-Portugol, Mapler, Calango, and Potigol. Feature coverage continues to evolve.

Potoo IDE already runs four Portugol family variants (Portugol Studio 2.0, VisuAlg, G-Portugol, and Mapler), the Calango pseudolanguage, and the Potigol programming language. PSeInt, Linotte, C0 (Simplified C), Égua, Logic Basic, and Karel the Robot remain future options under evaluation.
