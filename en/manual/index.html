01 · Overview

What is Potoo IDE?

Potoo IDE is a desktop environment for students and teachers learning and teaching programming logic with Portugol family pseudolanguages and the Potigol programming language. The app already brings together an editor, projects and algorithm execution.

The project is at an early stage: it already supports the Portugol family and the Potigol programming language, while compatibility and teaching features continue to evolve.

How to read this manual: “Planned” marks a product goal. “Available” describes something that exists in the current application foundation.

02 · Current status

What exists today

Potoo IDE already lets you create and edit projects and run algorithms in Portugol Studio 2.0, VisuAlg, G-Portugol and Potigol. All four options are available in the app: three Portugol family pseudolanguages and the Potigol programming language.

Compatibility is still being developed; command and feature coverage can vary across the Portugol variants and the Potigol programming language.

In development: the project continues to expand compatibility and improve learning support.

03 · Using the app

How to create and run an algorithm

The basic workflow is already available in the app:

  1. Create a project and choose an available language or variant.
  2. Write and arrange the algorithm in the editor.
  3. Run the program and provide any requested input.
  4. Review the output, diagnostics and available debugging features.

Diagnostic and debugging coverage varies by language or variant and continues to improve.

04 · Languages and pseudolanguages

Portugol and Potigol are already available

Portugol is a family of educational pseudolanguages written in Portuguese, with no single syntax. Potoo IDE already runs the Portugol Studio 2.0, VisuAlg and G-Portugol variants, each with its own rules; programs in one variant are not automatically compatible with the others. The app also runs Potigol, an educational programming language independent of the Portugol family.

Portugol family references

  • Portugol Studio 2.0: structure, types, operators, control flow, arrays, functions and libraries.
    Read the complete Portugol Studio 2.0 reference.
  • VisuAlg: structure, types, operators, vectors, subprograms, functions and teaching commands.
    Read the complete VisuAlg reference.
  • G-Portugol: structure, types, matrices, operators, input and output, control flow, and functions.
    Read the complete G-Portugol reference.

Potigol

  • Potigol programming language: syntax, types, collections, math and functional operations, pattern matching, and the Jerimum game library. Potoo IDE supports a subset of its graphics and audio features.
    Read the Potigol reference.

Other documented references

  • PSeInt: algorithm structure, types, operators, arrays, subprograms, built-in functions and official configuration profiles.
    Read the PSeInt reference.
  • Linotte: actors, collections, conditions, functions, math operations, graphical events, and Atelier features.
    Read the Linotte reference.
  • Karel the Robot: commands, sensors, custom methods, planning, and scenario testing in Stanford's Java reference.
    Read the Karel the Robot reference.

PSeInt, Linotte, C0 (Simplified C) and Karel the Robot remain under evaluation. Their references describe those projects and do not indicate current support in Potoo IDE.

05 · App features

What you can do today

  • Program editor: create and edit program files within projects.
  • Execution: run algorithms, respond to interactive input and view output.
  • Diagnostics: messages tied to the source of code issues.
  • Debugging: follow program execution with the controls available for each language or variant.
Compatibility: support is in development and varies across the Portugol variants and the Potigol programming language.

08 · FAQ

Common questions

Can I write programs in Potoo IDE yet?

Yes. You can create and edit projects and run algorithms in Portugol Studio 2.0, VisuAlg, G-Portugol and Potigol. The app is still in development, and compatibility varies by language or variant.

Which languages and pseudolanguages does the app run?

Potoo IDE runs Portugol Studio 2.0, VisuAlg and G-Portugol, variants in the Portugol family, as well as the Potigol programming language. PSeInt, Linotte, C0 (Simplified C) and Karel the Robot remain under evaluation.

When will the app be ready?

The project is still in development and has no announced release date.
