01 · Overview

What is Potoo IDE?

Potoo IDE is a desktop environment project for students and teachers learning and teaching programming logic through pseudocode. The goal is to bring algorithm writing, contextual help and results together in a simple interface.

The project is at an early stage. This site describes its goals and plans; it does not present finished features or a release for everyday use.

How to read this manual: “Planned” marks a product goal. “Available” describes something that exists in the current application foundation.

02 · Current status

What exists today

Today, Potoo IDE opens a welcome window. The editor, pseudolanguage selection, algorithm execution, contextual help and debugging are not yet available in the app.

For now, the app cannot create a programming project, run pseudocode or show errors in the IDE.

In development: next steps include the main interface, IDE panels and the programming workflow for the Portugol 2.0 and VisuAlg pseudolanguages.

03 · Planned experience

How the workflow is intended to work

The steps below describe the intended experience, not an available product tutorial:

  1. Choose a pseudolanguage for the exercise.
  2. Write and arrange the algorithm in the editor.
  3. Ask for contextual help about a line or concept.
  4. Run the code and read its output and issues in companion panels.

The app still needs to define how it will present error messages and which debugging features will be available.

04 · Pseudolanguages

Which pseudolanguages are in scope?

Potoo IDE's initial scope includes the Portugol 2.0 and VisuAlg pseudolanguages. The references below document their rules and features based on official sources:

  • Portugol 2.0: structure, types, operators, control flow, arrays, functions and libraries.
    Read the complete Portugol 2.0 reference.
  • VisuAlg: structure, types, operators, vectors, subprograms, functions and teaching commands.
    Read the complete VisuAlg reference.
  • Potigol: syntax, types, collections, math and functional operations, pattern matching, and the Jerimum game library.
    Read the Potigol reference.
  • PSeInt: algorithm structure, types, operators, arrays, subprograms, built-in functions and official configuration profiles.
    Read the PSeInt reference.
  • Linotte: actors, collections, conditions, functions, math operations, graphical events, and Atelier features.
    Read the Linotte reference.
  • Karel the Robot: commands, sensors, custom methods, planning, and scenario testing in Stanford's Java reference.
    Read the Karel the Robot reference.

Potigol, PSeInt, Linotte, C0 (Simplified C), and Karel the Robot remain possibilities under evaluation, with no commitment to integrate them at this stage. These pages document each project's reference material; they do not indicate that these features are available in Potoo IDE.

05 · Editor and help

What the project aims to offer

  • Pseudocode editor: a place to write algorithms without unnecessary distractions.
  • Contextual help: an explanation tied to the selected line and the idea behind it.
  • Bottom panels: planned space for output, issues and debugging.
  • Several pseudolanguages: a choice between pseudolanguages once their integrations are defined.
Keep in mind: this list describes product goals. The editor, execution, contextual help and debugging are not available in the desktop app yet.

08 · FAQ

Common questions

Can I write programs in Potoo IDE yet?

Not yet. Potoo IDE currently opens a welcome window; the editor and algorithm execution are in development.

Which pseudolanguages are already integrated?

None is integrated into the desktop app. Portugol 2.0 and VisuAlg are in the initial scope; Potigol, PSeInt, Linotte, C0 (Simplified C), and Karel the Robot remain under evaluation.

When will the app be ready?

The project is still in development and has no announced release date.
