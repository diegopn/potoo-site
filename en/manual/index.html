01 · Overview

What is Potoo IDE?

Potoo IDE is a desktop environment project for students and teachers learning and teaching programming logic through pseudocode. The goal is to bring algorithm writing, contextual help and results together in a simple interface.

The project is at an early stage. This site describes its goals and plans; it does not present finished features or a release for everyday use.

How to read this manual: “Planned” marks a product goal. “Available” describes something that exists in the current application foundation.

02 · Current status

What exists today

The initial foundation opens a Potoo IDE window with a welcome message. Independent crates for the Portugol 2.0 and VisuAlg pseudolanguages are in development, but they are not connected to the desktop app yet. The editor, pseudolanguage selection, algorithm execution, contextual help and debugging have not been implemented.

For now, the app cannot create a programming project, run pseudocode or show errors in the IDE.

In development: planned next steps include the main interface, IDE panels and integration of the independent interpreters.

03 · Planned experience

How the workflow is intended to work

The steps below describe the intended experience, not an available product tutorial:

  1. Choose a pseudolanguage for the exercise.
  2. Write and arrange the algorithm in the editor.
  3. Ask for contextual help about a line or concept.
  4. Run the code and read its output and issues in companion panels.

The project still needs to define how it will communicate with each interpreter, how error messages will work and which debugging features are possible.

04 · Pseudolanguages

Which pseudolanguages are in scope?

The project aims to implement the complete Portugol 2.0 and VisuAlg dialects. The pages below document these reference pseudolanguages and separate dialect scope from current support in the crates and app:

  • Portugol 2.0: the independent crate already implements part of the dialect, but it is not connected to the app. Read the complete Portugol 2.0 pseudolanguage reference.
  • VisuAlg: the crate uses VisuAlg 3.0.5.2 as its compatibility baseline and is not integrated into the app either. Read the complete VisuAlg pseudolanguage reference.

Potigol, PSeInt, Linotte, C0 (Simplified C), and Karel the Robot remain possibilities under evaluation, with no commitment to integrate them at this stage.

05 · Editor and help

What the project aims to offer

  • Pseudocode editor: a place to write algorithms without unnecessary distractions.
  • Contextual help: an explanation tied to the selected line and the idea behind it.
  • Bottom panels: planned space for output, issues and debugging.
  • Several pseudolanguages: a choice between pseudolanguages once their integrations are defined.
Keep in mind: this list describes product goals. The editor, execution, contextual help and debugging are not available in the desktop app yet.

06 · Development

How to follow the project

Potoo IDE is in development. Its foundation is currently a welcome window; the editor and planned panels still need to be built, and the independent crates for the Portugol 2.0 and VisuAlg pseudolanguages still need to be integrated into the app.

No release date has been announced. This page describes the current known state and can be updated as the application progresses.

08 · FAQ

Common questions

Can I write programs in Potoo IDE yet?

Not yet. Potoo IDE currently opens a welcome window; the editor and algorithm execution are in development.

Which pseudolanguages are already integrated?

None is integrated into the desktop app. Partially implemented independent crates exist for Portugol 2.0 and VisuAlg; Potigol, PSeInt, Linotte, C0 (Simplified C), and Karel the Robot remain under evaluation.

When will the app be ready?

The project is still in development and has no announced release date.
