01 · Overview

What is Potoo IDE?

Potoo IDE is a desktop environment project for students and teachers learning and teaching programming logic through pseudocode. The goal is to bring algorithm writing, contextual help and results together in a simple interface.

The project is at an early stage. This site describes its goals and plans; it does not present finished features or a release for everyday use.

How to read this manual: “Planned” marks a product goal. “Available” describes something that exists in the current application foundation.

02 · Current status

What exists today

The initial foundation opens a Potoo IDE window with a welcome message. The editor, language selection, algorithm execution, contextual help and debugging have not been implemented yet.

For now, the app cannot create a programming project, run pseudocode or show errors in the IDE.

In development: planned next steps include the main interface, IDE panels and decisions about connecting independent interpreters.

03 · Planned experience

How the workflow is intended to work

The steps below describe the intended experience, not an available product tutorial:

  1. Choose a pseudocode language for the exercise.
  2. Write and arrange the algorithm in the editor.
  3. Ask for contextual help about a line or concept.
  4. Run the code and read its output and issues in companion panels.

The project still needs to define how it will communicate with each interpreter, how error messages will work and which debugging features are possible.

04 · Pseudocode languages

Which languages are in scope?

  • Portugol: part of the initial project scope; no interpreter is integrated yet.
  • VisuAlg: also in the initial scope; its technical integration is still to be defined.
  • PSeInt and Linotte: possibilities under evaluation, with no commitment to add them at this stage.

The interpreters are independent projects. Compatibility, technical limits and licenses need to be reviewed before choosing an integration.

05 · Editor and help

What the project aims to offer

  • Pseudocode editor: a place to write algorithms without unnecessary distractions.
  • Contextual help: an explanation tied to the selected line and the idea behind it.
  • Bottom panels: planned space for output, issues and debugging.
  • Several languages: a choice of pseudocode languages once their integrations are defined.
Keep in mind: this list describes product goals. None of these features is available in the initial application.

06 · Development

How to follow the project

Potoo IDE is in development. Its foundation is currently a welcome window; the editor, pseudocode integrations and planned panels still need to be built.

No release date has been announced. This page describes the current known state and can be updated as the application progresses.

08 · FAQ

Common questions

Can I write programs in Potoo IDE yet?

Not yet. The initial version opens a welcome window; the editor and algorithm execution are in development.

Which pseudocode languages already work?

None is integrated at this stage. Portugol and VisuAlg are in the initial scope; PSeInt and Linotte are under evaluation.

When will the app be ready?

The project is still in development and has no announced release date.
