01 · Overview

About Mapler

Mapler is an educational Portugol variant: its commands describe algorithms in structured Portuguese and organize them into readable blocks. The primary reference is the Mapler project manual, supplemented by its official examples for structure, types, operations, decisions, loops, and modules.

This page describes Mapler specifically. Its rules do not define a single syntax for the other variants in the Portugol family.

02 · Organization

Program structure

A Mapler algorithm has three areas: declarations in variaveis, commands between inicio and fim, and the program ending. Declare variables and modules before inicio; define modules after the main block.

variaveis
    name: cadeia;
    age: inteiro;
inicio
    // Ask before reading input
    escrever "What is your name?";
    ler name;
    escrever "Hello, ", name;
fim.

Simple commands end with semicolons. Line comments start with //. The period after fim appears in the official structure examples.

03 · Data

Variables, types, and vectors

Declare each variable in the variaveis area as name: type;. inteiro represents whole numbers; real, decimal numbers written with a period; logico, verdadeiro or falso; caractere, one character; and cadeia, text in double quotes.

variaveis
    attempts: inteiro;
    average: real;
    passed: logico;
    initial: caractere;
    message: cadeia;
    grades: vetor [1..5] de real;
inicio
    attempts <- 0;
    passed <- falso;
    initial <- "M";
    message <- "Welcome";
    grades[1] <- 8.5;
fim

Vector bounds are inclusive and part of the declaration: in [1..5], valid indices range from 1 to 5. Use a bracketed index to read or change an element. Vectors hold values of one type.

Do not treat inteiro and real as interchangeable types. The Mapler reference says assigning a real directly to an integer is an error. Integer-to-real conversion only occurs in an expression that already contains a real operand: 2.5 + 2 produces a real, while 2 + 2 remains an integer.

04 · Calculations

Assignment, operators, and precedence

Assign an expression result with <-. The documented arithmetic operations are addition, subtraction, multiplication, and division. Comparisons produce logical values and can be combined with e, ou, and nao.

GroupFormsUse
Arithmetic+ - * /Add, subtract, multiply, and divide numbers.
Relational= <> < <= > >=Compare values in conditions.
Logicale ou naoCombine or negate logical conditions.

For arithmetic, parentheses are evaluated first, followed by multiplication and division, then addition and subtraction. Operators at the same level are evaluated from left to right. Use parentheses to make another order explicit.

total <- price * quantity;
average <- (grade1 + grade2) / 2;
se total >= limit e passed entao
    escrever "You can continue";
fim se;

05 · Interaction

Input and output

escrever displays text and values. Separate items with commas; they appear in the same order, so include spaces in text literals when you want visual separation. ler reads the next value entered and assigns it to the named variable.

variaveis
    name: cadeia;
    age: inteiro;
inicio
    escrever "Name: ";
    ler name;
    escrever "Age: ";
    ler age;
    escrever name, " is ", age, " years old.";
fim

Declare the variable with a type compatible with the input. A prompt before ler tells the user what the algorithm expects.

06 · Decisions

Conditions with se and senao

se evaluates a logical condition and entao starts the block that runs when it is true. The optional senao defines the alternative. The block ends with fim se;. A condition can combine comparisons and logical operators.

se grade >= 7 entao
    escrever "Passed";
senao
    escrever "Keep practicing";
fim se;

Conditions can be nested. Close each inner block before the outer one, and use parentheses to make compound expressions easy to follow.

07 · Repetition

para, enquanto, and repita loops

para traverses a range with a control variable, start, end, and step. In the documented form, the variable advances when the start is less than the end; equal values run the body once, and a start greater than the end skips it. enquanto checks before each pass, so its body may run zero times.

repita runs its body before checking the condition. The body runs at least once and repeats while the condition after ate is true; the loop ends when it becomes false.

variaveis
    i: inteiro;
inicio
    para i de 1 ate 5 passo 1 faca
        escrever i;
    fim para;

    i <- 1;
    enquanto i <= 5 faca
        escrever i;
        i <- i + 1;
    fim enquanto;

    i <- 1;
    repita
        escrever i;
        i <- i + 1;
    ate i <= 5;
fim

Loops can be nested. In enquanto, update the variables used by the condition so the algorithm reaches its intended end.

08 · Reuse

Modules

A module names commands that can be called from different points in an algorithm. Declare it in variaveis with type modulo, call it by name inside the main block, and define it after the main block ends.

variaveis
    sayHello: modulo;
    name: cadeia;
inicio
    escrever "Name: ";
    ler name;
    sayHello;
fim

modulo sayHello;
    escrever "Hello, ", name;
fim modulo;

According to the official material, modules can access variables from the main block and take no parameters. Use them to group reusable actions; they do not return a value like a function.

09 · In practice

Complete example

This example combines declarations, input, a calculation, and a decision. It uses structures described in the Mapler reference.

variaveis
    valor_a: real;
    valor_b: real;
    media: real;
inicio
    escrever "First value:";
    ler valor_a;
    escrever "Second value:";
    ler valor_b;
    media <- (valor_a + valor_b) / 2;
    escrever "Average: ", media;
    se media >= 7 entao
        escrever "Sufficient result";
    senao
        escrever "Review the material";
    fim se;
fim.

10 · Files

File extension in Potoo IDE

The Mapler manual describes source text files with a .txt extension. Potoo IDE uses .mapler for Mapler files, a choice inspired by the DesignLiquido/mapler project. That repository is cited only as background for the adopted extension; syntax and features on this page come from Mapler's official manual and examples.
