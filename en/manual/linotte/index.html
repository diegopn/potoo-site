01 · Overview

About Linotte

Linotte is an educational project whose syntax uses French words and phrases. The official project presents an environment for learning programming fundamentals and includes examples of variables, interaction, conditions, loops, calculations, and functions.

Code on this page remains in French so it can be compared with the original files. Translating keywords such as affiche, prend, or ferme would change the syntax.

02 · Organization

Program and comments

A Linotte program is a set of instructions in a project file. Introductory examples do not require an outer block around the whole program. An instruction can occupy one line; multi-line blocks end with ferme.

Line comments start with //. Multiline comments use /* and */.

affiche "Bonjour !"
// This comment ends at the line break.
/*
This whole block is ignored
while interpreting the program.
*/

03 · Data

Variables and values

Linotte describes variables as actors: each actor has a name, a role (its type), and a value. The introductory guide presents five basic roles: texte, nombre, drapeau, casier, and espèce. Declare a role with est un; if omitted, the first value assigned with prend can determine the type.

prénom est un texte
prénom prend "Clément"
affiche prénom
prénom prend "Jade"

compteur est un nombre
compteur prend 10
compteur prend compteur + 1

actif est un drapeau
actif prend vrai

mois est un casier de textes valant "janvier", "février", "mars"

drapeau stores a logical value, vrai or faux. Actor names may include accents, as in prénom; type words and text values remain in French.

04 · Interaction

Input and output

affiche displays an expression. demande asks for a value and stores it in the named actor; declare its type before reading it.

prénom est un texte
affiche "Quel est ton prénom ?"
demande prénom
affiche "Bonjour " + prénom

questionne prénom sur "Quel est ton prénom ?" combines the question and value input in one instruction. Text and expressions can be joined with +.

06 · Decisions

Conditions

si starts a condition and sinon introduces the alternative. A simple instruction can follow on the same line; multi-line blocks end with ferme.

note est un nombre
age est un nombre
note prend 12
age prend 20
si note >= 10 affiche "Très bien !"
sinon affiche "Continue à pratiquer"

si age >= 18
    affiche "Adulte"
    affiche "Accès autorisé"
ferme
sinon
    affiche "Mineur"
ferme

Conditions compare values or test a logical value. Examples show =, !=, >, <, >=, and <=.

07 · Repetition

Loops

pour walks through a numeric sequence with both the starting and ending bounds included. Multi-line blocks end with ferme. Current repository examples for version 3.14 use pour chaque item de casier to bind each collection item to a named actor. The general Linotte 3 tutorial also documents the compact form pour chaque casier, which makes the item available as joker.

compteur est un nombre
pour compteur de 1 à 5 affiche compteur

pour compteur de 1 à 3
    affiche compteur
    attends 200 millisecondes
ferme

mois est un casier de textes valant "janvier", "février", "mars"
mois_courant est un texte
pour chaque mois_courant de mois
    affiche mois_courant
ferme

Choose bounds that match the desired number of steps. The examples on this page use a named actor to iterate through a collection in Linotte 3.14; use joker to recognize the tutorial's compact form or numeric loops that use it.

08 · Reuse

Functions and return values

A function begins with its name, a colon, and its parameters. Its body can declare local variables, run conditions, and return a result with retourne. Functions can also call themselves recursively.

double : nombre
    retourne nombre * 2
fibonacci : n
    si n < 2 retourne n
    sinon retourne fibonacci(n - 1) + fibonacci(n - 2)

Call a function by placing arguments in parentheses after its name. Official examples use functions to separate calculations and build messages.

09 · Data organization

Collections and extensions

casier groups values that can be visited with pour chaque item de casier. The Linotte environment also contains visual examples and additional libraries; these resources depend on that environment and are not necessarily available in every context.

nombres est un casier de nombres valant 2, 4, 6
valeur est un nombre
pour chaque valeur de nombres
    affiche valeur * valeur
ferme

For a specific resource, check its example and the documentation for that component in the original project.

10 · Combined example

Scores, a function, and an average

prénoms est un casier de textes valant "Lia", "Caio", "Noa"
notes est un casier de nombres
indice est un nombre
seuil est un nombre
note est un nombre
total est un nombre
quantite est un nombre
moyenne est un nombre

total prend 0
quantite prend 0
affiche "Quelle note minimale permet d'atteindre l'objectif ?"
demande seuil

pour indice de 0 à 2
    ajoute question(prénoms{indice}) dans notes
ferme

pour chaque note de notes
    total prend total + note
    quantite prend quantite + 1
    si note >= seuil
        affiche note + " : objectif atteint"
    sinon
        affiche note + " : en dessous de l'objectif"
    ferme
ferme

moyenne prend total / quantite
affiche "Moyenne : " + moyenne
si moyenne >= seuil
    affiche "Objectif moyen atteint"
sinon
    affiche "Objectif moyen non atteint"
ferme

question : prénom
    valeur est un nombre
    affiche "Quelle est la note de " + prénom + " ?"
    demande valeur
    retourne valeur

The program collects three scores, stores them in a casier, compares each score with the entered threshold, and calculates the average. The question function handles input; the explicit loop binds each item to a named actor.

11 · Collections

Collection access and iteration

A casier groups values so a program can visit them without repeating instructions. Official examples start indexes at zero: three items use positions 0, 1, and 2. Braces read an item; ajoute adds a value to another collection.

nombres est un casier de textes valant "Lia", "Caio", "Noa"
indice est un nombre
nom_courant est un texte
pour indice de 0 à 2
    affiche nombres{indice}
ferme

pour chaque nom_courant de nombres
    affiche nom_courant
ferme

In version 3.14 examples, pour chaque nom_courant de nombres binds the current item to the named actor. The general tutorial also shows the compact form with joker; identify which form a Linotte 3 source uses.

12 · Compact syntax

Shortcuts and interpolation

The official tutorial documents compact forms for displaying, requesting, and assigning values. Interpolation inserts an actor's value inside a string between braces.

prénom est un texte
prénom ?                    // request a value
"Bonjour, {prénom} !" !     // display interpolated text
prénom = "Jules"            // shorthand for prend
"Bonjour, " & prénom !

& can group actions or values, and § can replace ferme in some shorthand forms. Start with full instructions when learning the structure.

14 · Modeling

Species and prototypes

An espèce defines a custom actor type with attributes. Its declaration specifies each attribute's role; creating an actor assigns values. Examples read them as attribute de actor or attribute@actor.

espèces
    nom & famille est un texte
    pattes est un nombre
    espèce animal contient nom, famille, pattes

principal :
    chat est un animal, nom prend "Mimi", famille prend "félin", pattes prend 4
    affiche nom de chat
    affiche famille@chat

A species can inherit from another and add attributes. The Atelier can also attach functions to prototypes; these features extend the basic data model.

espèces
    couleur est un texte
    espèce fleur hérite de point et contient couleur

15 · Atelier features

Events, graphics, and tasks

Graphics and interaction depend on the Atelier and its version. The official 17_cassebrique.liv example, associated with version 3.14, combines graphical actors, a collection of objects, collisions, and loops. This shortened excerpt shows the explicit iteration used in those examples:

balle est un cercle, x vaut 200, y vaut 60, rayon vaut 10, plein vaut vrai, couleur vaut "rouge"
cibles est un casier de rectangle
position est un nombre
pour position de 0 à 2
    cible est un rectangle, x vaut 30 + 65 * position, y vaut 10, largeur vaut 50, hauteur vaut 20, plein vaut vrai
    ajoute cible dans cibles
ferme
cible est un rectangle, visible vaut faux
pour chaque cible de cibles
    si balle.collision(cible)
        efface cible
    ferme
ferme

The general Linotte 3 tutorial also demonstrates mouse events and tasks started with appelle and awaited with observe. Check their syntax and availability in the installed Atelier.

16 · Diagnostics

Errors and debugging

The tutorial uses essaie with a sinon alternative for runtime errors and débogue to start step-by-step tracing in the Atelier.

  • Read the error and identify the active instruction.
  • Step through execution and inspect actors used in each calculation.
  • Check that loops change state and can reach their stopping condition.
  • Test empty collections, a single item, and index boundaries.

The form and availability of these tools depend on Linotte Atelier; this reference describes the original environment.

Language model reference

The paragraph named principal is the name used in these examples for the main sequence. Execution starts at the book’s first executable paragraph; principal is not a reserved word.

Program model and concept reference

Linotte uses the metaphors of book, paragraph, role, and actor to make program structure visible. They are also operational concepts: a book contains paragraphs; a paragraph organizes roles and actions; an actor stores a value; and some actions iterate over collections or return a result.

TermLanguage roleForm shown in examples

Role / actorThe role declares the kind of value; the actor is the variable that receives it.compteur est un nombre
ActionExecutable command for displaying, reading, assigning, testing, or iterating over data.affiche, demande, prend, si, pour.
jokerImplicit actor used in compact loop forms and numeric examples.pour chaque casier in the general tutorial; 3.14 loops can also name the item actor.
reviensEnds the current paragraph or task without returning a value.Finish an event handler or a called task.
retourneReturns the result computed by a function.Use where the function hands back its value.

A casier is useful when several values of the same role should be handled as a group. Linotte 3.14 examples use pour chaque item de casier to bind the current item to a named actor. The general tutorial also documents the compact form with joker; numeric loops may use joker as their current value.

Versions and reference materials

The official releases page identifies Atelier Linotte 3.14; this is the version used as the baseline here. The official 05_boucle_2.liv example marks pour chaque valeur de liste as available from version 3.14. The general Linotte 3 tutorial also shows the compact form with joker, so this reference distinguishes the two uses. The archived Linotte 2.0.4 manual is historical and does not guarantee identical syntax.

The official 17_cassebrique.liv program combines graphical objects, collections, collisions, movement, and mouse interaction. Events, prototypes, and extensions may depend on the installed Atelier; check each feature against the version in use.
