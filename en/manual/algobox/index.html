01 · overview

What is AlgoBox

AlgoBox combines an algorithm editor with an execution environment for teaching. Learners can assemble instructions in a structured interface or work in text mode. The program helps them practise variables, input and output, conditions, and loops without requiring the syntax of a general-purpose language from the first exercise.

Step-by-step mode helps students track changing values and branch choices. The environment also documents exercises with lists and simple simulations. The official interface and examples are in French.

Status in Potoo IDE: AlgoBox is under evaluation. This page describes the independent project and does not indicate an available integration.

02 · purpose

Audience and approach

The project was created for teaching algorithms, especially in French-speaking school settings. The focus is on arranging reasoning as observable operations: define data, request an input, transform a value, and present a result.

Before starting an algorithm, think through the problem before choosing blocks:

  1. specify the known data and the data that must be entered;
  2. identify the result to display;
  3. write the steps and conditions in order;
  4. run a small case and follow each value.

This process makes the structured editor a representation of the algorithm, rather than just a way to enter text.

03 · program structure

Structure and vocabulary

The text editor uses French keywords. A typical algorithm has a variable section and explicit start and end markers. This fragment illustrates documented forms for declaring a number, reading input, assigning a value, and displaying the result:

VARIABLES
  n EST_DU_TYPE NOMBRE
  carre EST_DU_TYPE NOMBRE
DEBUT_ALGORITHME
  AFFICHER "Entrez un nombre"
  LIRE n
  carre PREND_LA_VALEUR n * n
  AFFICHER carre
FIN_ALGORITHME

The structured editor helps insert each element in the expected place. When editing text directly, check accents, reserved words, and punctuation against the manual for your version.

04 · data and expressions

Variables, types, and operators

AlgoBox documentation presents data families for numbers, strings, and lists. A variable needs a type that is compatible with the values it will hold. Assignment uses PREND_LA_VALEUR; input and display have their own instructions.

Arithmetic operations and comparisons form expressions; use parentheses to make the intended order clear. Check the official list for conversion details and list-specific features.

05 · control flow

Conditions, loops, and execution

Algorithms can choose a path based on a condition and repeat a sequence. The environment also provides step-by-step execution, showing how conditions and variables affect the path.

  • Condition: handles different cases separately.
  • Counted loop: repeats a block over a known range or quantity.
  • Conditional loop: repeats while a condition set by the exercise remains true.
  • List: can be used in exercises that collect and traverse values.

When building a loop, make the initialization, continuation rule, and state update clear. In step-by-step mode, verify that each iteration moves the program toward its stopping condition.

The manual documents blocks such as SI, POUR, and TANT_QUE, as well as local functions. It also describes commands for drawing points and line segments on a graph and a PAUSE instruction that can help investigate execution. These features depend on the environment options and should be learned from the manual for the relevant version.

Form or blockDocumented useLimits and notes
== != < <= > >=Tests equality, inequality, and ordering.Choose the comparison that matches the condition.
ET, OUCombines conditions in a logical expression.The manual shows interval and alternative checks.

TANT QUERepeats while the condition remains true.A single loop is limited to 500,000 iterations.
POUR ... DE ... A ...Traverses a numeric range.The variable is numeric, increases by 1, and the starting value must not exceed the ending value.

The manual also limits total algorithm iterations to five million. These limits protect execution, but they do not replace a correct stopping condition.

06 · worked example

Calculate the square of a number

The introductory example asks for a number and displays its square. In structured mode, first select the variables, then add display, input, assignment, and result display actions.

VARIABLES
  n EST_DU_TYPE NOMBRE
  carre EST_DU_TYPE NOMBRE
DEBUT_ALGORITHME
  AFFICHER "Entrez un nombre"
  LIRE n
  carre PREND_LA_VALEUR n * n
  AFFICHER "Carré : "
  AFFICHER carre
FIN_ALGORITHME

Run the example with n = 0, n = 1, and a negative value to check that multiplication gives the expected square. Then add a condition to distinguish even from odd numbers and trace its instructions one at a time.

07 · guided walkthrough

Build and test one program in both modes

This exercise calculates the arithmetic mean of three marks and reports whether it is at least 7. Assume the input marks are valid; checking that each mark is between 0 and 10 can be an extension.

Build the algorithm in normal mode

  1. Create a new algorithm and declare grade1, grade2, grade3, and mean as NOMBRE.
  2. Place the current line at DEBUT_ALGORITHME. Insert a new line and add AFFICHER Message to introduce the input; add one line for each LIRE instruction.
  3. After the input instructions, insert a line and choose AFFECTER valeur à variable. Select mean and enter (grade1+grade2+grade3)/3.
  4. Display the mean before the decision: add an AFFICHER Message instruction with “Calculated mean:” and another AFFICHER variable instruction to show mean. Enable line breaks when you want each result on a separate line.
  5. Insert an SI...ALORS block with the condition mean>=7 and enable SINON. Add the passing message inside the first block and the recovery message inside the alternative block.
  6. Choose Tester, then Lancer l'algorithme. In step-by-step mode, advance through the input, inspect mean after the assignment, and check which branch runs.

When configuring display instructions, select Ajouter un retour à la ligne to place each result on its own line. To insert an instruction, select the correct position in the tree and choose Nouvelle ligne; normal mode does not allow commands after FIN_ALGORITHME.

Write the same algorithm in the text editor

Start with a blank algorithm and choose Edition → Mode Edition. Write one instruction per line and declare each variable on its own line. In the text editor, AFFICHER* adds a line break; AFFICHER without the asterisk continues output on the same line.

VARIABLES
  grade1 EST_DU_TYPE NOMBRE
  grade2 EST_DU_TYPE NOMBRE
  grade3 EST_DU_TYPE NOMBRE
  mean EST_DU_TYPE NOMBRE
DEBUT_ALGORITHME
  AFFICHER* "Enter three marks."
  LIRE grade1
  LIRE grade2
  LIRE grade3
  mean PREND_LA_VALEUR (grade1+grade2+grade3)/3
  AFFICHER* "Calculated mean:"
  AFFICHER* mean
  SI (mean>=7) ALORS
    DEBUT_SI
      AFFICHER* "Result: pass."
    FIN_SI
  SINON
    DEBUT_SINON
      AFFICHER* "Result: recovery."
    FIN_SINON
FIN_ALGORITHME

Before running the text, choose Vérifier Code. AlgoBox checks whether it recognizes the syntax and rebuilds the instruction tree; correct any reported error before testing.

Check both outcomes

Input marksMeanmean>=7 conditionBranch output
8, 6, 108TruePass
6, 6, 66FalseRecovery

These cases exercise both branches. To trace execution, record the three inputs, check the value of mean, and confirm that the condition is evaluated after the assignment.

08 · study and debugging

How to practise

Choose a simple exercise and describe what should happen in plain language before opening the editor. Step-by-step mode lets you compare that description with the actual instruction order.

  • Run cases that cover every branch of a condition.
  • Watch a variable before and after each assignment.
  • Test the input boundary that ends a loop.
  • For lists, try an empty list, one item, and several items if the operation allows it.
  • Consult the French documentation if a keyword or feature is not recognized.

Structured blocks and text represent the same algorithm only when all instructions and boundaries are correct. Check the result, not merely the absence of syntax errors.

09 · versions and scope

Versions and limits

AlgoBox is an environment with its own grammar and tools. Structured block editing, text mode, list features, and step-by-step display belong to AlgoBox; they are not universal properties of pseudocode.

Reference version: AlgoBox 1.2.0, listed on the official download page consulted on November 18, 2026. The online official manual does not identify its own version; this page therefore summarizes that live reference, and its rules should be checked against the help available in the installation being used.

The official change log describes the move from version 1.1.1 to 1.2.0 as a technical update, with a move to Qt 6, platform support changes, and bug fixes. The instructions and examples here describe AlgoBox; they do not indicate that Potoo IDE runs it. AlgoBox remains under evaluation for Potoo IDE.

10 · workflow

Editing modes and building an algorithm

The manual recommends normal mode for beginners. It displays an algorithm as a tree of logical blocks; the text editor lets users type instructions directly. Both modes help practise the same logic, but text must still follow AlgoBox grammar.

Mode or actionHow it works
Normal modeInsert a line at the intended position, then choose the instruction or block for that line.
Text editorType commands directly and check keywords, conditions, and assignments against the manual.
Edit a blockChange an instruction's parameters when the edit button is available.
Delete a blockRemoving a condition or loop also removes the instructions nested inside it.

In normal mode, declare a variable before using it. To insert an instruction, move the cursor to the desired position and choose New line (shortcut Ctrl+Enter); then select a command. A line cannot be inserted after FIN_ALGORITHME. When deleting a SI, POUR, or TANT_QUE block, review its whole body because the nested instructions are removed with it.

To switch to the text editor, save your current work and start a blank algorithm; mode changes are made from an empty algorithm. Choose Edition → Mode Edition. In the text editor, keep one instruction per line, declare each variable on a separate line, and use AFFICHER* to end output with a line break. The Vérifier Code button checks the syntax and rebuilds the algorithm tree, which helps locate an invalid line.

Before saving, give the algorithm a clear name and briefly describe its purpose in the presentation field. The file menu can also print or export the code. Exporting an algorithm to a web page may limit features such as step-by-step execution, progressive input display, and manual stopping.

11 · execution tools

Lists, functions, and execution tracing

Lists store and traverse a sequence of values. To read or display an item, the manual requires both the list name and its rank; the rank can be a number or a NOMBRE variable. The documented library includes statistical calculations over a range of ranks, such as mean, variance, standard deviation, median, quartiles, minimum, maximum, and the positions of the extremes.

Some calculations have preconditions: the documented quartile functions require at least four elements. If a range is empty or the list does not meet the requirement, the environment reports an error. Check the first and last ranks before calling a function, and compare the result against a small set that can be calculated by hand.

The numeric feature F1(x) lets you define a function's expression in terms of x in the interface and call it inside an assignment or condition. The local-functions panel also supports reusable operations, local variables, and a returned value. The manual describes graphing options for drawing points and segments in a coordinate plane, plus the PAUSE command to suspend execution.

In step-by-step mode, the current line is highlighted and variable values can be inspected after reads, assignments, and loop blocks. Use this to find the first point where a value differs from what you expected. The environment limits each loop to 500,000 iterations as a safety measure; this prevents unbounded runs but does not replace a correct stopping condition.

Real-number calculations can also show representation and rounding effects. When comparing decimal results, choose a tolerance suitable for the exercise instead of assuming that every mathematical equality will be represented exactly by the computer.

12 · list practice

Calculate and check list statistics

A LISTE stores numbers in numbered positions. In this AlgoBox feature, the first position is 1; provide both the first and last rank in the range for each calculation. Lists use indices starting at 1, while text operations such as substr use a starting position of 0. Do not reuse an index from one structure in the other without adjusting its base.

The program below calculates the sum, mean, maximum, and position of the maximum for four marks:

VARIABLES
  marks EST_DU_TYPE LISTE
  total EST_DU_TYPE NOMBRE
  mean EST_DU_TYPE NOMBRE
  highest EST_DU_TYPE NOMBRE
DEBUT_ALGORITHME
  marks[1] PREND_LA_VALEUR 7:8:10:15
  total PREND_LA_VALEUR ALGOBOX_SOMME(marks,1,4)
  mean PREND_LA_VALEUR ALGOBOX_MOYENNE(marks,1,4)
  highest PREND_LA_VALEUR ALGOBOX_MAXIMUM(marks,1,4)
  AFFICHER "Sum: "
  AFFICHER total
  AFFICHER "Mean: "
  AFFICHER mean
  AFFICHER "Maximum: "
  AFFICHER highest
  AFFICHER ALGOBOX_POS_MAXIMUM(marks,1,4)
FIN_ALGORITHME

For this range, the sum is 40, the mean is 10, the maximum is 15, and its position is 4. The trace table checks the sum independently of the statistics function:

The list library documents sum, mean, variance, standard deviation, median, minimum, maximum, and the ranks of the extremes. Quartiles have two variants: ALGOBOX_QUARTILE1/ALGOBOX_QUARTILE3 and their _BIS variants, which use different statistical definitions. Each requires a range of at least four values; check the question to see which definition applies. Reversing the ranks, selecting a rank outside the list, or violating this precondition produces an error.

When a result looks wrong, compare the call with the ranks used, display the list, and calculate a short set by hand. In step-by-step mode, advance one instruction at a time and watch the variable values; AlgoBox also marks the last executed line when an error occurs. PAUSE temporarily suspends execution, and displaying a variable helps locate the first incorrect pass.
