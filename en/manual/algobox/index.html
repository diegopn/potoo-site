AlgoBox

AlgoBox is a French environment for learning to build and run algorithms. Its interface guides writing through structured blocks and also offers text editing. This manual describes its language and teaching workflow according to the official site; AlgoBox is under evaluation and is not run by Potoo IDE.

01 · overview

What is AlgoBox

AlgoBox combines an algorithm editor with an execution environment for teaching. Learners can assemble instructions in a structured interface or work in text mode. The program helps them practise variables, input and output, conditions, and loops without requiring the syntax of a general-purpose language from the first exercise.

Step-by-step mode helps students track changing values and branch choices. The environment also documents exercises with lists and simple simulations. The official interface and examples are in French.

Status in Potoo IDE: AlgoBox is under evaluation. This page describes the independent project and does not indicate an available integration.

02 · purpose

Audience and approach

The project was created for teaching algorithms, especially in French-speaking school settings. The focus is on arranging reasoning as observable operations: define data, request an input, transform a value, and present a result.

Before starting an algorithm, think through the problem before choosing blocks:

  1. specify the known data and the data that must be entered;
  2. identify the result to display;
  3. write the steps and conditions in order;
  4. run a small case and follow each value.

This process makes the structured editor a representation of the algorithm, rather than just a way to enter text.

03 · program structure

Structure and vocabulary

The text editor uses French keywords. A typical algorithm has a variable section and explicit start and end markers. This fragment illustrates documented forms for declaring a number, reading input, assigning a value, and displaying the result:

VARIABLES
  n EST_DU_TYPE NOMBRE
  carre EST_DU_TYPE NOMBRE
DEBUT_ALGORITHME
  AFFICHER "Entrez un nombre"
  LIRE n
  carre PREND_LA_VALEUR n * n
  AFFICHER carre
FIN_ALGORITHME

The structured editor helps insert each element in the expected place. When editing text directly, check accents, reserved words, and punctuation against the manual for your version.

04 · data and expressions

Variables, types, and operators

AlgoBox documentation presents data families for numbers, strings, and lists. A variable needs a type that is compatible with the values it will hold. Assignment uses PREND_LA_VALEUR; input and display have their own instructions.

Arithmetic operations and comparisons form expressions; use parentheses to make the intended order clear. Check the official list for conversion details and list-specific features.

05 · control flow

Conditions, loops, and execution

Algorithms can choose a path based on a condition and repeat a sequence. The environment also provides step-by-step execution, showing how conditions and variables affect the path.

  • Condition: handles different cases separately.
  • Counted loop: repeats a block over a known range or quantity.
  • Conditional loop: repeats while a condition set by the exercise remains true.
  • List: can be used in exercises that collect and traverse values.

When building a loop, make the initialization, continuation rule, and state update clear. In step-by-step mode, verify that each iteration moves the program toward its stopping condition.

The manual documents blocks such as SI, POUR, and TANT_QUE, as well as local functions. It also describes commands for drawing points and line segments on a graph and a PAUSE instruction that can help investigate execution. These features depend on the environment options and should be learned from the manual for the relevant version.

06 · worked example

Calculate the square of a number

The introductory example asks for a number and displays its square. In structured mode, first select the variables, then add display, input, assignment, and result display actions.

VARIABLES
  n EST_DU_TYPE NOMBRE
  carre EST_DU_TYPE NOMBRE
DEBUT_ALGORITHME
  AFFICHER "Entrez un nombre"
  LIRE n
  carre PREND_LA_VALEUR n * n
  AFFICHER "Carré : "
  AFFICHER carre
FIN_ALGORITHME

Run the example with n = 0, n = 1, and a negative value to check that multiplication gives the expected square. Then add a condition to distinguish even from odd numbers and trace its instructions one at a time.

07 · study and debugging

How to practise

Choose a simple exercise and describe what should happen in plain language before opening the editor. Step-by-step mode lets you compare that description with the actual instruction order.

  • Run cases that cover every branch of a condition.
  • Watch a variable before and after each assignment.
  • Test the input boundary that ends a loop.
  • For lists, try an empty list, one item, and several items if the operation allows it.
  • Consult the French documentation if a keyword or feature is not recognized.

Structured blocks and text represent the same algorithm only when all instructions and boundaries are correct. Check the result, not merely the absence of syntax errors.

08 · versions and scope

Versions and limits

AlgoBox is an environment with its own grammar and tools. Structured block editing, text mode, list features, and step-by-step display belong to AlgoBox; they are not universal properties of pseudocode.

Options and installation details can change between versions. This page summarizes the official site and manual; consult the linked documentation to confirm the behavior of the software you downloaded. AlgoBox remains under evaluation for Potoo IDE.
