Educational reference · historical Arabic educational language · under evaluation

Jeem

Jeem is described in historical sources as an educational language that uses Arabic letters, words, and numerals to teach programming. The technical documentation publicly accessible today is limited and does not establish a complete executable grammar. This reference separates documented facts from gaps; Jeem is under evaluation and is not run by Potoo IDE.

01 · overview

About Jeem

Jeem is associated with an Arabic programming initiative intended to bring computer science concepts closer to the language students use. Accounts of the project emphasize Arabic letters, words, and numerals and its possible use in school education.

The public documentation preserved today is much less complete than that of currently maintained educational languages. This page therefore provides a contextual reference, not a language specification.

Status in Potoo IDE: Jeem is under evaluation. This page records only what accessible sources support and does not claim compatibility with the app.

02 · historical context

Educational motivation

An interview published by the Saudi newspaper Al-Riyadh presents Jeem as a way to teach programming through Arabic writing and vocabulary. The idea responds to a common barrier in computing materials: examples and reserved words often assume familiarity with the Latin alphabet and English.

Keep three aspects separate when reading this goal:

  • Code language: the project is described as using Arabic writing.
  • Purpose: bring programming education closer to Arabic-speaking school settings.
  • Implementation: current software details require their own technical source.

A documented educational purpose is not enough to infer how a compiler interpreted each construct.

04 · syntax

Why there is no code example

An executable example requires a source that confirms reserved words, writing direction, delimiters, types, and execution rules. The historical sources found describe Jeem’s proposal, but do not provide a complete grammar with which to validate these choices.

To document an example safely, researchers would need:

  1. the technical manual or textbook for the original version;
  2. the environment that runs the language, if it is still available;
  3. a sample program with its expected output;
  4. information about character encoding and Arabic text order.

Until then, do not replace the missing grammar with translated Arabic words or with Kalimat constructs; these are separate projects.

05 · reading the project

How to study the proposal

Even without an available implementation, the educational intention can be analyzed. Compare the language proposal with a student’s experience: which terms would be familiar, how would code be edited on screen, and how would the notation present sequence, selection, and repetition?

  • Use accounts as historical sources for purpose and audience.
  • Mark whether a claim comes from an interview rather than a specification.
  • Do not turn a general description into a guarantee of a technical feature.
  • If an original manual is found, record its institution, year, and version before reproducing examples.

This method lets readers study the project’s contribution without inventing features absent from accessible sources.

06 · related projects

Jeem and Kalimat are different projects

Jeem and Kalimat are often grouped because they use Arabic, but that does not make them the same language. Kalimat has a current portal and distributed documentation describing programming features; the sources consulted for Jeem are mainly historical and high-level.

Do not transfer Kalimat’s advertised object-oriented features, concurrency, graphics, or native integration to Jeem. A valid comparison needs a specific source for each project and should state the period of the documentation.

07 · scope and uncertainty

Availability and limits

The newspaper source and reference overview help locate Jeem’s context, but they do not replace a maintained repository or original specification. The historical address associated with the project was not confirmed as an active portal with current documentation and downloads.

Therefore, this page does not state an operating system, installation process, compiler, version, or syntax as current fact. The status can be revisited if verifiable primary files become available. Jeem remains under evaluation, with no implementation commitment.
