01 · Overview

About Logic Basic

Logic Basic is a programming language paired with a visual environment: besides code, a program can interact with a window, controls, drawings, sounds, and data files. The author's manual introduces it through commands and progressive exercises for beginners.

This reference summarizes concepts and forms of writing documented in the manual consulted. Since the material is organized around commands and environment features, use the source for details of each visual option.

02 · Organization

Program, window, and file

The manual describes two work areas: the code and the window where the program displays results and controls. Execution proceeds through the code until the end or until FimPrograma or FimJanela. Source files use the .LBC extension.

A line can contain multiple commands separated by semicolons; each separated command is treated as a logical line. An apostrophe begins a code comment.

Memoria Nome
Nome = "Ana"
Posicione 1, 1
Escreva "Hello, ", Nome
FimPrograma

Program order and extensions

The main file runs in sequence, from its first instruction to its last. FimPrograma ends that sequence while leaving the window open; FimJanela also closes the window. Code extensions act as sections appended to the main code and are a documented place to store routines called by the program. The manual recommends declaring memory values at the start of the main code.

ElementWhen to useDocumented effect
MemoriaIn the main-code header.Creates names that can hold values and resources.
Numbered extensionTo separate routines from the main flow.It is appended to the main code during execution.
FimProgramaWhen the algorithm should finish but the window should remain.Stops the program.
FimJanelaWhen the window should close as well.Stops the program and closes the window.

03 · Data

Memory values

Memoria creates names used to store values. The manual recommends putting these declarations at the beginning of the main code. A memory value can hold text, numbers, and visual-environment items such as objects and sounds. The same name can receive a new value during execution.

Memoria Nome, Pontos, Fundo
Nome = "Ana"
Pontos = 12
Fundo = "fundo-verde"

Text is quoted. An unquoted number is numeric and can be used in calculations; a quoted number is text. The manual uses a comma as the decimal separator, for example 3,5. Memory names cannot contain spaces.

Reading the stored value

Memoria lists the names the program can use; the assigned value determines how a name participates in an expression. Quotation marks matter: numeric-looking text remains text. The consulted manual does not show type declarations for these memory values.

FormExampleHow to read it
Text literalNome = "Ana"Stores characters enclosed in quotation marks.
NumberPontos = 12A numeric value that can take part in a calculation.
Text that looks numericPontos = "12"Still text; do not treat it as the number 12.
Indexed memoryNome(0)Reads a matrix position declared with a size.

05 · Interaction

Input, messages, and output

Escreva displays one or more items in the window in sequence. Posicione sets the output position and LimpaJanela clears the visual area. Mensagem displays a dialog message.

EntraTexto prompts for text and returns the input to a memory value. The manual also describes controls such as text boxes, lists, options, and check boxes; their values can be read with Componente Valor.

Memoria Nome
Nome = EntraTexto, "Enter your name:"
LimpaJanela
Posicione 1, 1
Escreva "Hello, ", Nome
Mensagem "Entry complete"

Interaction command reference

Command arguments are separated by commas. Escreva displays each argument in sequence; quotation marks distinguish literal text from a memory name. The default window uses zero-based coordinates, although Janela can change its resolution.

FormResultImportant detail
Posicione row, columnSets the next output position in the window.The default grid has 27 rows and 79 columns, numbered 0–26 and 0–78.
Escreva expression, ...Displays arguments in the window on the same logical line.Literal text is quoted; an unquoted memory name supplies its contents.
Mensagem textOpens a centered message box.It ignores the position set by Posicione.
name = EntraTexto, promptPrompts for text and stores the response in memory.The memory value must already be declared.
Componente Valor, nameReads the value entered in a control.Create the control first with Componente.
AguardePauses for an interaction or configured duration.It can wait for a key, a button/object click, or a number of seconds; an interaction result may be placed in Retorno.

A semicolon lets you place multiple commands on one physical line, but the manual treats each separated command as a logical line. This matters when reading the debugger and using jumps to labels.

06 · Decisions and repetition

Se, CasoContrario, and VaPara

Se executes statements when a condition is true. CasoContrario defines an optional alternative and FimSe closes the block. For repetition, the manual presents labels and VaPara, which transfers execution to a named line.

Memoria Tentativa
Tentativa = 0
INICIO
Tentativa = Tentativa + 1
Escreva "Attempt ", Tentativa
Se Tentativa < 3
VaPara INICIO
CasoContrario
Escreva "Attempts complete"
FimSe

This form can create loops, but it requires explicit control of the state that ends repetition. An incorrect jump can make the program repeat forever.

Control forms at a glance

FormEffectWatch for
Se condition ... FimSeRuns the block when the comparison is true.= compares inside a condition, although it assigns outside one.
CasoContrarioMarks the alternative block of a Se.Keep it inside the matching block and close the structure with FimSe.
LABEL followed by VaPara LABELResumes execution at the named line.Update the value used by the condition before jumping again.

A jump creates repetition through control flow: the label marks the start, and the condition decides whether execution returns. Before running it, trace one iteration by hand and confirm that the tested value moves toward the exit.

07 · Reuse

Functions and extensions

The manual describes named routines outside the main flow. Execute Name() calls a routine, and Retorne returns execution to the command after the call. A routine can call other routines and can be recursive. The material also presents extension panels for organizing reusable code.

Escreva "Before the routine"
Execute Saudacao()
Escreva "After the routine"
FimPrograma

Saudacao()
Escreva "Hello!"
Retorne

Use consistent routine names and make sure every execution path that enters a routine reaches Retorne, so it does not continue into unrelated code.

Routines, calls, and return

A named routine appears after the main program's terminator or in an extension. Execute Name() transfers control to it; Retorne returns to the command after the call. The introductory manual describes this as control flow, not as an expression that returns a calculated value. In its basic examples, shared memory values provide the way to exchange data: declare them and read or update them inside the routine.

Memoria Resultado
Resultado = "ready"
Execute ExibaResultado()
FimPrograma

ExibaResultado()
Escreva "Status: ", Resultado
Retorne

Separate a routine when a group of commands has a clear responsibility or is called from more than one place. In a recursive routine, every path must reach a stopping case or Retorne; otherwise calls can continue to accumulate.

08 · Collections

Matrices

A memory value can be declared with a number of positions in parentheses. Indices start at zero. For example, Memoria Nome(20) creates positions from Nome(0) through Nome(19). A numeric value can serve as an index inside a loop.

Memoria Nome(3), I
Nome(0) = "Ana"
Nome(1) = "Beto"
Nome(2) = "Caio"
I = 0
INICIO
Escreva Nome(I)
I = I + 1
Se I < 3
VaPara INICIO
FimSe

ProcureMatriz searches for a value in a matrix and returns its matching index; the manual says it returns -1 when the value is not found.

09 · Visual features

Window, controls, and media

Visual commands can position text, draw objects, display images, and respond to interactions. Componente creates form controls; Desenhe displays objects or visual resources; Aguarde pauses execution or receives an interaction, depending on the arguments documented in the manual.

The material also covers mouse input, sound, and video. Channels, positions, dimensions, and controls depend on each command's parameters; consult the source before using advanced options.

LimpaJanela
Posicione 5, 5
Desenhe "personagem"
Aguarde

Debug by following program state

The environment's Depurar mode shows command lines as they run. Compare the current instruction with the window output and the values in the memory it uses. The manual recommends checking that every memory name has been declared and that each command is spelled correctly.

SymptomWhat to check first
A name is displayed literally.Check that it was declared with Memoria and given the expected value.
Text appears in the wrong position.Check the argument order of Posicione row, column and whether the coordinates fit the window resolution.
A loop does not stop.Check whether the memory tested by Se changes before the VaPara jump.
A routine does not return to its call site.Trace the executed path and confirm that it reaches Retorne.
An interaction does not update memory.Check that the control was created first and that the response is read through Componente Valor or Retorno, depending on the command.

10 · Persistent data

Native database

The manual describes BD ... FimBD blocks for defining fields and AbreBD for opening a data file. Fields are populated through the database and field names; AdicionaRegistro saves a record, LeRegistro reads by position, and FechaBD closes the file. Commands for sorting, searching, and counting records are also documented.

CommandPurpose in the manual
BD ... FimBDDefine a table's fields.
AbreBD / FechaBDOpen or close the associated file.
AdicionaRegistroSave populated fields as a new record.
LeRegistroRead a record by position.
OrdemBD, ProcureSort or locate records.
TotalRegistrosGet the number of records.

The database uses its own files and a field definition. Follow the manual's open and close sequence before reading or saving records.

Schema, opening, and record indexes

A BD declaration associates a logical name with a path and lists each table field with its size; it belongs in the header after Memoria. Data files use the .LBA extension, which may be omitted from AbreBD. A database can have only one file open at a time: close it before selecting another file for the same schema.

Records are indexed from zero. If TotalRegistros returns T, valid indexes range from 0 to T - 1. Run OrdemBD before the routine that uses the sort order; after setting an index, reads follow that order until you select Sequencial or another ordering. Procure uses the current index and returns -1 when no record matches.

A safe operation sequence is: define the fields, open a file, populate a record's fields, and save it with AdicionaRegistro; for queries, get the count or locate a position, read with LeRegistro, and close with FechaBD when finished.

11 · In practice

Integrated example

This example uses memory values, input, and a condition to display a personalized greeting. It brings together basic commands without depending on advanced graphics.

Memoria Nome, Pontos
Nome = EntraTexto, "What is your name?"
Pontos = 0
LimpaJanela
Posicione 1, 1
Escreva "Welcome, ", Nome
Se Nome = ""
Mensagem "Enter a name to continue"
CasoContrario
Pontos = Pontos + 1
Escreva "Points: ", Pontos
FimSe
FimPrograma
