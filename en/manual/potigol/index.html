Potigol

01 · Overview

About Potigol

Potigol is an educational project with Portuguese syntax and features for imperative, functional, and object-oriented programming. Its official documentation highlights static typing with inference, functions, lists, tuples, custom types, and pattern matching.

This page describes Potigol using the project's references. Additional libraries such as Jerimum extend what a program can do without becoming part of Potigol's core syntax.

02 · Organization

Basic structure

A file can begin directly with declarations and instructions. Simple examples do not need an outer programa block or a main function.

# A sequence of instructions
nome = "Mundo"
escreva "Olá, {nome}!"

soma(a: Inteiro, b: Inteiro) = a + b
escreva soma(2, 3)

Instructions can be expressions, declarations, calls, assignments, or blocks that end with fim. Functions and types can also be declared in the file.

03 · Writing

Names and comments

  • Identifiers start with a letter and may contain letters, accents, digits, and underscores.
  • Keywords and type names use Portuguese terms such as se, então, Inteiro, and Lógico.
  • Line comments start with #.
  • Text uses double quotes; expressions inside braces are interpolated.
# Comment
aluna = "Lia"
nota = 8.5
escreva "{aluna} obteve {nota}"

04 · Data

Types and variables

TypeExample or use

Assignment with = creates a value that cannot be reassigned. Use var for a mutable variable and := to update it. Types are inferred when omitted and remain fixed while the program runs.

pontos = 10
var tentativas := 0
tentativas := tentativas + 1
nome: Texto = "Lia"
idade: Inteiro = 14

Parallel assignment binds several values in one instruction, for example a, b = 3, 7.

05 · Expressions

Operators

Parentheses make evaluation order explicit. :: prepends an item: 0 :: [1, 2] produces [0, 1, 2].

06 · Interaction

Input and output

escreva prints an expression and advances to the next line; imprima writes without that line break. leia_inteiro, leia_numero, and leia_texto read values of the specified type. The documentation also describes multiple-value and list input.

imprima "Digite seu nome: "
nome = leia_texto
escreva "Olá, {nome}!"
escreva "Digite dois números:"
a, b = leia_inteiro
escreva "{a} + {b} = {a + b}"

In a string, {expression} inserts its value. Potigol also documents formatting with the value formato pattern expression.

07 · Flow

Conditions and loops

se and escolha express decisions. Blocks can be used as instructions or as expressions that produce a value.

mensagem = se nota >= 7 então
  "Aprovada"
senão
  "Continue praticando"
fim

escolha nota
  caso 10 => "Excelente"
  caso n se n >= 7 => "Aprovada"
  caso _ => "Estude mais"
fim

Loops include para and enquanto. para iterates over a range or a collection and can take a step value.

para i de 1 até 3 faça
  escreva i
fim

var n := 3
enquanto n > 0 faça
  escreva n
  n := n - 1
fim

08 · Reuse

Functions and collections

A short function can be written as an expression. Functions with several instructions end with fim; the final expression supplies the result, or retorne can state it explicitly. Functions also support typed parameters and recursion.

dobro(n: Inteiro) = n * 2

fatorial(n: Inteiro): Inteiro
  se n <= 1 então
    1
  senão
    n * fatorial(n - 1)
  fim
fim

Lists and tuples organize values. Lists can be transformed with mapeie, filtered with selecione, and reduced with injete. Potigol's documentation uses one-based list indexes.

numeros = [1, 2, 3, 4]
dobros = numeros.mapeie(n => n * 2)
pares = numeros.selecione(n => n mod 2 == 0)
coordenada = (3.5, 2.0)

09 · Modeling

Custom types and object-oriented programming

tipo declares structures with attributes and methods. Create a value by calling the type with its attribute values; methods can be used as properties or functions.

tipo Pessoa
  nome: Texto
  saudacao() = "Olá, {nome}!"
fim
aluna = Pessoa("Lia")
escreva aluna.saudacao

The official documentation also covers abstract types, inheritance, generics, tuples, functions as values, and pattern matching.

10 · Game library

Jerimum: games with Potigol

Jerimum is a game library for Potigol. Its official repository contains examples and modules for opening a window, drawing images and text, reading keyboard and mouse input, tracking time, and playing audio. It adds game features to Potigol programs and remains separate from Potigol's core syntax.

Startup and the game loop

A program starts with use "jerimum" and defines atualize() to update game state and desenhe() to register drawing operations. jogo.iniciar receives a title, width, height, the two functions, and an optional frame rate that defaults to 60.

use "jerimum"

atualize()
  # Atualize o estado do jogo
fim

desenhe()
  # Registre imagens e textos do quadro
fim

jogo.iniciar("Meu jogo", 640, 480, atualize, desenhe, 60)

jogo exposes largura, altura, título, and fps. The source creates a fixed-size window with Swing/AWT. Jogo.distância, Jogo.projeção_X, and Jogo.projeção_Y support movement calculations; projection angles are given in degrees.

Drawing, layers, and images

Imagem("file.png") loads an image. desenhe(x, y, z) places it at coordinates on an integer layer. Higher-numbered layers are drawn in front. The library also provides centered drawing, rotation, scaling, and sprite-sheet slicing with fatie.

fundo = Imagem("fundo.png")
nave = Imagem("nave.png")
quadros = Imagem.fatie("explosao.png", 32, 32)
desenhe()
  fundo.desenhe(0, 0, 0)
  nave.desenhe_centralizado(320, 240, 2, 0)
fim

Animacao(velocidade, imagens) selects images from a sequence based on elapsed time.

Keyboard, mouse, and time

Teclado exposes logical values such as TECLA_PARA_DIREITA, TECLA_ENTER, and TECLA_A through TECLA_Z. Mouse.x and Mouse.y report the pointer position; Mouse.BOTAO_ESQUERDO and Mouse.BOTAO_DIREITO report button states. Relógio.milisegundos counts time since initialization.

var x := 100
atualize()
  se Teclado.TECLA_PARA_DIREITA então x := x + 4 fim
  se Mouse.BOTAO_ESQUERDO então x := Mouse.x fim
fim

Text, colors, audio, and files

Fonte(tamanho) creates a font. Its drawing methods accept text, coordinates, a layer, and a color. Cor(vermelho, verde, azul) creates an RGB color; constants include Cor.BRANCO, Cor.PRETO, and Cor.VERDE.

Som("efeito.wav") plays an effect with toque(). Musica("faixa.wav") provides toque, pause, continue, pare, and tocando; playback loops by default. Arquivo.leia("dados.txt") returns the file's lines as a list.

Example: move an image

use "jerimum"
nave = Imagem("nave.png")
var x := 300
var y := 220
atualize()
  se Teclado.TECLA_PARA_DIREITA então x := x + 4 fim
  se Teclado.TECLA_PARA_ESQUERDA então x := x - 4 fim
  se Teclado.TECLA_PARA_CIMA então y := y - 4 fim
  se Teclado.TECLA_PARA_BAIXO então y := y + 4 fim
fim
desenhe()
  nave.desenhe_centralizado(x, y, 1)
fim
jogo.iniciar("Movimento", 640, 480, atualize, desenhe)

Method details are in the Jerimum documentation and source code. The library uses Java facilities for windows, drawing, and audio; its examples describe desktop Potigol programs.

11 · Combined example

Calculate an average

media(a: Real, b: Real, c: Real) = (a + b + c) / 3
escreva "Digite três notas:"
a, b, c = leia_numero
resultado = media(a, b, c)
se resultado >= 7 então
  escreva "Aprovada: {resultado}"
senão
  escreva "Em recuperação: {resultado}"
fim
