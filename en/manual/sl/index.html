01 · overview

About SL

SL introduces programming concepts in a textual form that is readable to Spanish-speaking students. Project materials describe a learning environment for constructing algorithms, testing execution, and studying the parts of a solution.

SL is not simply a translation of another pseudolanguage: its grammar, reserved words, and library should be read from SL documentation. This reference highlights concepts in material from the Universidad Nacional de Asunción and avoids mixing in commands from other systems.

Status in Potoo IDE: SL is under evaluation. The examples on this page refer to the external project and do not claim compatibility with the app.

02 · background

Project and teaching purpose

The official material is associated with the Facultad Politécnica at the Universidad Nacional de Asunción. It presents SL as a resource for teaching algorithms and includes the SLE environment, documents, examples, and supporting material.

The language was designed for practicing introductory concepts:

  • describe a sequence of instructions with an explicit beginning and end;
  • declare data and compose expressions;
  • read input and display results;
  • control decisions and repetition;
  • organize calculations into functions and procedures.

The official portal and project book are the references for syntax details and for features in a specific version of SLE.

03 · program outline

Program structure

The smallest program declares data, starts execution at inicio, and ends at fin. The optional header programa name identifies the file; it does not change the execution sequence.

programa saludo
var
    numero, cuadrado : numerico
inicio
    leer(numero)
    cuadrado = numero * numero
    imprimir("Square: ", cuadrado)
fin

const, tipos, and var declarations can appear before inicio, in any order and more than once. A subroutine is declared after the main program and has its own local declarations.

FormRoleNote
programa nomeOptional header.Identifies the program.
const / tipos / varDeclares global constants, types, and variables.Can appear more than once and in any order before inicio.
inicioStarts program execution.Follows the global declarations.
finEnds the main program.Subroutines follow it.

04 · structured data

Types, variables, and collections

SL has three basic types. numerico represents integers and real numbers; there are no separate types for each precision. The type checker requires compatible types in expressions. You can create composite types with vectors, matrices, records, and names declared under tipos.

Type or formRepresentsUsage rule
numericoIntegers and real values.Use one type for counters, measurements, and calculations.
cadenaText with dynamic length.The + operator concatenates two strings; characters can be accessed by index.
logicoLogical values, such as TRUE and FALSE in official examples.Conditions and relational operators produce logical values.
vector [n] tipoVector with a fixed size.Positions start at 1 and end at n.
matriz [rows, columns] tipoMatrix with one or more dimensions.Provide one index per dimension.
vector [*] tipoOpen vector sized at runtime.Call dim(vector, size) before traversing its elements.
registro { field : type }Groups named fields that can have different types.Access a field with a dot, such as alumno.nota.
tipos NAME : typeCreates a reusable type name.Composite types are structurally compatible.
tipos
    ALUMNO : registro {
        nombre : cadena
        nota : numerico
    }
var
    grupo : vector [*] ALUMNO
    total : numerico
inicio
    dim(grupo, 2)
    grupo[1].nombre = "Lia"
    grupo[1].nota = 9
    grupo[2].nombre = "Rui"
    grupo[2].nota = 7
    total = alen(grupo)
    imprimir(grupo[1].nombre, " / ", total)
fin

The first index is 1, which differs from languages that start at zero. A matrix M can be traversed by rows with alen(M); alen(M[1]) returns the column count in its first row. If a size is known only at runtime, declare the dimension as open with * and allocate it with dim.

The example shows two access steps for a record stored in a vector: select an element, then its field. Check the element count before indexing; an out-of-range access causes a runtime error.

05 · interaction

Input, output, and files

leer and imprimir accept several arguments and complete structures. By default, input fields are separated by commas; output values are written in sequence, so add spaces and line breaks explicitly.

FormEffectDetail
leer(a, b)Reads values into the listed variables or structures.One call can read several scalars, a vector, or a record.
imprimir(a, b)Writes values to the screen or the current destination.Use "\n" and "\t" to format lines and columns.
set_ifs(separator)Changes the field separator for leer.The default is a comma; set it again after set_stdin.
set_stdin(file)Reads from a file instead of the keyboard.Check its logical return value and use eof() while reading a file.
set_stdout(file)Redirects imprimir to a file.The basic form replaces an existing file; mode "at" appends.
set_ofs(separator)Changes the separator used when printing composite values.The default for vectors and records is a comma.
var
    nombre : cadena
    edad : numerico
inicio
    imprimir("Name and age (comma-separated): ")
    leer(nombre, edad)
    imprimir("\nHello, ", nombre, ". Age: ", edad, "\n")
fin

Strings recognize escape sequences such as \n (newline), \r (return to the start of the line), and \t (tab). To process a file line by line, select it with set_stdin, set set_ifs("\n"), read the first record, and test eof() before continuing the loop. The standard library explains how to restore keyboard and screen output with an empty string.

06 · execution flow

Conditions, selection, and loops

Conditions are enclosed in parentheses. si chooses a branch, eval selects among conditions, and the three loop forms test at different points.

FormExecutionWhen to use
si (condition) { ... sino ... }Runs one branch according to the test.Use for two alternatives or chained decisions.
eval { caso (condition) ... sino ... }Checks cases in order and runs the first true one, then exits the block.Use for several mutually exclusive conditions. sino is optional and comes last.
mientras (condition) { ... }Tests before the body.May run zero times; update data in the body so the condition can become false.
repetir ... hasta (condition)Tests after the body.Runs at least once; useful for a first prompt or validation.
desde i=start hasta end paso step { ... }Walks an integer range including its final value.The step may be negative; match its direction to the bounds.
var
    i, suma : numerico
inicio
    i = 1
    suma = 0
    repetir
        suma = suma + i
        i = i + 1
    hasta (i > 4)
    imprimir("Sum from 1 to 4: ", suma)
fin

In desde, the start, end, and step are converted to integers. The step can move forward or backward. A smaller start pairs with a positive step; to count down, use a larger start and a negative step. The loop may run zero times when the bounds and step cannot reach the range.

The repetir example always adds at least the first value. To trace it, record i before the body and suma before and after the assignment. Once i passes 4, the condition ends the loop.

07 · complete program

Guided example: average a set of marks

This program sizes a vector from the input, visits each mark, and calculates an average. The count check prevents division by zero. Indices start at 1, and alen uses the actual vector size instead of a repeated constant.

programa promedio_notas
var
    cantidad : numerico
    notas : vector [*] numerico
    i, suma, media : numerico
inicio
    imprimir("Number of marks: ")
    leer(cantidad)
    si (cantidad > 0) {
        dim(notas, cantidad)
        suma = 0
        desde i=1 hasta alen(notas) {
            imprimir("\nMark: ")
            leer(notas[i])
            suma = suma + notas[i]
        }
        media = suma / alen(notas)
        imprimir("\nAverage = ", str(media, 0, 2))
    sino
        imprimir("\nAt least one mark is required.")
    }
fin

With inputs 3, 8, 6, and 10, the sum reaches 24 and the average is 8. The table records the state after each pass.

IterationiMarkRunning sum
1188
22614
331024

After the ordinary case, test a count of 1 and a count of 0. The first runs one iteration; the second skips allocation and division. To extend the program, add a condition for each valid mark and keep accepted values separate.

08 · workflow

Practice, tests, and debugging

The official portal keeps the introductory book, selected examples, and a built-in function reference. Start with short programs, check their values by hand, and then add vectors, records, and subroutines.

AreaTestReview question
DataTry zero, one value, and a boundary value.Does the declared type fit all values and operations?
ConditionsExercise every branch, including the final alternative.Do comparisons use matching types and cover all cases?
LoopsRecord the condition, counter, and controlling value.Can the condition become false, and does the right value change?
VectorsTry the first and last valid positions.Does the index start at 1 and stay within alen(v)?
SubroutinesCompare arguments before the call and the result after it.Should the parameter be passed by value or by reference?

The SLE step-through debugger can help find the instruction where a value diverges from expectations, depending on the installed version. A dry-run table still helps without a debugger: add one row per iteration and record only the values that control the result.

09 · scope and compatibility

Version and scope of this reference

The Universidad Nacional de Asunción portal documents the SLE environment and publishes historical materials for SL. Its documents page warns that the book describes a version earlier than the current SLE release. Confirm syntax and behavior in the help for the version used in class.

SL remains under evaluation for Potoo IDE. This page describes SL from the book, examples, and official function reference; it does not claim that the current SLE or every listed feature is integrated into the application.

10 · reading the syntax

Identifiers, operators, and source layout

The book defines identifiers as case-sensitive, up to 32 characters, and starting with a letter or underscore. The letter ñ is allowed; accented vowels are not listed as valid identifier letters. Reserved words are written in lowercase. Comments use // or /* ... */.

Operator or formMeaningNote
=Assignment.The right-hand expression must match the variable type.
==Equality.Do not confuse it with assignment.
<>Inequality.Comparisons require operands of the same simple type.
and, or, notConjunction, disjunction, and negation.They produce logical values; use parentheses to make intent clear.
+Addition or concatenation.Both operands must be numeric or both strings.
;Separates statements on the same line.It is not needed between statements on separate lines.
LevelOperatorsMeaning
Highest^Exponentiation.
2+x, -xUnary sign.
3*, /, %Multiplication, division, and remainder.
4+, -Addition, subtraction, and compatible string concatenation.
5==, <>, <, <=, >, >=Equality and relational comparisons.
6notLogical negation.
7andLogical conjunction.
LowestorLogical disjunction.

Operators on the same precedence row are evaluated left to right. Parentheses change the order. The first edition of the book uses and, or, and not; examples in the function reference also show && in some expressions, so confirm the spelling accepted by the installed SLE.

Statements may continue across lines. A semicolon is an optional separator only when multiple statements share a line.

11 · modularity

Functions, procedures, and parameters

The main program is followed by subroutine definitions. A function declares its return type and uses retorna; a procedure has no return clause. Parameters are copied by default, or can use ref to modify the variable supplied by the caller.

subrutina cuadrado(n : numerico) retorna numerico
inicio
    retorna (n * n)
fin

Functions can return any type, including vectors and records. Parameters and variables declared inside a subroutine are local; declarations in the main program are global. A subroutine can call another without a prototype and can recurse.

subrutina duplicar(ref valor : numerico)
inicio
    valor = valor * 2
fin
FormRoleWhat to check
subrutina f(x : tipo) retorna tipoFunction that returns a value.It can appear in an expression; declare a type compatible with the returned value.
subrutina f(x : tipo)Procedure that performs actions.Call it as a statement and account for its effects.
x : tipoValue parameter.The subroutine changes its local copy.
ref x : tipoReference parameter.An assignment can modify the caller’s variable.
ref a : vector [*] numericoOpen vector passed by reference.The routine can call alen(a) and change its elements.

Use reference parameters only for values that must come back changed. For a calculation, prefer value parameters and a returned result. For a routine that fills or sorts a vector, document that the argument is modified.

12 · standard library reference

Built-in functions and procedures

SLE includes mathematical, string, array, I/O, and utility routines. The table catalogs the families in the official reference; these built-ins do not need imports. Check the complete signatures and optional arguments in the documentation for the installed version.

FunctionsFamilyUse and notes
abs, arctan, cos, exp, int, log, sin, sqrt, tanMathematics.Includes absolute value, trigonometry in radians, exponentials, logarithms, square root, and integer part. log requires n > 0; sqrt requires a positive input according to the installed SLE version.
ascii, ord, lower, upper, pos, strdup, strlen, substrStrings.Reads a character code, searches, changes case, repeats a string, measures length, and extracts substrings. substr uses positions starting at 1.
str, valFormatting and conversion.str formats a number; val reads digits from a string and returns 0 when it finds no number.
alen, dimVectors and matrices.alen returns a size; dim allocates open dimensions at runtime.
imprimir, leer, eofInput and output.Accept simple values and structures; eof checks end of file.
set_stdin, set_stdout, set_ifs, set_ofs, get_ifs, get_ofsFiles and separators.Select devices and configure input and structured-output separators.
beep, cls, readkeyConsole.Beep, clear the screen, or wait for a key; effects depend on the input/output device.
get_color, set_color, get_curpos, set_curpos, get_scrsizeScreen and cursor.Read or change color, position, and terminal dimensions.
inc, dec, intercambiar, swap, max, min, ifvalUtilities.Update or exchange values, compare two values of the same type, and select a conditional expression.
random, sec, paramval, pcount, runcmd, terminarExecution and system.Generate pseudorandom integers, read time and arguments, run a process, or terminate the program.

Useful signatures

CallResultNote
random(limit)Integer from 0 through limit - 1.SLE initializes the generator at startup; a seed is usually unnecessary.
substr(text, start [, count])Copy of a substring.A start beyond the end of the text returns an empty string.
str(number [, width [, places [, fill]]])Formatted text representation.Use width 0 to omit a minimum width; check rounding behavior.
val(text)Numeric value.Returns 0 if the string contains no number; validate before using the result.
dim(vector, sizes...)Allocates the specified open dimensions.Fixed dimensions already declared do not take a new size.
alen(vector)Element count.For matrices, alen(M) reads the rows and alen(M[1]) reads columns in the first row.
inc(ref n [, step]), dec(ref n [, step])Updates n and returns its new value.The default step is 1; it may be positive or negative.
ifval(condition, when_true, when_false)Conditional expression.Evaluates only the selected value; both alternatives must have the same simple type.
set_stdin(file), set_stdout(file)Redirects reading or printing.Check the logical result. set_stdout replaces a file by default; mode at appends.

var
    nota : numerico
inicio
    nota = val("7.5")
    imprimir("\n", upper("sl"), " / ", substr("algoritmo", 1, 4))
    imprimir("\nFormatted mark: ", str(nota, 0, 2))
    imprimir("\nDie (0 to 5): ", random(6))
fin

Terminal, file, and process routines depend on SLE and its host system. sec() also has a history of version-dependent behavior. The official reference gives the full signatures, side effects, and examples for every routine.
