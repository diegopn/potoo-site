Educational reference · gradual multilingual language · under evaluation

Hedy

Hedy is a gradual textual programming language and educational platform for learning programming step by step. Each level introduces additional concepts and conventions, helping students move toward a language such as Python. The platform includes Portuguese and other languages. Hedy is under evaluation; Potoo IDE does not run Hedy programs.

01 · overview

What is Hedy

Hedy was created to help students begin programming with text. Instead of presenting all the syntax of a traditional language at once, the platform introduces commands and rules gradually across learning levels.

The project brings together a language, online environment, activities, and teacher materials. Commands can appear in different languages, so accepted program text depends on the selected language and level.

Status in Potoo IDE: Hedy is under evaluation. This page describes the external platform and does not imply compatibility or execution in the app.

02 · progression

Levels and gradual learning

Each level adds concepts or moves the written form closer to a language such as Python. A learner starts with small operations and can progress to variables, conditions, repetition, lists, and other features as the course advances.

The progression avoids overwhelming beginners with every punctuation rule at the start. It also means the same command can have a different form at different levels. When reading an example, always note:

  • the activity’s level;
  • the selected command language;
  • the constructs already introduced;
  • the instructions the exercise expects learners to use.

Do not compare two listings without checking these details; a syntax difference may be intentional.

03 · first commands

Output and interaction

At early levels, simple commands can display a message and ask for input. The following form illustrates introductory commands in English; other translations may be available in the platform settings:

print Welcome to Hedy!
ask What is your favorite sport?
print so your favorite sport is answer

print displays a message, ask asks a question, and answer inserts the answer in displayed text. Exact forms and available commands depend on the selected level. Use the example attached to the activity to confirm syntax in the language you chose.

04 · progressive concepts

Variables, conditions, and collections

As the course advances, Hedy introduces names for storing values, expressions, and structures that control execution. Later lessons work with conditions, repetition, and collections, bringing the code closer to conventions found in textual programming languages.

ConceptWhat learners study
VariablesStore and reuse answers and results.
ExpressionsCombine values to produce an answer.
ConditionsChoose an action based on data.
RepetitionRun instructions several times under a rule.
Lists and functionsOrganize values and reuse operations at later levels.

Content and level names are part of the platform’s curriculum. Check the current lesson because the progression may be revised.

05 · languages

Languages and command variants

Hedy supports experiences in multiple languages, including Brazilian and European Portuguese. The project maintains a translation process, and available commands can vary by translation and level.

This is different from translating only the interface: some program keywords can also be localized. When sharing an exercise:

  • state the selected language;
  • record the lesson level;
  • avoid substituting improvised translations for commands;
  • confirm that another learner can open the activity with the same settings.

If a command is not recognized, check the code language and lesson before concluding that the algorithm is wrong.

06 · worked example

Ask an interactive question

The introductory sequence can ask about a favorite sport. This English example asks about a favorite sport and includes the answer in a message:

print Welcome to Hedy!
ask What is your favorite sport?
print so your favorite sport is answer

First, run the activity and observe the input. Then change the question and observe how the answer changes. When the lesson introduces a way to store answers in a variable, write a personalized response using the command taught at that level. This progression is intentional: do not use later-level syntax before the activity introduces it.

07 · learning platform

Activities and classroom use

Alongside code, the platform organizes levels, lessons, exercises, and teacher support. Activities provide a learning path and can show feedback that helps students interpret errors. Teachers can use the materials to plan a sequence, follow a class, and contextualize the transition to Python.

To work through an activity:

  1. choose the language and level set by the course;
  2. read the explanation before editing the program;
  3. run an initial example;
  4. make a small change and observe the response;
  5. save or share work using the platform’s available options.

Account, classroom, and storage features depend on the online version and may change.

08 · study and debugging

Understanding errors

Environment feedback is part of learning. When a program does not work, first check what the lesson allows at that level and language. Then read the error message and reduce the problem to one change at a time.

  • Check whether the command was introduced at the current level.
  • Verify translated spelling and required punctuation.
  • Run the smallest version that reproduces the issue.
  • Compare supplied input with expected output.
  • When moving toward Python, note which rules are Hedy-specific and which carry over.

A syntax error can result from using a convention from another level; it does not necessarily mean the algorithmic idea is wrong.

09 · versions and scope

Languages, levels, and change

Hedy evolves as a platform and curriculum. The number of levels, lessons, translations, and features may change. This page avoids fixing a level count and describes the general progression in current official materials.

Syntax depends on level and language. A single example therefore does not represent the entire language. Consult the current platform and teacher manual before preparing class materials. Hedy remains under evaluation for Potoo IDE.
