PSeInt

01 · Overview

About PSeInt

PSeInt is an educational environment for writing and running algorithms in pseudocode. Its official reference describes Spanish-language instructions and profiles with more flexible or stricter rules.

The environment can also display algorithms as flowcharts, making sequences, decisions, and loops easier to follow alongside the instructions.

02 · Organization

Algorithm structure

The documented format places instructions between Proceso and FinProceso. Some versions and profiles also accept Algoritmo and FinAlgoritmo. Depending on the profile, statements may require semicolons or be separated by lines.

Proceso Saludo
    Definir nombre Como Caracter
    Escribir "¿Cómo te llamas?"
    Leer nombre
    Escribir "Hola, ", nombre
FinProceso

03 · Data

Variables, types, and assignment

An explicit declaration uses Definir nombre Como Tipo. Assignment evaluates the right-hand expression and stores its result in the variable on the left; the types must be compatible.

TypeUse
EnteroInteger numbers.
RealNumbers with a decimal part.
CaracterCharacters and text.
LogicoVerdadero or Falso.
Definir edad Como Entero
Definir promedio Como Real
Definir nombre Como Caracter
Definir aprobado Como Logico
edad <- 16
promedio <- 8.25
nombre <- "Ana"
aprobado <- Verdadero

Names start with a letter, may continue with letters and digits, and cannot match reserved words. Comments start with //.

Operators and functions

Parentheses change the usual evaluation order. The reference also lists built-in functions such as RC, ABS, LN, EXP, SEN, COS, ATAN, TRUNC, REDON, and AZAR.

area <- base * altura / 2
resto <- numero MOD 2
es_par <- resto = 0
raiz <- RC(numero)

05 · Interaction

Input and output

Leer receives one or more values and assigns them to the listed variables. Escribir displays one or more expressions. Some profiles include output without a line break, such as Escribir Sin Saltar.

Escribir "Enter two numbers:"
Leer a, b
suma <- a + b
Escribir "Sum: ", suma

06 · Decisions

Conditions and selection

Si evaluates a condition; Entonces introduces the true branch and Sino the alternative. Segun selects among several cases and may include De Otro Modo.

Si nota >= 7 Entonces
    Escribir "Aprobado"
Sino
    Escribir "Keep practicing"
FinSi
Segun opcion Hacer
    1:
        Escribir "Start"
    De Otro Modo:
        Escribir "Invalid option"
FinSegun

07 · Repetition

Loops

Mientras checks its condition before each iteration. Repetir runs the body first and checks Hasta Que, so it executes at least once. Para walks a range and can use Con Paso.

Para i <- 1 Hasta 5 Con Paso 1 Hacer
    Escribir i
FinPara
Repetir
    Leer clave
Hasta Que clave = "fin"

Make sure the stopping condition can become true to avoid an infinite loop.

08 · Collections

Arrays and matrices

Dimension declares an array or matrix. Its notation and starting index depend on the active profile, so do not assume the bounds. This example has five positions numbered from 0 through 4:

Definir notas Como Real
Dimension notas[5]
Para i <- 0 Hasta 4 Hacer
    Leer notas[i]
FinPara
Escribir "First grade: ", notas[0]

A second dimension creates a matrix and requires one index per dimension. Check the size and bounds set by the profile before accessing a position. Arrays can also be passed to subprograms when their signature is supported by the profile.

09 · Reuse

Subprograms

SubProceso defines a reusable routine. If it returns a value, the header names the variable that receives the result; otherwise, it performs actions without returning one. Call it by name with arguments in parentheses. Parameters can be inputs or, when the profile supports the form, passed by reference to return changes to the caller.

SubProceso resultado <- Doble(numero)
    resultado <- numero * 2
FinSubProceso
Proceso Principal
    Escribir Doble(6)
FinProceso

Local variables stay within the routine. The reference includes recursive calls, such as a power calculation, and passing arrays as arguments. Prefer value parameters for calculations that should not change the original variable; use references only when a routine truly needs to return a modification.

10 · Combined example

Average and result

Proceso Promedio
    Definir a, b, c, media Como Real
    Escribir "Enter three grades:"
    Leer a, b, c
    media <- (a + b + c) / 3
    Si media >= 7 Entonces
        Escribir "Approved: ", media
    Sino
        Escribir "Keep practicing: ", media
    FinSi
FinProceso

11 · Math library

Built-in functions

The functions below appear in PSeInt's basic reference. Write arguments in parentheses; assign, display, or combine the returned value in another expression.

FormResult
RC(x)Square root.
ABS(x)Absolute value.
LN(x), EXP(x)Natural logarithm and exponential function.
SEN(x), COS(x), ATAN(x)Trigonometric functions.
TRUNC(x), REDON(x)Integer part and nearest integer.
AZAR(n)Random integer from 0 through n - 1.
Longitud(texto)Number of characters.
SubCadena(texto, inicio, fin)Substring between the specified positions.

Definir radio, area Como Real
radio <- 3
area <- 3.14159 * radio ^ 2
Escribir "Area: ", REDON(area)
Escribir "Die: ", AZAR(6) + 1
Definir frase, minuscula Como Caracter
frase <- "Hola, Potoo!"
minuscula <- Minusculas(frase)
Escribir "Characters: ", Longitud(minuscula)
Escribir "Start: ", SubCadena(minuscula, 1, 3)
Escribir Concatenar("Text: ", minuscula)

Check the domain of each math function. String operations depend on the profile that enables them. This example starts indexes at 1, so adjust SubCadena to match the active profile.

12 · Syntax variants

Profiles and variants

The selected profile determines which spellings the interpreter accepts. PSeInt can require the original structured form, accept flexible variants, or use intermediate options set by an institution or teacher.

AspectWhat can varyRecommendation
Opening and closingProceso / FinProceso or alternatives such as Algoritmo / FinAlgoritmo.Keep each pair consistent.
DeclarationsA profile may require Definir or allow type inference.Declare data explicitly while learning.
SeparatorsRequired semicolons or line breaks between statements.Use one style throughout an algorithm.
ArraysDimension notation and starting index.Check the active profile's bounds.
LoopsPara i <- ... or Para Cada Elemento de Lista.Use the form enabled by the selected profile.
ConditionsOperators such as > or descriptive forms such as Es Mayor Que.Do not mix forms from different profiles.

An example valid in one profile may need changes in another. If a class or course provides a profile, use it as the authority for names, types, and syntax in that exercise.

13 · Problem solving

Testing and tracing

Before running an algorithm, identify its inputs, expected result, and conditions that can change its path. Then try simple values whose results you can calculate independently.

  • Test a normal case and boundary values such as zero, one item, and the largest expected input.
  • At each loop, watch the condition, counter, and variables that change.
  • For arrays, verify every index falls inside the declared dimension.
  • For a function, compare its arguments with the returned value and inspect each return path.

The interpreter can trace execution step by step and compare it with a flowchart. A trace helps locate the moment a variable stops matching the expected value; it does not replace choosing useful test cases.
