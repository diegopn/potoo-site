01 · Scope

About the dialect

Portugol is a name used by several pseudolanguages. This page covers the Portugol 2.0 dialect specifically; these rules do not define one universal standard for every pseudolanguage called Portugol.

The grammar and lexer used as the basis for this reference are listed in the references section. They guide the scope of the Portugol 2.0 dialect adopted by Potoo IDE.

Project goal: implement the complete dialect of this pseudolanguage. Features described here are not necessarily available to run in the app today.

02 · Organization

Program structure

A file starts with programa and a block enclosed in braces. Library includes appear at the beginning of the block; global declarations and functions may follow. The conventional entry point is a function named inicio.

programa {
    inclua biblioteca Matematica --> mat

    const inteiro tentativas = 3
    inteiro acertos = 0

    funcao inicio() {
        escreva("Welcome to the exercise")
    }
}

Functions, conditions and loops use { and } for blocks. Semicolons separate the three fields in a para header; common examples place one statement on each line without ending every statement with a semicolon.

03 · Writing

Names, comments and literals

  • Identifiers start with an ASCII letter or underscore; following characters may be ASCII letters, digits or underscores. The published grammar does not allow accented letters in identifiers.
  • Keywords are written without accents and the grammar recognizes their lowercase forms, such as programa, funcao and enquanto.
  • Line comments start with //; block comments are enclosed by /* and */.
  • Real numbers use a period as the decimal separator. Strings use double quotes and individual characters use single quotes; the lexer also defines escapes and hexadecimal literals.
  • Logical values are verdadeiro and falso.
// line comment
/* block
   comment */
cadeia mensagem = "Hello"
caracter inicial = 'A'
real media = 7.5
logico aprovado = verdadeiro

04 · Data

Types, variables and constants

TypeUse
inteiroWhole numbers.
realNumbers with a fractional part.

vazioMarks a function with no return value.

Place the type before the name. A declaration can group names of the same type and include an initial expression. The const keyword marks constant declarations. Values and types must be compatible.

inteiro idade = 18, ano
real altura = 1.72
const real pi_aproximado = 3.14
cadeia nome = "Lia"
logico concluiu = falso

A variable declared inside a function or block has local scope; declarations in the main program outside functions are global. Declarations also allow vector and matrix initializers, described in Vectors and matrices.

05 · Expressions

Operators and precedence

GroupOperatorsMeaning
Arithmetic+ - * / %Addition, subtraction, multiplication, division and remainder.
Unary+ - nao ~ ++ --Sign, logical negation, bitwise negation, increment and decrement. ++ and -- may appear before or after an identifier.
Assignment= += -= *= /=Simple and compound assignment. = is not the equality operator.

The official grammar defines operators through recursive alternatives, but it does not publish a clear precedence table for every combination. Use parentheses to make evaluation order explicit, especially when mixing comparisons, logic and bitwise operations.

Recommended practice: the grammar rule itself notes that equality has low priority, so do not rely on an assumed order in compound expressions.

06 · Interaction

Input and output

escreva displays one or more expressions. To start a new line, include the \n escape sequence in a string passed to it. leia reads values into variables. The predefined function limpa() clears the output area. Potoo IDE's independent crate also offers escreva_linha as its own convenience; it is not part of the official dialect.

programa {
    funcao inicio() {
        cadeia nome
        escreva("What is your name? ")
        leia(nome)
        escreva("Hello, ", nome, "!\n")
    }
}

The way data is displayed and read may depend on the library implementation or the environment that runs the algorithm. Potoo IDE does not yet provide these workflows in the app.

07 · Decisions

Conditions and selection

se runs a branch when a logical expression is true; senao defines the alternative branch. Blocks can contain multiple statements. Multiway selection uses escolha, caso labels and the fallback case contrario.

se (nota >= 7) {
    escreva("Passed\n")
} senao {
    escreva("Keep practicing\n")
}

escolha (opcao) {
    caso 1:
        escreva("Start\n")
        pare
    caso contrario:
        escreva("Unknown option\n")
}

pare ends the current escolha case or exits a loop. Use a logical expression as the condition.

08 · Loops

Repetition

The dialect defines conditional loops and a loop with initialization, condition and increment fields:

inteiro contador = 1
enquanto (contador <= 3) {
    escreva(contador, "\n")
    contador++
}

faca {
    contador--
} enquanto (contador > 0)

para (inteiro i = 0; i < 3; i++) {
    escreva(i, "\n")
}

enquanto checks before each repetition; faca ... enquanto checks after the block. In para, semicolons separate fields that can initialize a variable, check a condition and update a counter. pare exits the current loop.

09 · Collections

Vectors and matrices

Vectors use one index in square brackets; matrices use two. An explicit size must be a positive integer constant expression; in declarations with an initializer, the size can be inferred. The grammar also allows matrices initialized by rows.

programa {
    funcao inicio() {
        inteiro notas[3] = {8, 9, 10}
        inteiro quadro[2][2] = {{1, 2}, {3, 4}}
        escreva(notas[0], "\n")
        escreva(quadro[1][0], "\n")
    }
}

Indices are integer expressions. Function parameters can declare dimensions without fixed sizes, for example inteiro valores[] or inteiro tabela[][].

10 · Reuse

Functions and parameters

A function may declare its return type before its name; omitting the type means it returns no value, which may also be written as vazio. Parameters have a type and name, can be comma-separated, and may receive vectors or matrices. An & before the name marks a reference parameter.

funcao inteiro dobrar(inteiro valor) {
    retorne valor * 2
}

funcao atualizar(inteiro &total, inteiro acrescimo) {
    total += acrescimo
}

funcao inicio() {
    inteiro resultado = dobrar(4)
    atualizar(resultado, 1)
    escreva(resultado, "\n")
}

retorne ends the function and may return an expression. The official reference describes calls in expressions, functions with return values and functions without one.

12 · Example

Complete program

This example combines a declaration, input and output, a condition, a function and a logical expression:

programa {
    funcao logico eh_par(inteiro numero) {
        retorne numero % 2 == 0
    }

    funcao inicio() {
        inteiro valor
        escreva("Enter an integer: ")
        leia(valor)

        se (eh_par(valor)) {
            escreva("The number is even\n")
        } senao {
            escreva("The number is odd\n")
        }
    }
}

13 · Compatibility

What works in Potoo IDE today

Potoo IDE is in development and does not yet integrate the interpreter into the desktop app. This page is a reference for the intended dialect, not a list of features available in the application.

The Potoo IDE repository contains an independent crate for the Portugol 2.0 pseudolanguage. It implements a subset: program and function structure, declarations, types, vectors and matrices, value and reference parameters, operators, control flow, input and output, and parts of the Matematica, Texto, Tipos and Util libraries. The crate identifies itself as a partial implementation; libraries such as Calendario, Objetos and Arquivos are not implemented there.

In development: the goal is to work toward the complete dialect. Until it is integrated with the desktop interface, these examples cannot be written or run in Potoo IDE.
