01 · overview

About ΓΛΩΣΣΑ

ΓΛΩΣΣΑ is the programming notation taught in official Greek computer science materials. It provides an algorithm structure and a set of types, commands, and control structures for students to specify solutions.

The name does not refer to one software product. Third-party editors and simulators may implement subsets or their own conventions; for an exam or exercise, the normative source is the curriculum material assigned by the course.

Status in Potoo IDE: Glossa is under evaluation as an educational notation. This reference does not mean the app runs ΓΛΩΣΣΑ programs.

02 · curriculum context

Source and audience

The main source for this page is the computer science textbook published on the official Greek schoolbook portal. It presents algorithms, structured programming, and Greek syntax used in curriculum exercises.

Students use the notation to learn:

  • declaring and using typed variables;
  • sequence, selection, and repetition;
  • arrays and procedures or functions;
  • input and output;
  • planning, reading, and testing algorithms.

The schoolbook takes precedence over informal translations or third-party tools. Latin transliterations in explanations are only descriptive; Greek reserved words appear in examples.

03 · program structure

Program organization

A ΓΛΩΣΣΑ program marks its header, variable section, executable body, and closing. The following example follows the structure shown in the textbook and calculates the mean of two integers:

ΠΡΟΓΡΑΜΜΑ ΜΕΣΟΣΟΡΟΣ
ΜΕΤΑΒΛΗΤΕΣ
  ΑΚΕΡΑΙΕΣ: Α, Β
  ΠΡΑΓΜΑΤΙΚΕΣ: ΜΕΣΟΣ
ΑΡΧΗ
  ΔΙΑΒΑΣΕ Α, Β
  ΜΕΣΟΣ <- (Α + Β) / 2
  ΓΡΑΨΕ ΜΕΣΟΣ
ΤΕΛΟΣ_ΠΡΟΓΡΑΜΜΑΤΟΣ

ΠΡΟΓΡΑΜΜΑ names the program, ΜΕΤΑΒΛΗΤΕΣ starts declarations, ΑΡΧΗ opens the instructions, and ΤΕΛΟΣ_ΠΡΟΓΡΑΜΜΑΤΟΣ closes the program. Follow the course rules for typography and identifiers.

04 · data

Types, operators, and assignment

The schoolbook distinguishes types for integers, real values, characters, and logical values. Declarations group variables by type; assignment uses an arrow pointing to the variable receiving the value.

Greek formMeaning
ΑΚΕΡΑΙΕΣInteger variables.
ΠΡΑΓΜΑΤΙΚΕΣReal variables.
ΧΑΡΑΚΤΗΡΕΣCharacters or strings as defined in the material.
ΛΟΓΙΚΕΣLogical values.
<-Assigns the right-hand expression to the left-hand variable.

Expressions combine arithmetic, relational, and logical operations. Parentheses make calculation order explicit. Check the textbook’s tables for precedence, conversions, and type limits.

05 · interaction

Input and output

ΔΙΑΒΑΣΕ receives data for the variables listed and ΓΡΑΨΕ displays values or messages. These statements help separate interaction from the central calculation.

ΓΡΑΨΕ "Δώσε έναν αριθμό"
ΔΙΑΒΑΣΕ Α
ΤΕΤΡΑΓΩΝΟ <- Α * Α
ΓΡΑΨΕ ΤΕΤΡΑΓΩΝΟ

This fragment highlights Greek input and output commands. In a complete program, declare each variable in the proper section and follow the literal and identifier form used by the schoolbook. The Greek message can be replaced by another literal without changing the algorithm’s structure.

06 · control flow

Conditions and loops

ΓΛΩΣΣΑ includes selection and repetition structures suited to structured programming exercises. Selection chooses a block based on a condition; loops repeat instructions according to a count or condition. The textbook specifies each form’s reserved words and delimiters.

  • Simple or two-way selection: handle a case and optionally its alternative.
  • Multi-way selection: choose among several possible values.
  • Counted repetition: traverse a sequence of values.
  • Conditional repetition: continue while a condition holds or until one occurs.

A condition must produce a logical value. For each loop, identify the variable that changes and confirm that its bounds do not leave the final iteration outside the intended range.

ΑΝ ... ΤΟΤΕ ... ΑΛΛΙΩΣ ... ΤΕΛΟΣ_ΑΝThe condition is evaluated when the selection is reached.Chooses a block; the ΑΛΛΙΩΣ alternative is optional.
ΟΣΟ condition ΕΠΑΝΑΛΑΒΕ ... ΤΕΛΟΣ_ΕΠΑΝΑΛΗΨΗΣBefore each pass.Repeats while true; it may execute zero times.
ΑΡΧΗ_ΕΠΑΝΑΛΗΨΗΣ ... ΜΕΧΡΙΣ_ΟΤΟΥ conditionAfter the body.Repeats until the condition is true; it executes at least once.

07 · decomposition

Arrays and subprograms

The textbook also covers arrays and subprograms. An array stores elements of one type, accessed by index. Procedures group actions; functions produce a result. Parameters carry input values and, depending on the form taught, data that a routine updates.

When using an array, declare its dimension and check the index range set by the exercise. When defining a procedure or function:

  1. choose a name that describes its task;
  2. list parameters and their types;
  3. declare any needed local variables;
  4. specify the result or observable effect;
  5. test the routine on its own before combining it with the main program.

Read the adopted textbook edition for details on bounds, parameter passing, and full syntax.

08 · worked example

Average and classification

After calculating an average, a condition can classify the result. The threshold belongs to the problem statement; do not assume one universal passing rule.

ΑΝ ΜΕΣΟΣ >= ΟΡΙΟ ΤΟΤΕ
  ΓΡΑΨΕ "Επιτυχία"
ΑΛΛΙΩΣ
  ΓΡΑΨΕ "Προσπάθησε ξανά"
ΤΕΛΟΣ_ΑΝ

Insert this fragment in a program that has declared and calculated ΜΕΣΟΣ and defined the threshold ΟΡΙΟ. Trace both cases: an average below the threshold and one equal to or above it. Follow the official form if the course uses another conditional construct.

09 · study and checking

How to study and test

Start with the program format and add one construct at a time. Preserve Greek reserved words, since translations or transliterations may not be recognized by a tool.

  • Check declarations and types before evaluating an expression.
  • Use inputs whose answers can be calculated by hand.
  • Test conditions on both sides of a boundary.
  • For arrays, trace the minimum and maximum indices.
  • For subprograms, test representative and boundary arguments.

External tools may support different subsets, so compare their results with examples in the official textbook. A third-party implementation is a study aid, not the definition of the curriculum language.

10 · versions and scope

Scope and variants

ΓΛΩΣΣΑ is a curriculum notation. There is no single official software package defining the syntax used by every student tool. Content and presentation can vary between textbook editions and course instructions.

This reference describes central constructs in the school material consulted and keeps Greek keywords in examples. Confirm types, operators, subprograms, truth tables, and array rules in the edition assigned by your course. Glossa remains under evaluation in Potoo IDE.

11 · problem-solving method

From problem to algorithm

The curriculum textbook presents programming as a sequence of decisions: understand the problem, organize the data, formulate a solution, and check that it meets the prompt. ΓΛΩΣΣΑ gives students a shared notation for recording algorithms in exercises. The workflow below separates the solution's logic from writing details required by a particular edition or course.

StepQuestionRecord
UnderstandWhich data are provided? What must be calculated or decided?Inputs, expected result, and constraints in the prompt.
PlanWhich operations, decisions, and repetitions solve the task?A sequence of steps in plain language or the form taught in class.
TraceHow does each variable change for a known input?A state table with values before and after each operation.
CheckDoes the algorithm cover ordinary and boundary cases?Results worked out by hand for comparison with a run or textbook example.

For the two-value average example, use Α=12 and Β=18. After ΔΙΑΒΑΣΕ, the table records 12 and 18; after the assignment, ΜΕΣΟΣ is 15; ΓΡΑΨΕ displays that result. A second test should use different values. If an exercise permits fractional averages, check that the declared types and division produce the expected precision.

An execution table also helps locate faults. If the output is wrong, first check the values read, then each calculation, and finally the condition or repetition that chooses a path. Change one part at a time and trace it again.

12 · practice sequence

Learning and debugging sequence

The school material's contents move from basic concepts to structures used in larger problems, including arrays, stacks, queues, search, sorting, and recursion. The sequence below uses those topics to plan exercises; it does not replace the definitions and examples in the adopted edition.

TopicPractice taskWhat to check
Types and input/outputRead values and display a simple calculation.Declarations, units, values read, and expected result.
Selection and repetitionCount how many values meet a condition.No matches, one match, and the exact loop boundary.
ArraysFind the minimum, maximum, or average of a collection.Dimension, index range, and processing every element.
Stacks and queuesSimulate a short sequence of insertions and removals.The order items enter and leave and the state after each operation.
Search and sortingFind a value and sort a few elements.Empty or single-item input, duplicates, and boundary positions.
RecursionSolve a small case through successive calls.Base case, reduction of the problem, and each call's return value.

Common errors

  • Uninitialized data: check that each variable receives a value before use.
  • Wrong boundary: test the condition when a value equals the limit, not only above or below it.
  • Loop without progress: confirm that the instructions change the variable or state controlling repetition.
  • Out-of-range array access: compare each index with the range set by the exercise and course edition.
  • Recursion that does not stop: check that each call moves its input toward the base case.

Third-party tools may interpret different conventions. When debugging, record the textbook edition, reproduce its examples, and compare the sequence of states before deciding that a tool reflects the curriculum rule. For assessments, use the notation specified by the teacher or exam.

Technical reference

A complete algorithm and its execution trace

This example adds the odd numbers from 1 to 9. It uses the program header, variable section, counted loop, and output command shown in the schoolbook:

ΠΡΟΓΡΑΜΜΑ ΑΘΡΟΙΣΜΑ_ΠΕΡΙΤΤΩΝ
ΜΕΤΑΒΛΗΤΕΣ
  ΑΚΕΡΑΙΕΣ: Ι, ΑΘΡΟΙΣΜΑ
ΑΡΧΗ
  ΑΘΡΟΙΣΜΑ <- 0
  ΓΙΑ Ι ΑΠΟ 1 ΜΕΧΡΙ 9 ΜΕ_ΒΗΜΑ 2
    ΑΘΡΟΙΣΜΑ <- ΑΘΡΟΙΣΜΑ + Ι
  ΤΕΛΟΣ_ΕΠΑΝΑΛΗΨΗΣ
  ΓΡΑΨΕ ΑΘΡΟΙΣΜΑ
ΤΕΛΟΣ_ΠΡΟΓΡΑΜΜΑΤΟΣ

A step size of 2 visits only odd numbers. The sum starts at zero, adds the current value of Ι, and then the counter advances. The table records the state after each loop body:

IterationΙΑΘΡΟΙΣΜΑ after addition
111
234
359
4716
5925

The displayed result is 25. To check the boundary, start the counter at 1 and record each value as it advances by the given step until it reaches the limit; for input values, also test a case where the loop should not run. In a condition-controlled loop, record the condition before and after the body; in an array, record both indexes and the row or region already traversed. A state table helps locate an error at the first incorrect transition without depending on specific software.

The curriculum also introduces Greek mathematical functions, such as ΗΜ, ΣΥΝ, ΕΦ, Τ_Ρ, ΛΟΓ, Ε, Α_Μ, and Α_Τ. Consult the table in the assigned edition to confirm each operation and its units, especially for trigonometric functions. ΓΛΩΣΣΑ is taught through curriculum materials; this reference does not imply a single interpreter or claim that this example runs in Potoo IDE.
