01 · Overview

About Calango

Calango is a pseudolanguage and learning environment for algorithms. Its Portuguese commands keep attention on steps, conditions, and data before learners move on to the syntax of other languages. Materials from the University of Brasília describe its educational use, interpreted execution, and step-by-step debugging.

This reference combines that teaching purpose with the Calango structures described in the sources at the end of the page.

02 · Organization

Algorithm structure

The header uses algoritmo, followed by an identifier and semicolon. The executable block sits between principal and fimPrincipal. Declare variables at the beginning of the main block or a function/procedure, before commands; declarations cannot include an initial value.

algoritmo boasVindas;
principal
    texto nome;
    // Ask first, then read
    escreva("What is your name?");
    leia(nome);
    escreval("Hello, ", nome);
fimPrincipal

Calango accepts line comments starting with // and block comments between /* and */. Simple statements end with a semicolon. Assign a value before reading a variable.

03 · Data

Types, variables, and vectors

Write the type before the name: inteiro, real, logico, caracter, or texto. Use verdadeiro and falso for logical values, single quotes for characters, and double quotes for text. Real numbers use a decimal point. The interpreter converts between integers and reals; assigning a real to an integer discards the fractional part.

inteiro quantity;
real price;
logico available;
caracter initial;
texto title;
inteiro grades[5];

quantity = 3;
price = 2.5;
available = verdadeiro;
initial = 'A';
title = "Algorithms";
grades[0] = 10;

Vectors and matrices have a fixed size and use integer indices starting at zero. Thus, grades[5] has positions from grades[0] through grades[4]. Matrices have two dimensions. Vectors are passed to routines by reference, so changes inside a routine affect the original vector.

04 · Expressions

Assignment, operators, and precedence

Use = for assignment and == for equality in a condition. Use != or <> for inequality, as well as <, <=, >, and >=. The + operator adds numbers or concatenates text.

CategoryOperatorsUse
Arithmetic+ - * / \ % modNumeric operations, integer division, and remainder.
Comparison== != <> < <= > >=Produce a logical value.
Logicalnao ! e ouNegate or combine conditions.

Precedence runs from unary operators to multiplication, division, integer division, and remainder; then addition and subtraction, comparisons, and finally e and ou at the same level. Operators at the same level are evaluated left to right. Parentheses make the intended order explicit.

real total;
total = price * quantity;
se ((quantity > 0) e available) entao
    escreval("Total: ", total);
fimSe

05 · Interaction

Input and output

leia(...) reads a value; leiaCaracter(...) reads a character. escreva(...) displays output without adding a line break, while escreval(...) ends with one. Comma-separated arguments are written in sequence, with no spaces inserted automatically. limpaTela() clears the output area.

texto nome;
inteiro idade;
escreva("Name: ");
leia(nome);
escreva("Age: ");
leia(idade);
escreval("Hello, ", nome, " — ", idade, " years old.");

To format a real number in output, use value:width:decimals. Width is a minimum; the number is right-aligned, and decimal places are rounded or padded with zeros.

real average;
average = 7.5;
escreval("Average: ", average:6:2);

06 · Decisions

Conditions and choice

se, senaoSe, and senao form a conditional branch, which ends with fimSe. In escolha, compare an integer or character expression with caso alternatives; outroCaso handles values that do not match.

se (grade >= 7) entao
    escreval("Passed");
senaoSe (grade >= 5) entao
    escreval("Review period");
senao
    escreval("Not passed");
fimSe

escolha option
    caso 1
        escreval("New exercise");
        interrompa;
    caso 2
        escreval("Review the material");
        interrompa;
    outroCaso
        escreval("Unknown option");
fimEscolha

Cases continue in sequence until interrompa. Include it to exit the choice after a matching alternative; without it, execution continues through later cases. Conditions must produce a logical value.

07 · Repetition

Enquanto, faça-enquanto, and para

enquanto checks its condition before running and may skip the body. faca ... enquanto checks afterward, so it runs at least once. para traverses values from start through end, inclusive; specify a step, which cannot be zero. interrompa; exits the innermost loop.

inteiro i;
i = 1;
enquanto (i <= 3) faca
    escreval(i);
    i = i + 1;
fimEnquanto

faca
    escreva("Enter a positive value: ");
    leia(i);
enquanto (i <= 0);

para i de 1 ate 3 passo 1 faca
    escreval(i);
fimPara

Update values used by a loop condition so it can eventually end. The explicit para step determines how the sequence advances or retreats.

08 · Reuse

Functions, procedures, and parameters

A function declares its return type before its name and ends with fimFuncao; retorna provides the result. A procedure returns no value and ends with fimProcedimento. Parameters specify a type and name in the order expected by the call. They are passed by value by default; use ref when the routine should change the original variable. Vectors are passed by reference automatically.

funcao inteiro doubleValue(inteiro value)
    retorna value * 2;
fimFuncao

procedimento addTo(ref inteiro total, inteiro value)
    total = total + value;
fimProcedimento

principal
    inteiro sum;
    sum = doubleValue(4);
    addTo(sum, 2);
    escreval(sum);
fimPrincipal

Declare local variables at the beginning of a routine. Calls pass arguments by position; a function can be used in an expression, while a procedure is called as a statement.

09 · Standard features

Built-in functions

Calango includes functions for mathematics, text, and characters. Use them in expressions, assign their results to variables, or include them directly in output.

GroupFunctionsBehavior
Mathabs(n), exp(base, expoente), raizQuadrada(n), aleatorio(limite), piAbsolute value, power, square root, random integer from zero to limit minus one, and the constant π. The square root requires a non-negative value and the random limit must be positive.
Textmaiusculo(t), minusculo(t), tamanhoTexto(t), copia(t, inicio, fim), caracterTexto(t, pos), comparaTexto(a, b)Change case, count characters, extract a range with inclusive positions starting at zero, get a character by index, or compare strings lexicographically and return a negative, zero, or positive value according to their order.
CharactersmaiusculoCaracter(c), minusculoCaracter(c), asciiCaracter(n), caracterAscii(c)Change case; asciiCaracter(n) returns the character for an ASCII code (0 through 127), while caracterAscii(c) returns its numeric code.
texto name;
name = "Calango";
escreval(maiusculo(name));
escreval(raizQuadrada(81));

10 · In practice

Complete example

This program reads three grades, calculates the average, and reports a result using a vector, loop, and condition.

algoritmo classAverage;
principal
    inteiro i;
    real grades[3];
    real sum;
    sum = 0;
    para i de 0 ate 2 passo 1 faca
        escreva("Grade: ");
        leia(grades[i]);
        sum = sum + grades[i];
    fimPara
    se (sum / 3 >= 7) entao
        escreval("Passed");
    senao
        escreval("Keep studying");
    fimSe
fimPrincipal
