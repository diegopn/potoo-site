01 · Overview

About Calango

Calango is a pseudolanguage and learning environment for algorithms. Its Portuguese commands keep attention on steps, conditions, and data before learners move on to the syntax of other languages. Materials from the University of Brasília describe its educational use, interpreted execution, and step-by-step debugging.

This reference combines that teaching purpose with the Calango structures described in the sources at the end of the page.

02 · Organization

Algorithm structure

The header uses algoritmo, followed by an identifier and semicolon. The executable block sits between principal and fimPrincipal. Declare variables at the beginning of the main block or a function/procedure, before commands; declarations cannot include an initial value.

algoritmo boasVindas;
principal
    texto nome;
    // Ask first, then read
    escreva("What is your name?");
    leia(nome);
    escreval("Hello, ", nome);
fimPrincipal

Calango accepts line comments starting with // and block comments between /* and */. Simple statements end with a semicolon. Assign a value before reading a variable.

03 · Data

Types, variables, and vectors

Calango uses five scalar types. A declared type determines which values and operations make sense; an identifier names a variable or collection during execution.

TypeDeclaration and exampleUse and notes
inteirointeiro idade;
idade = -18;		Counts, positions, and values without a fractional part.
realreal altura;
altura = 1.72;		Measurements and fractional calculations. Write decimals with a period.
logicologico ativo;
ativo = verdadeiro;		Only verdadeiro or falso; use it in conditions.
caractercaracter inicial;
inicial = 'A';		One character in single quotes; distinguish it from text. In the Potoo interpreter, a character literal must fit in one UTF-16 code unit.
textotexto nome;
nome = "Lia";		A sequence in double quotes. In the Potoo implementation, compare text with comparaTexto(a, b).

Declare the type before the identifier and end the declaration with a semicolon. One declaration can group identifiers of the same type, separated by commas, as in inteiro day, month, year;. The syntax does not accept an initializer on the same line; in the Potoo interpreter, the variable receives its type’s default value. For predictable results, assign an intentional value before using it; otherwise the implementation uses the type default. Real literals use a decimal point, for example 0.5; logical values are reserved words.

Type compatibility

Documentation and interpreters can adopt different conversion rules. The interpreter integrated with Potoo accepts assigning an inteiro to a real; the reverse assignment is incompatible and does not silently discard the decimal part. There is no general real-to-integer conversion: choose the variable type and operation deliberately.

Source typeTarget typeRule in the Potoo interpreter
inteirorealAccepted and represented as a real number.
realinteiroIncompatible; it is not truncated or rounded automatically.
Different typesAny other typeRequire compatibility; do not assume automatic conversions.

The Potoo interpreter uses signed 64-bit integers and detects overflow in integer operations, reporting an error instead of wrapping around. The real type uses 64-bit floating point, so some decimals are approximations. These are rules of this implementation, not universal limits for every Calango version.

Vectors and matrices

A homogeneous collection stores multiple values of the same type under one identifier. The number in brackets is the number of positions, not the last index. Vectors have one dimension; matrices add another. When a size is written in brackets, that dimension has a fixed number of positions.

FormExampleHow to read it
Scalar variablereal altura;Stores one real value.
Vectorreal alturas[5];Stores five real values; indices run from 0 to 4.
Matrixinteiro assentos[3][4];Stores three rows and four columns; row indices run from 0 to 2 and column indices from 0 to 3.
Accessalturas[i]
assentos[linha][coluna]		Read or change one position; each integer index must be inside its matching dimension.
inteiro i;
real alturas[5];
para i de 0 ate 4 passo 1 faca
    escreva("Height: ");
    leia(alturas[i]);
fimPara

Indices start at zero. A vector of size five contains positions alturas[0] through alturas[4]; alturas[5] attempts to access a sixth position. In a matrix, check every dimension independently.

Case for a vector of size 5Index or traversalResult
First positionalturas[0]Valid.
Last positionalturas[4]Valid.
Before the startalturas[-1]Invalid index.
One past the endalturas[5]Invalid index; the size is not a valid index.
Full traversalpara i de 0 ate 4 passo 1Visits all five positions because para bounds are inclusive.

In the Potoo interpreter, declarations and collection elements start with default values: zero, real zero, false, a character with code zero, or empty text, according to their type. Still initialize every position before relying on a calculated value. Vectors are passed to routines by reference: a change to a vector parameter is also visible to the calling algorithm.

04 · Expressions

Assignment, operators, and precedence

Use = for assignment and prefer == to compare equality. The interpreter integrated with Potoo also accepts = as equality in expressions and != for inequality; it does not accept <> as an alias. Relational comparisons use <, <=, >, and >=. Use nao for logical negation; ! is not a unary operator in this implementation. The + sign adds numbers and can also concatenate characters and text.

CategoryAccepted formsUse
Arithmetic+ - * / \ % modAddition, subtraction, multiplication, division, integer division, and remainder.
Equality== (=) !=Produce a logical value; this implementation also accepts = for equality.
Relational< <= > >=Compare order and limits.
Logicalnao e ouNegate, combine, or alternate logical conditions.

The result also depends on operand types. In the Potoo interpreter, / performs real division; \ truncates the quotient toward zero; % and mod calculate the remainder. Division by zero causes an error.

ExpressionResultWhy
7 + 2 * 313Multiplication happens before addition.
7 / 23.5The slash performs real division.
7 \ 23The backslash calculates the integer quotient.
-7 \ 2-3The quotient is truncated toward zero.
7 mod 21The remainder is what is left after integer division.

Use parentheses when an expression could be read in more than one way. The precedence used by the integrated interpreter is:

OrderOperatorsExample
1 · highestUnary: nao, -nao ativo

3+ -10 - 3 + 1

7 · lowestouerro ou ausente

Operators at the same level group from left to right. When combining comparisons and logic, put each comparison in parentheses to make the intended order clear.

inteiro quantidade;
real preco;
real total;
quantidade = 3;
preco = 2.5;
total = preco * quantidade;
se ((quantidade > 0) e (total >= 5)) entao
    escreval("Total: ", total);
fimSe

The inteiro type has a finite range in this implementation. Overflow in an integer operation produces a diagnostic; division by zero and a non-finite real result are runtime errors. Choose a suitable type and validate the input domain before calculating.

05 · Interaction

Input and output

leia(...) reads a value; leiaCaracter(...) reads a character. escreva(...) displays output without adding a line break, while escreval(...) ends with one. Comma-separated arguments are written in sequence, with no spaces inserted automatically. limpaTela() clears the output area.

texto nome;
inteiro idade;
escreva("Name: ");
leia(nome);
escreva("Age: ");
leia(idade);
escreval("Hello, ", nome, " — ", idade, " years old.");

To format a real number in output, use value:width:decimals. Width is a minimum; the number is right-aligned, and decimal places are rounded or padded with zeros.

real average;
average = 7.5;
escreval("Average: ", average:6:2);

06 · Decisions

Conditions and choice

se, senaoSe, and senao organize decisions using logical conditions; the structure ends with fimSe. Use escolha to compare an option with caso alternatives and, when needed, an outroCaso branch.

se (grade >= 7) entao
    escreval("Passed");
senaoSe (grade >= 5) entao
    escreval("Review period");
senao
    escreval("Not passed");
fimSe

escolha option
    caso 1
        escreval("New exercise");
    caso 2
        escreval("Review the material");
    outroCaso
        escreval("Unknown option");
fimEscolha

se conditions are checked in order, and only the first true branch runs. In the interpreter integrated with Potoo, escolha runs the body of the first matching caso and exits the structure; it does not continue automatically through later cases. interrompa exits the innermost loop, not escolha; outside a loop, this implementation reports an error.

FormWhen to useFlow in the Potoo interpreter
se ... senaoSe ... senaoTest conditions in order.Runs the first true branch and skips the others.
escolha ... caso ... outroCasoSelect among discrete alternatives.Runs only the first matching case or outroCaso.
interrompa;Exit a repetition early.Leaves the innermost loop; it does not replace fimEscolha.

Before running a decision, list the possible values and confirm that each reaches the expected branch. Include outroCaso when an unexpected option needs explicit handling.

07 · Repetition

Enquanto, faça-enquanto, and para

enquanto checks its condition before running and may skip the body. faca ... enquanto checks afterward, so it runs at least once. para traverses values from start through end, inclusive; specify a step, which cannot be zero. interrompa; exits the innermost loop.

inteiro i;
i = 1;
enquanto (i <= 3) faca
    escreval(i);
    i = i + 1;
fimEnquanto

faca
    escreva("Enter a positive value: ");
    leia(i);
enquanto (i <= 0);

para i de 1 ate 3 passo 1 faca
    escreval(i);
fimPara

Update values used by a loop condition so it can eventually end. The explicit para step determines how the sequence advances or retreats.

08 · Reuse

Functions, procedures, and parameters

A function declares its return type before its name and ends with fimFuncao; retorna provides the result. A procedure returns no value and ends with fimProcedimento. Parameters specify a type and name in the order expected by the call. They are passed by value by default; use ref when the routine should change the original variable. Vectors are passed by reference automatically.

funcao inteiro doubleValue(inteiro value)
    retorna value * 2;
fimFuncao

procedimento addTo(ref inteiro total, inteiro value)
    total = total + value;
fimProcedimento

principal
    inteiro sum;
    sum = doubleValue(4);
    addTo(sum, 2);
    escreval(sum);
fimPrincipal

Declare local variables at the beginning of a routine. Calls pass arguments by position; a function can be used in an expression, while a procedure is called as a statement.

texto palavra;

For "Calango", positions 1 through 3 contain "ala", and position 0 contains 'C'. The call aleatorio(6) can return any integer from 0 to 5; do not use the limit as though it were an inclusive final index.

Text positions in the Potoo interpreter count UTF-16 code units, not visible graphemes. Some supplementary-plane symbols occupy two units; if copia splits that pair, it raises an error. Check boundaries before extracting text containing those symbols. convTextoCaract creates one position per UTF-16 unit; convCaractTexto errors if the vector does not form a valid sequence.

10 · In practice

Complete example

The program reads three grades, rejects values outside 0 to 10, and calculates the average, lowest grade, and highest grade. The number of readings is fixed, so the final division cannot use a zero divisor.

algoritmo gradeAnalysis;
principal
    inteiro i;
    real grades[3];
    real sum;
    real average;
    real lowest;
    real highest;
    sum = 0;
    para i de 0 ate 2 passo 1 faca
        faca
            escreva("Grade from 0 to 10: ");
            leia(grades[i]);
        enquanto ((grades[i] < 0) ou (grades[i] > 10));
        sum = sum + grades[i];
        se (i == 0) entao
            lowest = grades[i];
            highest = grades[i];
        senao
            se (grades[i] < lowest) entao
                lowest = grades[i];
            fimSe
            se (grades[i] > highest) entao
                highest = grades[i];
            fimSe
        fimSe
    fimPara
    average = sum / 3;
    escreval("Average: ", average:6:2);
    escreval("Lowest grade: ", lowest:6:2);
    escreval("Highest grade: ", highest:6:2);
    se (average >= 7) entao
        escreval("Passed");
    senaoSe (average >= 5) entao
        escreval("Review period");
    senao
        escreval("Not passed");
    fimSe
fimPrincipal

The faca ... enquanto loop reads at least once and repeats while the grade is outside the range. The endpoints 0 and 10 are accepted. Because para includes its final bound, indices 0, 1, and 2 visit exactly the vector's three positions.

InputCheckAction
0Within 0 to 10.Accepted.
10Within 0 to 10.Accepted.
-0.1Below 0.Prompts for the same grade again.
10.1Above 10.Prompts for the same grade again.

With inputs 8, 4.5, and 9, the trace is:

Index iGrade readSum after readingLowestHighest
08888
14.512.54.58
2921.54.59

The average is 21.5 / 3 = 7.166…, displayed as 7.17, so the result is a pass. The trace also helps locate errors: if the sum is correct but the lowest or highest value is wrong, inspect the comparisons; if a position is missing, check the loop's bound and step.

11 · runtime semantics

Trace loops, choice, and parameters

In Calango, small differences in test position and parameter passing change the output. Use the table to choose a construct and predict how many times its body runs:

FormWhen it tests or advancesConsequence
enquanto (condition) faca ... fimEnquantoTests before the body.May run zero times. The condition must eventually become false.
faca ... enquanto (condition);Tests after the body.Runs at least once; use it when the first action must happen before validation.
para i de start ate end passo n faca ... fimParaAdvances by the step and includes the final bound when the sequence reaches it.Useful for a known count; step zero is invalid. For a descending traversal, use a negative step as supported by the implementation.
interrompa;Runs where it appears.Exits the innermost loop; it does not exit escolha.
escolha ... casoCompares the expression with cases in written order.Only the first matching case runs; execution does not fall through to later cases.

Compare pass-by-value and pass-by-reference with a routine that updates an accumulator:

procedimento acrescentar(ref inteiro total, inteiro valor)
    total = total + valor;
fimProcedimento

principal
    inteiro pontos;
    pontos = 10;
    acrescentar(pontos, 3);
    escreval(pontos);
fimPrincipal

The output is 13: total refers to the variable pontos, while valor receives a copy of argument 3. Without ref, an assignment to a scalar parameter changes only the local copy. Vectors behave differently: they are passed by reference automatically, so a routine can modify their elements. In the Potoo interpreter, a parameter with an empty dimension, such as inteiro values[], accepts vectors of different sizes; a parameter with an explicit size, such as inteiro values[5], requires that size.

ParameterCall behaviourEffect to expect
Scalar without refReceives the argument's value.Changing the parameter does not replace the caller's variable.
Scalar with refRefers to the supplied variable.Assignments to the parameter change the original variable.
VectorPassed by reference automatically.Element changes can be observed after the call returns.
Functionretorna supplies a value.The call can appear in an assignment or expression.
ProcedureRuns commands without a returned value.Call it as a statement and trace effects such as updates and output.

Output formatting also matters when debugging: escreva adds neither a line break nor spaces between arguments; escreval adds the final line break. In the Potoo interpreter, assigning real to inteiro is incompatible; the fractional part is not truncated automatically. Test values just below and above a boundary, and record each parameter before the call and after it returns; this separates formula errors from control-flow and data-passing errors.

12 · Interpreter

Calango interpreter in Potoo IDE

Potoo IDE runs Calango through an interpreter library maintained in its own repository. It covers the algoritmo/principal structure, typed data, vectors, expressions, decisions, loops, functions, and procedures.

The app provides input and output. The interpreter also provides line-and-column diagnostics, cancellation, and debugging events; its repository includes a terminal runner without an interactive debugger. It implements a subset with its own rules, identified in the sections on types, operators, and escolha.
