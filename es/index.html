01 · La propuesta

Un comienzo más claro para la lógica

Potoo IDE quiere dar a quienes empiezan un lugar sencillo para experimentar con algoritmos. La idea es reunir escritura, explicaciones y resultados en una interfaz de escritorio, sin convertir el aprendizaje en un conjunto de herramientas desconectadas.

Para quiénEstudiantes y docentes

Un espacio de apoyo para aprender y enseñar los fundamentos de la programación.

EnfoqueLógica antes que sintaxis

Los pseudolenguajes ayudan a centrar la atención en los pasos del algoritmo.

FormatoAplicación de escritorio

Una IDE nativa prevista para Linux, Windows y macOS.

03 · Cómo podría funcionar

Cuatro pasos para explorar una idea

Este flujo describe la experiencia que Potoo IDE busca ofrecer, no funciones disponibles hoy.

01

Elige el lenguaje

Empieza con el pseudolenguaje de tu clase o estudio.

02

Escribe el algoritmo

Ordena los pasos en el editor y céntrate en la lógica.

03

Entiende el siguiente paso

Consulta la ayuda contextual para aclarar una línea o concepto.

04

Lee el resultado

Usa la salida y los paneles previstos para seguir la ejecución.

↗Flujo en planificación. El editor, la ejecución de código y la depuración aún no están disponibles.

04 · Lenguajes

Diseñado en torno al pseudocódigo

El alcance se está definiendo con cuidado para que cada integración respete su propio proyecto y licencia.
