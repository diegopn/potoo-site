Karel the Robot

Esta página documenta la referencia Java de Karel mantenida por Stanford. Karel aparece en varias implementaciones educativas; los comandos y las reglas pueden variar entre ellas. Los ejemplos siguientes usan la sintaxis y los recursos del material Java de Stanford.

01 · Visión general

Sobre Karel

Karel es un robot que recibe instrucciones para resolver tareas sencillas en un mundo de calles, esquinas y paredes. El modelo fue creado para que los primeros ejercicios de programación destaquen la descomposición de problemas y la secuencia de instrucciones.

Esta página elige la referencia Java de Stanford, que define una clase de programa y un método run. Otras implementaciones pueden usar Python o una sintaxis propia; no mezcles ejemplos de versiones distintas.

02 · Entorno

El mundo en cuadrícula

El robot ocupa una esquina, mira hacia una de las cuatro direcciones y puede cargar o dejar beepers. Las paredes bloquean el movimiento entre esquinas. Cada ejercicio establece el estado inicial del mundo y el estado que debe alcanzar el programa.

  • Posición: esquina de la cuadrícula ocupada por el robot.
  • Dirección: norte, sur, este u oeste.
  • Beepers: marcadores que el robot puede recoger y dejar.
  • Paredes: obstáculos que bloquean el paso.

Intentar atravesar una pared, recoger un beeper inexistente o dejar uno sin tenerlo en la bolsa causa un error del entorno.

03 · Organización

Estructura del programa

Un programa Java de Karel declara una clase que extiende SuperKarel. El método público run() contiene las instrucciones iniciales; también se pueden declarar métodos privados para dar nombre a secuencias reutilizables.

import stanford.karel.*;

public class EjemploKarel extends SuperKarel {
    public void run() {
        move();
        turnLeft();
    }
}

El código usa bloques entre llaves, punto y coma al final de las instrucciones y comentarios Java con // o /* ... */.

04 · Acciones

Comandos básicos

ComandoAcción
move()Avanza una esquina si no hay una pared delante.
turnLeft()Gira 90 grados a la izquierda.
putBeeper()Deja un beeper en la esquina actual.
pickBeeper()Recoge un beeper de la esquina actual.
turnRight()Gira 90 grados a la derecha; lo proporciona SuperKarel.
turnAround()Gira 180 grados; lo proporciona SuperKarel.

Los comandos primitivos se llaman con paréntesis vacíos y punto y coma. Las acciones con beepers dependen del contenido de la esquina y de la bolsa del robot.

05 · Observación

Sensores y condiciones

Karel no recibe todo el mapa como un valor. Consulta condiciones locales para decidir su siguiente acción.

CondiciónEs verdadera cuando
frontIsClear()No hay una pared inmediatamente delante.
leftIsClear(), rightIsClear()El camino indicado está libre.
beepersPresent()Hay al menos un beeper en la esquina actual.
noBeepersPresent()No hay beepers en la esquina actual.
facingNorth(), facingEast(), facingSouth(), facingWest()El robot mira hacia la dirección indicada.

Las condiciones se escriben entre paréntesis y se combinan con operadores booleanos de Java.

06 · Flujo

Decisiones y repeticiones

La referencia Java usa if, if/else, while y for para responder a las condiciones del mundo y repetir acciones.

if (frontIsClear()) {
    move();
} else {
    turnLeft();
}
while (beepersPresent()) {
    pickBeeper();
}
for (int i = 0; i < 3; i++) {
    move();
}

Un bucle basado en un sensor debe cambiar el mundo o la posición del robot para alcanzar la condición de salida. Revisa las paredes y beepers del escenario antes de ejecutar la secuencia.

07 · Reutilización

Métodos propios

Un método privado da nombre a una acción compuesta. Después de declararlo en la clase, puede llamarse desde run() u otros métodos de esa clase.

private void turnRightSafely() {
    turnLeft();
    turnLeft();
    turnLeft();
}
public void run() {
    move();
    turnRightSafely();
    move();
}

Este método usa tres giros a la izquierda, el comando primitivo de la referencia básica. Si SuperKarel está disponible, turnRight() expresa directamente esa acción.

08 · Estado

Estado y datos

El problema puede resolverse solo con posición, dirección, paredes y beepers, pero la referencia Java también permite variables locales y contadores. El robot mantiene el estado físico del mundo; las variables ayudan a registrar pasos o cantidades.

int pasos = 0;
while (frontIsClear()) {
    move();
    pasos++;
}
putBeeper();

Usa estado adicional cuando ayude a describir la solución. Muchos ejercicios iniciales se resuelven con sensores y métodos bien nombrados.

09 · Ejemplo integrado

Avanzar y marcar la esquina final

El programa avanza hasta encontrar una pared y deja un beeper en la posición final si todavía no hay uno:

import stanford.karel.*;

public class MarcarDestino extends SuperKarel {
    public void run() {
        while (frontIsClear()) {
            move();
        }
        if (noBeepersPresent()) {
            putBeeper();
        }
    }
}
