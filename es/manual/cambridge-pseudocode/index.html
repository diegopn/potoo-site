01 · panorama

Qué es el pseudocódigo Cambridge

El pseudocódigo Cambridge es una convención para presentar algoritmos en cursos y evaluaciones de informática. Las palabras clave en inglés y los bloques delimitados hacen visible el flujo de control sin exigir un lenguaje de programación ejecutable.

La guía para docentes especifica las formas esperadas en las respuestas y el material del curso. En las preguntas de examen, utiliza la notación de Cambridge International aunque conozcas mejor otro lenguaje.

Estado en Potoo IDE: la notación está en evaluación. Que exista este manual no significa que la aplicación ejecute programas escritos en ella.

02 · contexto de evaluación

Guías y años de examen

Cambridge International publica guías de pseudocódigo vinculadas a sus programas de estudio. La edición aplicable depende del año del examen; las actualizaciones pueden cambiar ejemplos, reglas o recomendaciones para docentes.

Para los exámenes de 2026, esta página sigue la guía de 2026. La guía publicada para 2027–2029 se aplica a los exámenes de esos tres años. Compara el año de tu evaluación con la portada del PDF antes de preparar respuestas; no apliques una edición posterior de forma retroactiva a un examen anterior.

El pseudocódigo busca que la escritura de algoritmos sea legible y coherente para quien responde y quien corrige, no definir un entorno de ejecución.

03 · datos

Declaraciones, tipos y asignación

La guía representa las declaraciones con DECLARE, el nombre del identificador, dos puntos y el tipo. La asignación utiliza una flecha que apunta a la variable. Entre los tipos habituales se incluyen enteros, reales, caracteres, cadenas y valores booleanos.

DECLARE mark : INTEGER
DECLARE passed : BOOLEAN
mark ← 72
passed ← mark >= 50
TipoUso habitual
INTEGERValores enteros.
REALValores numéricos con fracción.
CHAR / STRINGUn carácter o una secuencia de texto.
BOOLEANCondiciones verdaderas o falsas.

La guía también especifica la declaración de arreglos y otras estructuras necesarias según el curso. Escribe los tipos y límites tal como aparecen en el documento vigente.

04 · entrada y salida

Leer y mostrar datos

INPUT recibe un valor y OUTPUT muestra texto o un resultado. En una respuesta escrita, indica cada operación de entrada y salida para que la interacción del algoritmo quede clara.

DECLARE name : STRING
INPUT name
OUTPUT "Hello, ", name

Al seguir la salida, respeta el orden de los argumentos y las convenciones de la guía para separarlos o unirlos. No confundas la notación de evaluación con la sintaxis de lectura de una consola concreta.

05 · flujo de control

Selección y bucles

Las palabras de control indican el inicio y el fin de cada bloque. El pseudocódigo Cambridge incluye selección con IF, alternativas y selección múltiple, además de los bucles FOR, WHILE y REPEAT.

IF mark >= 50 THEN
    OUTPUT "Pass"
ELSE
    OUTPUT "Retry"
ENDIF

En un bucle FOR, indica el intervalo y la dirección del contador; la condición de WHILE se evalúa antes del cuerpo; en REPEAT, comprueba que la condición se evalúe después de las instrucciones tal como indica la guía. Escribe correctamente todos los delimitadores de cierre.

06 · colecciones

Arreglos y estructuras

Los arreglos almacenan varios valores de un tipo y se accede a ellos por índice. La guía permite declarar dimensiones y límites; no presupongas que todos empiezan en cero o en uno sin leer la declaración.

El pseudocódigo también documenta registros y estructuras de datos cuando los requiere el nivel del curso. Para cada colección:

  • anota el tipo y las dimensiones;
  • comprueba que cada índice esté dentro de los límites;
  • distingue el tamaño del arreglo de la posición actual;
  • al recorrerlo, verifica el primer y el último valor del contador.

Las respuestas de examen deben mantener los mismos límites en la declaración, los accesos y el bucle.

ElementoLecturaComprobación
Declaración ARRAY[1:5]Límites inclusivos de 1 a 5.Hay cinco posiciones; se declara el índice inicial.
A[index]Elemento de una posición.Comprueba que index esté dentro de los límites.
A[row, column]Elemento de una matriz.Valida cada dimensión por separado.

07 · rutinas

Procedimientos y funciones

Los procedimientos dan nombre a acciones reutilizables; las funciones calculan y devuelven un valor. El encabezado identifica los parámetros y, en una función, el tipo de retorno según la guía. Una llamada transfiere el control a la rutina y continúa después de su retorno.

Al escribir una rutina, describe su finalidad y elige suficientes parámetros para evitar depender de variables externas. La evaluación considera la forma de pasar parámetros y el ámbito de las variables según las reglas del año de examen.

No mezcles el pseudocódigo Cambridge con declaraciones de Pascal, Python o el pseudocódigo de otra entidad examinadora.

08 · ejemplo guiado

Sumar los elementos de un arreglo

Para sumar los elementos de un arreglo, inicializa un acumulador, recorre las posiciones válidas y añade cada elemento. La declaración siguiente muestra un arreglo indexado de 1 a 5; utiliza los límites del enunciado.

DECLARE numbers : ARRAY[1:5] OF INTEGER
DECLARE total : INTEGER
DECLARE index : INTEGER

total ← 0
FOR index ← 1 TO 5
    total ← total + numbers[index]
NEXT index
OUTPUT total

El ejemplo muestra asignación, índices y bucle. Una respuesta completa también debe indicar cómo se leyeron o asignaron los valores de numbers, según el problema. Sigue el acumulador en cada iteración para no omitir el primer ni el último elemento.

09 · respuestas de examen

Escribir y comprobar respuestas

En una respuesta de examen, la coherencia importa tanto como la idea algorítmica. Utiliza nombres descriptivos, sangría uniforme y delimitadores de bloque de la guía.

  • Declara las variables y los arreglos antes de utilizarlos cuando sea necesario.
  • Comprueba que el tipo de cada variable corresponda a sus valores.
  • Sigue al menos un caso habitual y uno límite.
  • Verifica la condición de salida y la actualización de contadores.
  • En funciones, comprueba todas las rutas de retorno.

El pseudocódigo comunica un algoritmo; la claridad y la fidelidad al estándar del año de examen facilitan su lectura y evaluación.

10 · operadores y selección

Operadores y selección con CASE

Las convenciones de operadores de Cambridge difieren de las de algunos lenguajes: DIV da el cociente entero, MOD el resto y <> significa «distinto de». Las comparaciones producen un valor booleano; utiliza paréntesis cuando una expresión combine varias operaciones.

CASE organiza alternativas para un identificador. Los intervalos del ejemplo presuponen notas de 0 a 100:

CASE OF Mark
    80 TO 100 : OUTPUT "Distinction"
    50 TO 79 : OUTPUT "Pass"
    OTHERWISE : OUTPUT "Resit"
ENDCASE

Los casos se comprueban en orden. Cuando uno coincide, se ejecutan sus instrucciones y el flujo continúa después de ENDCASE. Si existe, OTHERWISE va al final y cubre los valores que no coincidieron antes. Antes de escribir intervalos, comprueba que no haya huecos ni solapamientos para los datos permitidos por el enunciado.

GrupoFormasFunción
Aritmética enteraDIV, MODCociente entero y resto.
Comparación=, <>, <, >, <=, >=Produce un valor BOOLEAN.
LógicaAND, OR, NOTCombina o niega condiciones booleanas.

11 · cadenas

Usar funciones de texto proporcionadas

La guía describe funciones como LENGTH, MID y RIGHT para contar caracteres, extraer un fragmento u obtener el final de una cadena. En los exámenes, el enunciado proporciona las funciones de manipulación de texto necesarias; no presupongas que sus parámetros sean iguales a los de otro lenguaje.

DECLARE ItemCode : STRING
INPUT ItemCode
IF LENGTH(ItemCode) >= 3 THEN
    OUTPUT MID(ItemCode, 1, 3)
ELSE
    OUTPUT ItemCode
ENDIF

La condición protege la extracción cuando el texto tiene menos de tres caracteres. Al resolver una pregunta, identifica en la descripción de la función la posición inicial y la cantidad de caracteres que solicita. Después prueba una cadena con la longitud mínima, otra más larga y una corta.

FunciónResultadoEjemplo
LENGTH(text)Cantidad de caracteres.LENGTH("Happy Days") devuelve 10.
MID(text, start, count)Fragmento con la longitud indicada.MID("ABCDEFGH", 2, 3) devuelve BCD.
RIGHT(text, count)Caracteres finales.RIGHT("ABCDEFGH", 3) devuelve FGH.

12 · subprogramas

Elegir paso por valor o por referencia

Los procedimientos reciben parámetros por valor, salvo que la guía o el enunciado indiquen otro modo. Con el paso por valor, el parámetro funciona como una copia local. BYREF indica que el procedimiento puede modificar la variable proporcionada en la llamada.

PROCEDURE AddBonus(BYREF Score : INTEGER, BYVAL Bonus : INTEGER)
    Score ← Score + Bonus
ENDPROCEDURE
CALL AddBonus(CurrentScore, 5)

Después de la llamada, CurrentScore aumenta en cinco porque Score se pasa por referencia; Bonus sigue siendo un parámetro por valor. La llamada a un procedimiento es una instrucción completa y comienza con CALL.

Una función es distinta: devuelve un solo valor y su llamada forma parte de una expresión o asignación. La guía indica que no se utilice CALL con funciones ni que sus parámetros se pasen por referencia. Al leer una rutina, identifica su tipo, los parámetros y dónde se utiliza el resultado.

FormaEfectoUso
Predeterminado / BYVALEl procedimiento recibe el valor del argumento.Los cambios locales no sustituyen la variable original.
BYREFEl parámetro hace referencia a la variable proporcionada.El procedimiento puede modificar el argumento del llamador.
Parámetro de funciónLa función devuelve un valor; su parámetro no se pasa por referencia.Usa la llamada en una expresión y no escribas CALL.

13 · estructuras avanzadas

Tipos definidos, archivos y objetos

La guía Cambridge 9618 abarca más que variables, arreglos y bucles básicos. En un examen, usa los tipos y operaciones autorizados por la guía del año correspondiente; estos ejemplos siguen la guía 2027–2029. Cada construcción pertenece a la especificación curricular, no a un intérprete de propósito general.

ConstrucciónForma documentadaUso y límite
EnumeraciónTYPE Season = (Spring, Summer, Autumn, Winter)Limita un valor a una lista explícita de alternativas con nombre.
PunteroTYPE TIntPointer = ^INTEGERRepresenta una referencia a una posición de memoria del tipo indicado; declara la variable con el nombre del tipo.
RegistroTYPE StudentRecord ... ENDTYPEAgrupa campos de tipos distintos, accesibles con punto, como Pupil.YearGroup.
ConjuntoTYPE LetterSet = SET OF CHARAgrupa valores de un tipo y se puede definir con DEFINE.
Archivo de textoOPENFILE, READFILE, WRITEFILE, EOF, CLOSEFILELee líneas en secuencia; abrir en modo WRITE crea o reemplaza el contenido.
Archivo aleatorioSEEK, GETRECORD, PUTRECORDMueve el puntero del archivo a un registro y lo lee o lo reemplaza.
ClaseCLASS, PRIVATE, PUBLIC, INHERITS, SUPERDefine propiedades, métodos, el constructor NEW y herencia en la guía de examen.

Este ejemplo lee un archivo de texto línea por línea, reemplaza las líneas vacías por guiones y cierra ambos archivos. Comprueba EOF antes de READFILE, de modo que un archivo vacío no intente una lectura inexistente:

DECLARE LineOfText : STRING
OPENFILE "Input.txt" FOR READ
OPENFILE "Output.txt" FOR WRITE
WHILE NOT EOF("Input.txt")
    READFILE "Input.txt", LineOfText
    IF LineOfText = "" THEN
        WRITEFILE "Output.txt", "----------------------------"
    ELSE
        WRITEFILE "Output.txt", LineOfText
    ENDIF
ENDWHILE
CLOSEFILE "Input.txt"
CLOSEFILE "Output.txt"

APPEND conserva el contenido existente y escribe después de él; WRITE reemplaza el archivo. Para archivos de acceso aleatorio, explica cómo calculas la dirección del registro antes de usar SEEK; PUTRECORD reemplaza el registro en la posición actual. En las clases, la guía usa procedimientos de construcción llamados NEW y SUPER.NEW(...) para inicializar la parte heredada. Consulta la guía del año de examen, porque los ejemplos evaluados y el programa de estudios tienen periodos propios.

14 · versiones y alcance

Versiones y límites

Utiliza la guía de 2026 para ese año de examen y la guía de 2027–2029 para las evaluaciones correspondientes. Consulta la página oficial del programa para localizar una edición posterior.

El pseudocódigo Cambridge no define un compilador, una biblioteca ejecutable estándar ni compatibilidad con un lenguaje concreto. Esta documentación describe convenciones de evaluación y no afirma que Potoo IDE las interprete.
