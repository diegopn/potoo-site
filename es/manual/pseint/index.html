01 · Visión general

Sobre PSeInt

PSeInt es un entorno educativo para escribir y ejecutar algoritmos en pseudocódigo. Su referencia oficial describe instrucciones en español y perfiles con reglas más flexibles o más estrictas.

El entorno también puede mostrar algoritmos como diagramas de flujo, para seguir secuencias, decisiones y repeticiones junto con las instrucciones.

02 · Organización

Estructura del algoritmo

El formato documentado coloca las instrucciones entre Proceso y FinProceso. Algunas versiones y perfiles también aceptan Algoritmo y FinAlgoritmo. Según el perfil, las instrucciones pueden requerir punto y coma o separarse por líneas.

Proceso Saludo
    Definir nombre Como Caracter
    Escribir "¿Cómo te llamas?"
    Leer nombre
    Escribir "Hola, ", nombre
FinProceso

03 · Datos

Variables, tipos y asignación

Una declaración explícita usa Definir nombre Como Tipo. La asignación evalúa la expresión derecha y guarda el resultado en la variable izquierda; los tipos deben ser compatibles.

TipoUso
EnteroNúmeros enteros.
RealNúmeros con parte decimal.
CaracterCaracteres y textos.
LogicoVerdadero o Falso.
Definir edad Como Entero
Definir promedio Como Real
Definir nombre Como Caracter
Definir aprobado Como Logico
edad <- 16
promedio <- 8.25
nombre <- "Ana"
aprobado <- Verdadero

Los nombres comienzan con una letra, pueden continuar con letras y números y no deben coincidir con palabras reservadas. Los comentarios comienzan con //.

04 · Expresiones

Operadores y funciones

CategoríaFormasSignificado
Aritméticos+ - * / ^ % MODOperaciones, potencia y resto entero.
Relacionales> < = <= >=Comparaciones.
Lógicos& Y | O ~ NOConjunción, disyunción y negación.

Los paréntesis cambian el orden habitual de los cálculos. La referencia también enumera funciones integradas como RC, ABS, LN, EXP, SEN, COS, ATAN, TRUNC, REDON y AZAR.

area <- base * altura / 2
resto <- numero MOD 2
es_par <- resto = 0
raiz <- RC(numero)

05 · Interacción

Entrada y salida

Leer recibe uno o más valores y los asigna a las variables indicadas. Escribir muestra una o más expresiones. Algunos perfiles incluyen una forma de salida sin salto de línea, como Escribir Sin Saltar.

Escribir "Ingresa dos números:"
Leer a, b
suma <- a + b
Escribir "Suma: ", suma

06 · Decisiones

Condiciones y selección

Si evalúa una condición; Entonces introduce el bloque verdadero y Sino el alternativo. Segun selecciona entre varios casos y puede incluir De Otro Modo.

Si nota >= 7 Entonces
    Escribir "Aprobado"
Sino
    Escribir "Sigue practicando"
FinSi
Segun opcion Hacer
    1:
        Escribir "Iniciar"
    De Otro Modo:
        Escribir "Opción no válida"
FinSegun

07 · Repetición

Bucles

Mientras comprueba la condición antes de cada vuelta. Repetir ejecuta el cuerpo primero y comprueba Hasta Que, por lo que corre al menos una vez. Para recorre un intervalo y puede usar Con Paso.

Para i <- 1 Hasta 5 Con Paso 1 Hacer
    Escribir i
FinPara
Repetir
    Leer clave
Hasta Que clave = "fin"

Comprueba que la condición de salida pueda alcanzarse para evitar ciclos infinitos.

08 · Colecciones

Arreglos y matrices

Dimension declara un arreglo o una matriz. La notación y el índice inicial dependen del perfil activo; no se deben suponer sus límites. En este ejemplo, el arreglo tiene cinco posiciones numeradas de 0 a 4:

Definir notas Como Real
Dimension notas[5]
Para i <- 0 Hasta 4 Hacer
    Leer notas[i]
FinPara
Escribir "Primera nota: ", notas[0]

Una segunda dimensión crea una matriz y exige un índice por dimensión. Antes de acceder a una posición, comprueba el tamaño y los límites definidos por el perfil. Los arreglos también pueden recibirse en subprocesos según la firma que acepte el perfil.

09 · Reutilización

Subprocesos

SubProceso define una rutina reutilizable. Si devuelve un valor, el encabezado nombra la variable que recibe el resultado; si no, la rutina ejecuta acciones sin producirlo. La llamada usa el nombre y los argumentos entre paréntesis. Los parámetros pueden ser de entrada o, cuando el perfil admite esta forma, por referencia para devolver cambios a quien llamó.

SubProceso resultado <- Doble(numero)
    resultado <- numero * 2
FinSubProceso
Proceso Principal
    Escribir Doble(6)
FinProceso

Las variables locales quedan restringidas a la rutina. La referencia incluye llamadas recursivas, como calcular una potencia, y el paso de arreglos como argumento. Prefiere el paso por valor para cálculos que no deben cambiar la variable original; usa la referencia solo cuando la rutina realmente necesite devolver una modificación.

10 · Ejemplo integrado

Promedio y resultado

Proceso Promedio
    Definir a, b, c, media Como Real
    Escribir "Ingresa tres notas:"
    Leer a, b, c
    media <- (a + b + c) / 3
    Si media >= 7 Entonces
        Escribir "Aprobado: ", media
    Sino
        Escribir "Sigue practicando: ", media
    FinSi
FinProceso

11 · Biblioteca matemática

Funciones integradas

Las funciones de la tabla forman parte de la referencia básica publicada por PSeInt. Sus argumentos se escriben entre paréntesis; el resultado puede asignarse, mostrarse o combinarse con otra expresión.

FormaResultado
RC(x)Raíz cuadrada.
ABS(x)Valor absoluto.
LN(x), EXP(x)Logaritmo natural y función exponencial.
SEN(x), COS(x), ATAN(x)Funciones trigonométricas.
TRUNC(x), REDON(x)Parte entera y entero más cercano.
AZAR(n)Entero aleatorio de 0 a n - 1.
Longitud(texto)Cantidad de caracteres.
SubCadena(texto, inicio, fin)Fragmento entre las posiciones indicadas.
Concatenar(a, b)Une dos cadenas de caracteres.
Mayusculas(texto), Minusculas(texto)Convierte las letras a mayúsculas o minúsculas.
Definir radio, area Como Real
radio <- 3
area <- 3.14159 * radio ^ 2
Escribir "Área: ", REDON(area)
Escribir "Dado: ", AZAR(6) + 1
Definir frase, minuscula Como Caracter
frase <- "Hola, mundo!"
minuscula <- Minusculas(frase)
Escribir "Caracteres: ", Longitud(minuscula)
Escribir "Inicio: ", SubCadena(minuscula, 1, 3)
Escribir Concatenar("Texto: ", minuscula)

Comprueba el dominio de cada función matemática. Las operaciones con cadenas dependen del perfil que las habilita; este ejemplo usa índices desde 1, así que ajusta SubCadena al perfil activo.

12 · Variantes de escritura

Perfiles de configuración de PSeInt

El perfil seleccionado reúne las opciones de escritura que acepta PSeInt. La documentación oficial presenta Estricto y Flexible como ejemplos para mostrar estas diferencias; el programa también ofrece perfiles predefinidos para instituciones. Los ejemplos ilustran configuraciones, no una lista universal de reglas para todas las clases.

AspectoEstrictoFlexible
EstructuraProceso / FinProceso.Algoritmo / FinAlgoritmo.
Declaración de datosDeclara variables con Definir y sus tipos.Puede inferir tipos a partir del uso de las variables.
Separación de instruccionesLos ejemplos usan punto y coma.Los ejemplos separan instrucciones por línea.
Recorrido de coleccionesPara I <- ... accede a cada posición por índice.Para Cada Elemento de Lista recorre los elementos.
CondicionesUsa comparaciones como Elemento > ValMayor.También admite formas descriptivas como Es Mayor Que y Es Par.
Dimensión de arreglosEl ejemplo reserva Dimension Lista[100].El ejemplo usa Dimension Lista[Cant].

Los nombres de las opciones, los límites de los arreglos y otras construcciones dependen del perfil seleccionado. Para los ejercicios de una clase, sigue el perfil indicado por el docente o el material didáctico.

Perfiles institucionales

PSeInt puede incluir perfiles preparados para universidades, facultades y carreras. Reúnen en un archivo las opciones elegidas para una asignatura; su disponibilidad depende de la lista incluida en la distribución o proporcionada por la institución.

Crear, guardar y cargar un perfil

  1. En PSeInt, abre Configurar → Opciones del Lenguaje (perfiles).
  2. En la ventana de selección, elige Personalizar.
  3. Ajusta las opciones según las convenciones que debe usar la clase.
  4. Usa el botón con el icono de disquete para guardar el perfil en un archivo; elige dónde guardarlo, añade una descripción y asigna al archivo un nombre que identifique el perfil.
  5. Para usar un perfil compartido, vuelve a la selección de perfiles, elige Cargar y selecciona el archivo recibido.

Después de cargarlo, comprueba que el perfil aparezca seleccionado antes de escribir o ejecutar el algoritmo. Compartir el mismo archivo ayuda a mantener las mismas reglas en los ejemplos de la clase.

13 · Resolución de problemas

Pruebas y seguimiento

Antes de ejecutar, identifica qué datos recibe el algoritmo, qué resultado debe producir y qué condiciones pueden cambiar su recorrido. Luego prueba con valores sencillos cuyo resultado puedas calcular por separado.

  • Prueba el caso habitual y los límites, como cero, un único elemento o la cantidad máxima prevista.
  • En cada repetición, observa la condición, el contador y las variables que cambian.
  • En los arreglos, comprueba que cada índice esté dentro de la dimensión declarada.
  • En una función, compara los argumentos con el valor devuelto y revisa cada camino de retorno.

El intérprete permite seguir la ejecución paso a paso y contrastarla con el diagrama de flujo. La traza ayuda a encontrar el momento en que una variable deja de tener el valor esperado; no reemplaza la selección de buenos casos de prueba.
