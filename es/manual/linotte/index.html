01 · Visión general

Sobre Linotte

Linotte es un proyecto educativo cuya sintaxis utiliza palabras y frases en francés. El proyecto oficial presenta un entorno para aprender fundamentos de programación y mantiene ejemplos de variables, interacción, condiciones, repeticiones, cálculos y funciones.

El código de esta referencia se conserva en francés para poder compararlo con los archivos originales. Traducir palabras como affiche, prend o ferme cambiaría la sintaxis.

02 · Organización

Programa y comentarios

Un programa Linotte se escribe como un conjunto de instrucciones en el archivo del proyecto. Los ejemplos iniciales no necesitan un bloque externo que envuelva todo el programa. Las instrucciones pueden ocupar una línea; los bloques de varias líneas terminan con ferme.

Los comentarios de línea comienzan con //. Los comentarios de varias líneas se escriben entre /* y */.

affiche "Bonjour !"
// Este comentario termina al final de la línea.
/*
Este bloque completo se ignora
durante la interpretación.
*/

03 · Datos

Variables y valores

Linotte describe las variables como actores: cada actor tiene un nombre, un papel (su tipo) y un valor. La guía introductoria presenta cinco papeles básicos: texte, nombre, drapeau, casier y espèce. El papel se declara con est un; si se omite, el primer valor asignado con prend puede determinar el tipo.

prénom est un texte
prénom prend "Clément"
affiche prénom
prénom prend "Jade"

compteur est un nombre
compteur prend 10
compteur prend compteur + 1

actif est un drapeau
actif prend vrai

mois est un casier de textes valant "janvier", "février", "mars"

drapeau guarda un valor lógico, vrai o faux. Los nombres de actores pueden incluir acentos, como prénom; las palabras de tipo y los valores de texto permanecen en francés.

04 · Interacción

Entrada y salida

affiche muestra una expresión. demande solicita un valor y lo guarda en el actor indicado; declara su tipo antes de leerlo.

prénom est un texte
affiche "Quel est ton prénom ?"
demande prénom
affiche "Bonjour " + prénom

questionne prénom sur "Quel est ton prénom ?" combina la pregunta y la lectura del valor en una sola instrucción. Se pueden unir textos y expresiones con +.

06 · Decisiones

Condiciones

si inicia una condición y sinon introduce la alternativa. Una instrucción sencilla puede ir en la misma línea; los bloques de varias instrucciones terminan con ferme.

note est un nombre
age est un nombre
note prend 12
age prend 20
si note >= 10 affiche "Très bien !"
sinon affiche "Continue à pratiquer"

si age >= 18
    affiche "Adulte"
    affiche "Accès autorisé"
ferme
sinon
    affiche "Mineur"
ferme

Las condiciones comparan valores o comprueban un valor lógico. Los operadores relacionales de los ejemplos incluyen =, !=, >, <, >= y <=.

07 · Repetición

Repeticiones

pour recorre una secuencia numérica con los límites inicial y final incluidos. Los bloques de varias instrucciones se cierran con ferme. Los ejemplos actuales del repositorio para la versión 3.14 usan pour chaque item de casier para vincular cada elemento a un actor con nombre. El tutorial general de Linotte 3 también documenta la forma compacta pour chaque casier, que deja el elemento disponible en joker.

compteur est un nombre
pour compteur de 1 à 5 affiche compteur

pour compteur de 1 à 3
    affiche compteur
    attends 200 millisecondes
ferme

mois est un casier de textes valant "janvier", "février", "mars"
mois_courant est un texte
pour chaque mois_courant de mois
    affiche mois_courant
ferme

Elige límites que correspondan al número de pasos previsto. En esta página se usa un actor con nombre para recorrer colecciones en Linotte 3.14; joker aparece en la forma compacta del tutorial y en algunos bucles numéricos.

08 · Reutilización

Funciones y valores de retorno

Una función se introduce con su nombre, dos puntos y sus parámetros. El cuerpo puede declarar variables locales, ejecutar condiciones y devolver un resultado con retourne. También puede ser recursiva.

double : nombre
    retourne nombre * 2
fibonacci : n
    si n < 2 retourne n
    sinon retourne fibonacci(n - 1) + fibonacci(n - 2)

Una llamada coloca los argumentos entre paréntesis después del nombre. Los ejemplos oficiales usan funciones para separar cálculos y construir mensajes.

09 · Organización de datos

Colecciones y extensiones

casier agrupa valores que se pueden recorrer con pour chaque item de casier. El entorno Linotte también incluye ejemplos visuales y bibliotecas adicionales; estos recursos dependen del entorno y no están necesariamente disponibles en todos los contextos.

nombres est un casier de nombres valant 2, 4, 6
valeur est un nombre
pour chaque valeur de nombres
    affiche valeur * valeur
ferme

Para un recurso concreto, consulta el ejemplo que lo acompaña y la documentación del componente en el proyecto original.

10 · Ejemplo integrado

Notas, función y promedio

prénoms est un casier de textes valant "Lia", "Caio", "Noa"
notes est un casier de nombres
indice est un nombre
seuil est un nombre
note est un nombre
total est un nombre
quantite est un nombre
moyenne est un nombre

total prend 0
quantite prend 0
affiche "Quelle note minimale permet d'atteindre l'objectif ?"
demande seuil

pour indice de 0 à 2
    ajoute question(prénoms{indice}) dans notes
ferme

pour chaque note de notes
    total prend total + note
    quantite prend quantite + 1
    si note >= seuil
        affiche note + " : objectif atteint"
    sinon
        affiche note + " : en dessous de l'objectif"
    ferme
ferme

moyenne prend total / quantite
affiche "Moyenne : " + moyenne
si moyenne >= seuil
    affiche "Objectif moyen atteint"
sinon
    affiche "Objectif moyen non atteint"
ferme

question : prénom
    valeur est un nombre
    affiche "Quelle est la note de " + prénom + " ?"
    demande valeur
    retourne valeur

El programa recopila tres notas, las guarda en un casier, compara cada valor con el límite indicado y calcula el promedio. La función question separa la lectura; el bucle explícito asocia cada elemento a un actor con nombre.

11 · Colecciones

Acceso a colecciones e iteración

Un casier agrupa valores y permite recorrerlos sin repetir instrucciones. Los ejemplos oficiales empiezan los índices en cero: para tres elementos, las posiciones son 0, 1 y 2. Las llaves leen una posición; ajoute incorpora un valor a otra colección.

nombres est un casier de textes valant "Lia", "Caio", "Noa"
indice est un nombre
nom_courant est un texte
pour indice de 0 à 2
    affiche nombres{indice}
ferme

pour chaque nom_courant de nombres
    affiche nom_courant
ferme

En los ejemplos de la versión 3.14, pour chaque nom_courant de nombres vincula el elemento actual al actor indicado. El tutorial general también muestra la forma compacta con joker; conviene identificar qué forma usa cada material de Linotte 3.

12 · Escritura compacta

Atajos e interpolación

El tutorial oficial documenta atajos para mostrar, solicitar y asignar valores. La interpolación inserta el valor de un actor en un texto entre llaves.

prénom est un texte
prénom ?                    // solicita el valor
"Bonjour, {prénom} !" !     // muestra texto interpolado
prénom = "Jules"            // forma abreviada de prend
"Bonjour, " & prénom !

& puede agrupar acciones o valores y § puede reemplazar ferme en ciertas formas abreviadas. Para estudiar la estructura, empieza por las instrucciones completas.

13 · Operaciones disponibles

Funciones integradas

Linotte incluye operaciones matemáticas y métodos para consultar o transformar texto. Algunas funciones usan notación prefija; los métodos de texto aparecen después del valor y llevan punto y paréntesis.

14 · Modelado

Especies y prototipos

Una espèce define un tipo propio de actor con atributos. La declaración indica el papel de cada atributo; al crear un actor se le asignan valores. Los ejemplos acceden a ellos como atributo de actor o atributo@actor.

espèces
    nom & famille est un texte
    pattes est un nombre
    espèce animal contient nom, famille, pattes

principal :
    chat est un animal, nom prend "Mimi", famille prend "félin", pattes prend 4
    affiche nom de chat
    affiche famille@chat

Una especie puede heredar de otra y añadir atributos. El Atelier también permite asociar funciones a prototipos; esos recursos amplían el modelo básico de datos.

espèces
    couleur est un texte
    espèce fleur hérite de point et contient couleur

15 · Recursos del Atelier

Eventos, gráficos y tareas

Los recursos gráficos y de interacción dependen del Atelier y de la versión. El ejemplo oficial 17_cassebrique.liv, asociado a la versión 3.14, combina actores gráficos, una colección de objetos, colisiones y repeticiones. Este fragmento abreviado muestra la iteración explícita de esos ejemplos:

balle est un cercle, x vaut 200, y vaut 60, rayon vaut 10, plein vaut vrai, couleur vaut "rouge"
cibles est un casier de rectangle
position est un nombre
pour position de 0 à 2
    cible est un rectangle, x vaut 30 + 65 * position, y vaut 10, largeur vaut 50, hauteur vaut 20, plein vaut vrai
    ajoute cible dans cibles
ferme
cible est un rectangle, visible vaut faux
pour chaque cible de cibles
    si balle.collision(cible)
        efface cible
    ferme
ferme

El tutorial general de Linotte 3 también muestra eventos del ratón y tareas iniciadas con appelle y sincronizadas con observe. Confirma la sintaxis y disponibilidad en el Atelier instalado.

16 · Diagnóstico

Errores y depuración

El tutorial presenta essaie con una alternativa sinon para responder a errores de ejecución, y débogue para iniciar el seguimiento paso a paso en el Atelier.

  • Lee el error e identifica la instrucción activa.
  • Avanza paso a paso y observa los actores usados en cada cálculo.
  • Comprueba que los bucles cambian el estado y alcanzan su condición de salida.
  • Prueba colecciones vacías, un elemento y los límites de los índices.

La forma y disponibilidad de estas herramientas dependen del Atelier Linotte; la referencia describe el entorno original.

Referencia del modelo del lenguaje

El párrafo llamado principal es el nombre usado en estos ejemplos para organizar la secuencia principal. La ejecución comienza en el primer párrafo ejecutable del libro; principal no es una palabra reservada.

Modelo del programa y referencia de conceptos

Linotte usa las metáforas de libro, párrafo, papel y actor para hacer visible la estructura del programa. También son conceptos operativos: el libro reúne párrafos; un párrafo organiza papeles y acciones; el actor guarda un valor; y ciertas acciones recorren colecciones o devuelven un resultado.

TérminoFunción en el lenguajeForma que aparece en ejemplos

PárrafoSecuencia nombrada de acciones; principal es el punto de entrada en los ejemplos de esta referencia.principal : y un nombre seguido de dos puntos.
Papel / actorEl papel declara la clase de valor; el actor es la variable que lo recibe.compteur est un nombre

Un casier resulta útil cuando varios valores del mismo papel deben tratarse como conjunto. Los ejemplos de Linotte 3.14 usan pour chaque item de casier para asociar el elemento actual a un actor con nombre. El tutorial general también documenta la forma compacta con joker; los bucles numéricos pueden usar joker como valor actual.

El acumulador empieza en cero y recibe cada uno de los tres valores:

total est un nombre
note est un nombre
total prend 0

    total prend total + note
ferme
affiche total

Si la colección está vacía, el cuerpo no cambia el acumulador, que queda en 0. En la forma explícita, el actor indicado recibe cada elemento; el nombre del casier sigue representando la colección completa.
