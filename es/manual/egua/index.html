01 · lenguaje y referencia

Panorama y versión

Égua es un lenguaje interpretado cuya sintaxis y mensajes usan vocabulario en portugués. Reúne programación imperativa, funciones como valores y orientación a objetos. El intérprete oficial recorre la estructura del programa para ejecutarlo; el proyecto distribuye una interfaz de línea de comandos y una experiencia en el navegador.

Este manual reúne los temas oficiales en una referencia continua: parte de la forma de escribir un archivo, explica las reglas que afectan el resultado de las expresiones y llega a las funciones integradas, las bibliotecas y las estrategias de depuración. Los nombres acentuados forman parte del lenguaje: escriba função, senão, padrão y aleatório con la grafía indicada.

Base de esta edición: versión oficial 1.3.16 y documentación consultada el 17 de noviembre de 2026. La documentación web se actualiza con el tiempo; este manual identifica la versión del intérprete cuando una regla depende de su implementación.

02 · entorno de ejecución

Entornos de ejecución

El mismo algoritmo puede estudiarse en un editor del navegador o ejecutarse como archivo con Node.js. El proyecto oficial indica Node.js 18 o posterior para la instalación mediante la línea de comandos.

EntornoCómo empezarÚtil para
Editor del navegadorAbrir la plataforma en línea y escribir en su editor.Primer contacto, demostraciones y experimentos sin instalar el intérprete.
Archivo localInstalar el paquete oficial con npm i -g egua y ejecutar egua programa.egua.Guardar programas en archivos .egua y ejecutarlos desde una terminal.
REPLEjecutar egua sin indicar un archivo.Probar expresiones e instrucciones pequeñas de forma interactiva.

Un archivo mínimo contiene una instrucción de salida:

escreva("¡Hola, mundo!");

El REPL mantiene una sesión interactiva, mientras que la ejecución de un archivo procesa su contenido. Para programas que deban reproducirse después, guarde el código en un archivo y anote la versión del intérprete utilizada.

03 · forma del código

Escritura y estructura

Un archivo combina declaraciones, instrucciones y bloques delimitados por llaves. La indentación no define los bloques: las llaves sí. Termine las declaraciones e instrucciones simples con punto y coma. Las expresiones de la cabecera de para también se separan con punto y coma.

ElementoFormaCómo se lee
Comentario de línea// notaEl intérprete ignora el resto de la línea.
Declaraciónvar total = 0;Crea un nombre; la expresión inicial es opcional.
Asignacióntotal = total + 1;Actualiza una variable o una propiedad/posición accesible.
Llamadaescreva(total);Llama a una función con argumentos entre paréntesis.
Bloque{ ... }Agrupa instrucciones y crea un ámbito local.
Texto"Olá" o 'Olá'Usa comillas simples o dobles.

Los identificadores distinguen mayúsculas de minúsculas. En la versión de referencia, pueden comenzar con guion bajo, una letra latina o letras acentuadas usadas en portugués; los siguientes caracteres también pueden incluir cifras. No use una palabra reservada como nombre de variable. Los comentarios documentados usan //; no suponga que se acepten comentarios de bloque con la forma /* ... */.

// Mantenga separado el cálculo de la presentación.
var raio = 3;
var area = 3.14159 * raio ** 2;
escreva(area);

escreva recibe una expresión y muestra su valor. Para imprimir varios elementos, use llamadas separadas o una los textos con +; no trate la función como una lista de argumentos de impresión.

04 · estado y ámbito

Variables y ámbito

var declara un nombre sin anotar su tipo. El tipo depende del valor almacenado y puede cambiar con una nueva asignación. Sin inicializador, la variable recibe nulo. La asignación usa =; la comparación de igualdad usa ==.

var tentativas;          // nulo
tentativas = 0;
tentativas = tentativas + 1;
escreva(tentativas);     // 1

El ámbito indica dónde puede leerse un nombre. Una declaración fuera de bloques es global. Una declaración dentro de un bloque es local; los bloques internos pueden leer y modificar nombres externos. Declarar el mismo nombre en un bloque interno crea un nombre local que oculta temporalmente al externo.

var mensagem = "fora";
{
  var mensagem = "dentro";
  escreva(mensagem); // dentro
}
escreva(mensagem);   // fora

Las funciones también crean ámbitos. Sus parámetros son nombres locales, y una función anónima puede usar un valor disponible en el contexto donde se creó. Este cierre sobre el contexto permite crear operaciones especializadas sin pasar cada valor como argumento explícito:

var fator = 3;
var multiplicar = função(valor) {
  retorna valor * fator;
};
escreva(multiplicar(4)); // 12

No lea una variable local en su propio inicializador. Declárela primero con un valor válido y luego actualícela. Para evitar ocultaciones accidentales, elija nombres distintos para acumuladores, parámetros y variables de bloques internos.

Textos, listas y diccionarios

Los índices de textos y listas empiezan en cero. Los textos también aceptan índices negativos contados desde el final: -1 representa el último carácter. La documentación oficial describe un error al leer una posición inexistente de una lista. Asignar más allá del final amplía la lista; las posiciones omitidas reciben nulo.

OperaciónEjemploEfecto
Leer una listanotas[0]Obtiene el primer elemento. Un índice inexistente genera un error.
Reemplazar un elementonotas[1] = 7;Reemplaza el elemento existente en la posición 1.
Ampliar una listanotas[3] = 9;Crea posiciones hasta la 3; los huecos pasan a ser nulo.

var notas = [8, 6.5];

escreva(notas); // [8, 6.5, nulo, 9]

var aluna = {"nome": "Ana", "turma": 2};
escreva(aluna["nome"]); // Ana

Use listas cuando importen la posición y el orden de los elementos; use diccionarios cuando una clave describa el dato. El operador em comprueba si un valor pertenece a una lista, si un carácter aparece en un texto o si existe una clave en un diccionario.

06 · cálculo y evaluación

Expresiones y precedencia

Una expresión combina valores, nombres, llamadas y operadores. Los paréntesis hacen explícita la intención. La tabla resume los grupos de operadores de la versión 1.3.16; las filas superiores se evalúan antes que las inferiores.

GrupoFormasRegla práctica
Aritmética** * / % + -Potencia, multiplicación, división, resto, suma y resta.
Comparación numérica> >= < <=Compara dos números y produce un valor lógico.
Igualdad== !=Compara tipo y valor; 4 == "4" resulta en falso. En la implementación 1.3.16, las listas, los diccionarios y las instancias se comparan por identidad.
Lógicose ouEvaluación corta: e omite el lado derecho si el izquierdo es falso; ou lo omite si el izquierdo es verdadero.
PertenenciaemComprueba un elemento en lista/texto o una clave en diccionario.
Bits! ~ & ^ | << >>! niega la veracidad; ~ y los demás operadores actúan sobre bits numéricos.
Asignación=Guarda un valor; la asignación se asocia de derecha a izquierda, por lo que a = b = 3 significa a = (b = 3).
OrdenOperadoresEjemplo de agrupación
1 · mayorParéntesis, llamadas, acceso a propiedades e índicesobjeto.metodo(x)[0]
2Unarios - ! ~-(x)
3**2 ** 3
4* / %a * b / c
5+ -a + b - c
6–8<< >>, después &, después | ^Desplazamientos antes de las combinaciones bit a bit.
9–10> >= < <=, después == !=Comparación numérica antes de igualdad.
11–13em, después e, después ouPertenencia antes de conjunción y disyunción.
14 · menor=Asignación; se asocia de derecha a izquierda: a = b = 3 significa a = (b = 3).

En la implementación etiquetada como 1.3.16, las cadenas de potencias se agrupan de izquierda a derecha: 2 ** 3 ** 2 significa (2 ** 3) ** 2. Use paréntesis si el ejercicio requiere otra asociación. El operador + acepta dos números o dos textos; mezclar un número y un texto genera un error en vez de una conversión automática. En la implementación 1.3.16, las listas, los diccionarios y las instancias se comparan por identidad. Combine pruebas relacionales separadas con e; no encadene comparaciones como 1 < x < 10.

La veracidad también importa fuera de las comparaciones: solo falso y nulo son falsos; los números, textos, listas y diccionarios, incluso vacíos, son verdaderos. e y ou devuelven el operando seleccionado, que no necesariamente es uno de los literales lógicos. Use una comparación cuando el resultado deba ser explícitamente verdadeiro o falso.

07 · flujo de ejecución

Decisiones y repeticiones

Las condiciones eligen qué bloque ejecutar; los bucles repiten un bloque; los selectores eligen entre varios casos. Las llaves delimitan los bloques, que pueden contener otros bloques.

FormaComportamientoCuándo usarla
se (condição) { ... }Ejecuta el bloque si la condición es verdadera.Una decisión binaria o un caso principal.
senãose (condição)Prueba otra condición si fallaron las anteriores.Clasificaciones ordenadas; esta forma reservada se escribe sin espacio.
senão { ... }Se ejecuta si no se seleccionó ninguna rama anterior.Tratar los casos restantes.
enquanto (condição) { ... }Prueba antes de cada repetición; puede ejecutarse cero veces.Repetir hasta que una condición deje de cumplirse.
para (início; teste; passo) { ... }Ejecuta el inicio una vez, prueba antes del cuerpo y aplica el paso después.Contar o recorrer con una actualización previsible.
fazer { ... } enquanto (condição)Ejecuta primero el cuerpo y prueba después; se ejecuta al menos una vez.Repetir una acción que debe ocurrir antes de la primera prueba.
pausa;Termina el bucle actual o una selección escolha.Salir después de encontrar un elemento.
continua;Omite el resto del cuerpo y pasa a la siguiente repetición.Omitir un elemento sin terminar el bucle.
escolha / caso / padrãoCompara una expresión con cada caso; padrão cubre la falta de coincidencia.Elegir una acción entre alternativas discretas.
tente / pegue / senão / finalmentePermite tratar un fallo, ejecutar una rama opcional de éxito y realizar un paso final.Importaciones u operaciones que pueden fallar durante la ejecución.
var notas = [8, 5.5, 9];
para (var i = 0; i < tamanho(notas); i = i + 1) {
  se (notas[i] >= 7) {
    escreva("Aprobada");
  } senãose (notas[i] >= 5) {
    escreva("Recuperación");
  } senão {
    escreva("Reprobada");
  }
}

Cada una de las tres partes de para puede omitirse por separado. Si se omite la prueba, no hay una condición de parada: el bucle continúa hasta que el cuerpo lo termine con pausa. Para depurarlo, anote el valor inicial, la prueba, la actualización y el número de vueltas. En escolha, los casos usan igualdad estricta; pueden ejecutarse varios casos si varias etiquetas tienen el mismo valor. pausa termina la selección; sin padrão, no ocurre nada cuando ningún caso coincide.

La referencia web muestra un punto y coma después de su ejemplo de fazer ... enquanto, pero el parser de la etiqueta 1.3.16 no consume ese terminador como parte del bucle. Hay otra diferencia ortográfica: la guía web actual escribe senão se con espacio, mientras que el lexer etiquetado reserva senãose como una sola palabra. Los ejemplos de esta edición siguen la forma aceptada por el intérprete etiquetado. No mezcle convenciones de versiones distintas.

08 · composición y reutilización

Funciones y parámetros

Una función con nombre usa função, un nombre, parámetros y un bloque. Puede realizar acciones, devolver un valor con retorna o terminar sin valor. Se llama con paréntesis y argumentos posicionales; este ejemplo recibe dos valores y devuelve un resultado reutilizable.

função média(a, b) {
  retorna (a + b) / 2;
}
var resultado = média(8, 10);
escreva(resultado); // 9

El retorno termina la ejecución de la función en ese punto. Si no hay una instrucción de retorno con valor, la llamada produce nulo. Una función anónima usa la misma palabra clave, pero puede guardarse en una variable o pasarse como argumento. Esto es útil con mapear, filtrar y reduzir, que reciben una función de transformación, prueba o acumulación.

var dobrados = mapear([1, 2, 3], função(n) {
  retorna n * 2;
});
escreva(dobrados); // [2, 4, 6]

La gramática de la versión 1.3.16 también admite parámetros con un valor predeterminado simple y un parámetro final precedido por * para reunir los argumentos restantes. Como estos detalles no aparecen en todas las guías oficiales, compruébelos en el intérprete concreto antes de usarlos en material compartido:

FormaEjemploEfecto
Valor predeterminadofunção saudar(nome = "visitante") { ... }Usa el valor indicado cuando no se proporciona un argumento.
Argumentos restantesfunção somar(*valores) { ... }Agrupa los argumentos restantes en una lista en el parámetro final.

Para que las llamadas sean fáciles de revisar, use pocos parámetros, elija nombres que expliquen cada argumento y devuelva valores que puedan probarse por separado. Una función de cálculo no necesita también imprimir: separar el cálculo de la presentación permite reutilizar el resultado.

09 · orientación a objetos

Clases y objetos

classe describe métodos y puede heredar de una clase base con herda. Llamar al nombre de la clase crea una instancia. Los métodos se declaran dentro de las llaves sin escribir função; el método construtor recibe los argumentos usados al crearla. Dentro de un método, isto se refiere a la instancia actual.

classe Contador {
  construtor(valor_inicial) {
    isto.valor = valor_inicial;
  }

  avançar() {
    isto.valor = isto.valor + 1;
    retorna isto.valor;
  }
}

var contador = Contador(2);
escreva(contador.avançar()); // 3

Una propiedad se puede leer o actualizar con un punto, como contador.valor. La herencia reutiliza métodos; super accede a un método definido en la clase padre:

classe Animal {
  apresentar() {
    retorna "animal";
  }
}

classe Cachorro herda Animal {
  apresentar() {
    retorna super.apresentar() + " doméstico";
  }
}

var bicho = Cachorro();
escreva(bicho.apresentar());

Use una clase cuando varias instancias deban mantener estados independientes y operaciones relacionadas. Si el problema solo transforma una entrada en una salida, una función suele mostrar la dependencia con mayor claridad. La documentación no define palabras clave de visibilidad como público o privado; no atribuya a las propiedades reglas de encapsulamiento que el lenguaje no documenta.

Las llamadas HTTP son síncronas y pueden esperar hasta 30 segundos. La documentación indica que los errores de red, las URL no válidas y las respuestas 4xx/5xx producen un fallo; no se documenta la configuración de cabeceras personalizadas. Evite esas llamadas en bucles largos. En la biblioteca de tiempo, use el formato explícito y pruebe fechas límite, como el último día del mes.

Importar una biblioteca hace explícita la dependencia del programa. Impórtela una vez y reutilice el módulo, en lugar de llamar a importar en cada repetición.

12 · ejemplo desarrollado

Programa guiado: clasificar y resumir calificaciones

Este ejemplo combina una función con nombre, un filtro, una reducción, una condición y conversión a texto. Antes de ejecutarlo, identifique los datos de entrada, la regla de aprobación y el caso en que la lista filtrada queda vacía.

função aprovado(nota) {
  retorna nota >= 7;
}

var notas = [8, 6, 9.5, 7, 5];
var aprovadas = filtrar(notas, aprovado);
var soma = reduzir(aprovadas, função(total, nota) {
  retorna total + nota;
}, 0);

escreva("Cantidad de calificaciones:");
escreva(tamanho(notas));
escreva("Aprobadas:");
escreva(aprovadas);

se (tamanho(aprovadas) > 0) {
  var média = soma / tamanho(aprovadas);
  escreva("Promedio de las aprobadas:");
  escreva(média);
} senão {
  escreva("Ninguna calificación alcanzó el mínimo.");
}

El acumulador de reduzir empieza en cero y suma cada calificación aprobada al total anterior. Con esta entrada, el filtro devuelve [8, 9.5, 7], el acumulador termina en 24.5 y el promedio es aproximadamente 8.17.

EtapaValor observadoPor qué importa
Entrada[8, 6, 9.5, 7, 5]Lista original, preservada por el filtro.
Predicado aprovadoverdadeiro para 8, 9.5 y 7La regla se concentra en un lugar.
Resultado de filtrar[8, 9.5, 7]Elementos para los que la función devuelve verdadero.
Reducción0 → 8 → 17.5 → 24.5Muestra cómo cada elemento modifica el acumulador.
Resultado24.5 / 3 ≈ 8.17La división solo ocurre si hay al menos una aprobación.

Amplíe el ejercicio contando las notas inferiores a 7 con otro filtro, buscando la nota más alta con la biblioteca matemática o reemplazando la lista de entrada. Pruebe también []: debe ejecutarse la rama alternativa sin intentar dividir entre cero.

13 · lectura de fallos

Errores y depuración

Separe los errores de escritura, de resolución de nombres y de ejecución. El mensaje suele indicar el token o la línea más cercana al problema; la causa puede estar en la instrucción anterior, por ejemplo, una llave o un punto y coma ausente.

SíntomaQué revisarAjuste típico
Se esperaba ; o }El final de la declaración y la apertura/cierre del bloque anterior.Termine cada instrucción simple y compruebe los pares de llaves.
Nombre no reconocidoGrafía, acentos y ámbito de la variable.Declare antes de usar; confirme matemática y otros nombres acentuados.
No se puede leer una variable en su inicializadorUna declaración como var x = x;.Inicialice a partir de otro valor o asigne después de declarar.

El índice de una lista genera un errorLista vacía, límite superior y cálculo del índice.Compruebe tamanho(lista) y pruebe la primera y última posición.
pausa o continua fuera de un bucle¿El bloque está dentro de enquanto, para o fazer?Mueva el control al cuerpo del bucle correspondiente.

  1. Reduzca el programa hasta la secuencia mínima que todavía reproduce el problema.
  2. Muestre valores intermedios con escreva, una expresión por llamada.
  3. Pruebe los límites: lista vacía, un elemento, primer/último índice y las dos ramas de una condición.
  4. Cambie una regla por vez y repita la misma entrada para identificar qué cambio corrigió el resultado.
  5. Anote la versión del intérprete, el archivo y la entrada; esto ayuda a detectar diferencias entre versiones.

14 · práctica guiada

Ruta de estudio

Una secuencia breve que reutiliza las mismas ideas en problemas progresivamente mayores:

  1. Salida y expresiones: calcule el área y el perímetro de un círculo. Compruebe la precedencia de la multiplicación y la potencia con un cálculo manual.
  2. Decisiones: clasifique una calificación en tres rangos. Pruebe valores inferiores a 5, entre 5 y 7, y desde 7 para cubrir cada rama.
  3. Repetición: recorra una lista por índice. Anote el valor de i, la condición de parada y el número de vueltas.
  4. Funciones: extraiga la regla de aprobación en una función que devuelva un valor lógico. Pruébela por separado antes de aplicarla a la lista.
  5. Programación funcional: filtre y calcule el promedio de la lista con las funciones integradas; trate explícitamente una lista vacía.
  6. Objetos y módulos: cree una clase para un estado que cambia con el tiempo e importe solo la biblioteca necesaria para el ejercicio.

En cada etapa, escriba también un caso que deba fallar o tomar otra rama. Explicar el valor esperado antes de ejecutar es una forma sencilla de comprobar si el algoritmo representa el problema.

16 · implementación independiente

Intérprete mantenido por el proyecto

Además del entorno oficial, una implementación independiente en Rust ofrece una biblioteca y un ejecutor de terminal para programas Égua. Toma como referencia la versión 1.3.16. El ejecutor se distribuye en un repositorio propio y todavía no está integrado en la ejecución de programas dentro de la interfaz de Potoo IDE. Consulta el repositorio del intérprete Égua para ver el código y las instrucciones para integrarlo como biblioteca.

Instalar desde el código fuente

La instalación requiere Rust 1.93 o posterior, Cargo y conexión a internet. El comando siguiente compila e instala el ejecutor desde la revisión 3bd024a. Cargo coloca el comando potoo-egua en su directorio de ejecutables; si la terminal no lo encuentra, añade ese directorio a tu PATH.

cargo install --git https://github.com/diegopn/potoo-egua-interpreter.git --rev 3bd024a06d834c6e27077d286edc922ada234a80 --locked --bin potoo-egua

Ejecutar un archivo o abrir la consola

Guarda el programa en UTF-8 con extensión .egua y ejecútalo desde la terminal. Sin un archivo como argumento, el comando abre una consola interactiva:

ModoComandoComportamiento
Archivopotoo-egua programa.eguaEjecuta un archivo fuente por llamada; la salida va a la salida estándar y los diagnósticos incluyen fase, línea y columna.
Consola interactivapotoo-eguaEvalúa una línea enviada por vez y conserva las variables globales durante la sesión.

Las importaciones del archivo de entrada y de la consola se resuelven desde el directorio de trabajo; dentro de un módulo importado, las rutas son relativas al directorio de ese módulo. En el ejecutor de terminal, las funciones HTTP de la biblioteca requisição dependen de curl en el sistema, aceptan URL HTTP o HTTPS y tienen un límite de 30 segundos. Para integrar la biblioteca Rust en otro proyecto, sigue las instrucciones del README del repositorio.
