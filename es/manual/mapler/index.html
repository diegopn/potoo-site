01 · Panorama

Sobre Mapler

Mapler es una variante educativa de Portugol: sus comandos describen algoritmos en portugués estructurado y se organizan en bloques legibles. La referencia principal es el manual del proyecto Mapler, complementado por sus ejemplos oficiales de estructura, tipos, operaciones, decisiones, bucles y módulos.

Las reglas de esta página se refieren específicamente a Mapler. No establecen una sintaxis única para las demás variantes de la familia Portugol.

02 · Organización

Estructura del algoritmo

Un algoritmo Mapler tiene tres áreas: declaraciones en variaveis, comandos entre inicio y fim, y el cierre del programa. Declara variables y módulos antes de inicio; define los módulos después del bloque principal.

variaveis
    nombre: cadeia;
    edad: inteiro;
inicio
    // La entrada viene después del mensaje
    escrever "¿Cómo te llamas?";
    ler nombre;
    escrever "Hola, ", nombre;
fim.

Los comandos simples terminan en punto y coma. Los comentarios de línea comienzan con //. El punto después de fim aparece en los ejemplos oficiales de estructura.

03 · Datos

Variables, tipos y vectores

Declara cada variable en el área variaveis con la forma nombre: tipo;. inteiro representa números sin parte decimal; real, números decimales con punto; logico, verdadeiro o falso; caractere, un carácter; y cadeia, texto entre comillas dobles.

variaveis
    intentos: inteiro;
    media: real;
    aprobado: logico;
    inicial: caractere;
    mensaje: cadeia;
    notas: vetor [1..5] de real;
inicio
    intentos <- 0;
    aprobado <- falso;
    inicial <- "M";
    mensaje <- "Bienvenida";
    notas[1] <- 8.5;
fim

Los límites del vector son inclusivos y forman parte de la declaración: en [1..5], los índices válidos van de 1 a 5. Usa el índice entre corchetes para leer o cambiar un elemento. Los vectores reúnen valores de un mismo tipo.

No trates inteiro y real como tipos intercambiables. La referencia de Mapler indica que asignar directamente un real a un entero produce un error. La conversión de entero a real solo ocurre dentro de una expresión que ya contiene un operando real: 2.5 + 2 produce real, mientras que 2 + 2 sigue siendo entero.

04 · Cálculos

Asignación, operadores y precedencia

Asigna el resultado de una expresión con <-. Las operaciones aritméticas documentadas son suma, resta, multiplicación y división. Las comparaciones producen valores lógicos y pueden combinarse con e, ou y nao.

GrupoFormasUso
Aritméticos+ - * /Sumar, restar, multiplicar y dividir números.
Relacionales= <> < <= > >=Comparar valores en condiciones.
Lógicose ou naoCombinar o negar condiciones lógicas.

En aritmética, primero se evalúan los paréntesis; luego, la multiplicación y la división; por último, la suma y la resta. Los operadores del mismo nivel se evalúan de izquierda a derecha. Usa paréntesis para hacer explícito otro orden.

total <- precio * cantidad;
media <- (nota1 + nota2) / 2;
se total >= limite e aprobado entao
    escrever "Puedes continuar";
fim se;

05 · Interacción

Entrada y salida

escrever muestra textos y valores. Separa los elementos con comas; aparecen en el mismo orden, así que añade espacios dentro de los textos cuando necesites separarlos visualmente. ler recibe el siguiente dato escrito y lo asigna a la variable indicada.

variaveis
    nombre: cadeia;
    edad: inteiro;
inicio
    escrever "Nombre: ";
    ler nombre;
    escrever "Edad: ";
    ler edad;
    escrever nombre, " tiene ", edad, " años.";
fim

Declara la variable con un tipo compatible con la entrada. Un mensaje antes de ler indica qué espera el algoritmo.

06 · Decisiones

Condiciones con se y senao

se evalúa una condición lógica y entao inicia el bloque que se ejecuta cuando es verdadera. senao es opcional y define la alternativa. El bloque termina con fim se;. Una condición puede combinar comparaciones y conectores lógicos.

se nota >= 7 entao
    escrever "Aprobado";
senao
    escrever "Sigue estudiando";
fim se;

Se pueden anidar condiciones. Cierra cada bloque interno antes del externo y usa paréntesis para que las expresiones compuestas sean fáciles de seguir.

07 · Repetición

Bucles para, enquanto y repita

para recorre un rango con variable de control, inicio, fin y paso. En la forma documentada, cuando el inicio es menor que el fin la variable avanza; si son iguales, el cuerpo se ejecuta una vez, y si el inicio es mayor, no se ejecuta. enquanto comprueba antes de cada pasada, por lo que puede ejecutarse cero veces.

repita ejecuta el cuerpo antes de comprobar su condición. El cuerpo se ejecuta al menos una vez y vuelve a repetirse mientras la condición después de ate sea verdadera; el bucle termina cuando se vuelve falsa.

variaveis
    i: inteiro;
inicio
    para i de 1 ate 5 passo 1 faca
        escrever i;
    fim para;

    i <- 1;
    enquanto i <= 5 faca
        escrever i;
        i <- i + 1;
    fim enquanto;

    i <- 1;
    repita
        escrever i;
        i <- i + 1;
    ate i <= 5;
fim

Los bucles se pueden anidar. En enquanto, actualiza las variables usadas por la condición para que el algoritmo llegue al final previsto.

08 · Reutilización

Módulos

Un módulo agrupa comandos que pueden llamarse desde distintos puntos del algoritmo. Decláralo en variaveis con el tipo modulo, llámalo por su nombre dentro del bloque principal y escribe su definición después del cierre principal.

variaveis
    decirHola: modulo;
    nombre: cadeia;
inicio
    escrever "Nombre: ";
    ler nombre;
    decirHola;
fim

modulo decirHola;
    escrever "Hola, ", nombre;
fim modulo;

Según el material oficial, los módulos pueden acceder a variables del bloque principal y no reciben parámetros. Úsalos para agrupar acciones reutilizables; no devuelven un valor como una función.

09 · Aplicación

Ejemplo completo

El ejemplo combina declaraciones, lectura, cálculo y una decisión. Solo usa estructuras descritas en la referencia de Mapler.

variaveis
    valor_a: real;
    valor_b: real;
    media: real;
inicio
    escrever "Primer valor:";
    ler valor_a;
    escrever "Segundo valor:";
    ler valor_b;
    media <- (valor_a + valor_b) / 2;
    escrever "Promedio: ", media;
    se media >= 7 entao
        escrever "Resultado suficiente";
    senao
        escrever "Repasa el contenido";
    fim se;
fim.

10 · Archivos

Extensión de archivo en Potoo IDE

El manual de Mapler indica archivos de texto con extensión .txt. En Potoo IDE, los archivos Mapler usan .mapler, una elección inspirada en el proyecto DesignLiquido/mapler. Ese repositorio se cita solo como referencia para la extensión adoptada; la sintaxis y las funciones descritas aquí provienen del manual y los ejemplos oficiales de Mapler.
