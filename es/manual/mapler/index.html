01 · Panorama

Sobre Mapler

Mapler es una variante educativa de Portugol: sus comandos describen algoritmos en portugués estructurado y se organizan en bloques legibles. La referencia principal es el manual del proyecto Mapler, complementado por sus ejemplos oficiales de estructura, tipos, operaciones, decisiones, bucles y módulos.

Las reglas de esta página se refieren específicamente a Mapler. No establecen una sintaxis única para las demás variantes de la familia Portugol.

02 · Organización

Estructura del algoritmo

Un programa tiene un área variaveis, el bloque ejecutable que comienza con inicio y el cierre fim. Las declaraciones se escriben antes del algoritmo principal; los módulos se declaran en esa área y se definen después del cierre principal.

variaveis
    nome: cadeia;
    idade: inteiro;
inicio
    escrever "¿Cómo te llamas?";
    ler nome;
    escrever "Hola, ", nome;
fim.

El punto después de fim aparece en los ejemplos de estructura del proyecto. Dentro de los bloques, los comandos terminan en punto y coma.

03 · Datos

Variables, tipos y vectores

Una declaración usa el nombre seguido de dos puntos y el tipo, dentro del área variaveis. Los tipos documentados incluyen inteiro, real, logico, caractere y cadeia. Usa verdadeiro y falso para valores lógicos; los textos van entre comillas y los caracteres individuales se representan como literales de carácter.

variaveis
    tentativas: inteiro;
    media: real;
    aprovado: logico;
    inicial: caractere;
    mensagem: cadeia;
    notas: vetor [1..5] de real;
inicio
    tentativas <- 0;
    aprovado <- falso;
    notas[1] <- 8.5;
fim

Los límites del vector se escriben entre corchetes. El ejemplo oficial usa un rango que comienza en 1; accede solo a índices dentro de los límites declarados.

04 · Cálculos

Asignación y operadores

La asignación usa <-. La referencia matemática presenta suma, resta, multiplicación y división con +, -, * y /. Las expresiones pueden combinar variables, literales y paréntesis; úsalos para dejar explícito el orden del cálculo.

GrupoFormasUso
Aritméticos+ - * /Sumar, restar, multiplicar y dividir números.
Relacionales= <> < <= > >=Comparar valores en condiciones.
Lógicose ou naoCombinar o negar condiciones lógicas.
total <- precio * cantidad;
se total >= limite entao
    escribir "Supera el límite";
fim se;

05 · Interacción

Entrada y salida

escrever muestra texto o valores en la terminal y acepta varios elementos separados por comas. ler recibe un valor del teclado y lo guarda en la variable indicada.

variaveis
    nome: cadeia;
    idade: inteiro;
inicio
    escrever "Nombre:";
    ler nome;
    escrever "Edad:";
    ler idade;
    escrever nome, " tiene ", idade, " años.";
fim

El tipo de la variable debe corresponder al dato introducido. Los mensajes antes de ler aclaran qué espera el algoritmo.

06 · Decisiones

Condiciones con se y senao

se evalúa una condición; entao inicia el bloque que se ejecuta cuando es verdadera. senao introduce la alternativa opcional. Cada bloque condicional termina con fim se;.

se nota >= 7 entao
    escrever "Aprobado";
senao
    escrever "Sigue estudiando";
fim se;

Se permiten condiciones anidadas, siempre que cada bloque se cierre antes que el exterior. Los operadores relacionales y lógicos permiten formar expresiones compuestas.

07 · Repetición

Bucles para, enquanto y repita

para recorre un intervalo con una variable de control, inicio, fin y paso. enquanto comprueba la condición antes de cada repetición. repita ejecuta el bloque y comprueba la condición al final, por lo que siempre se ejecuta al menos una vez.

variaveis
    i: inteiro;
inicio
    para i de 1 ate 5 passo 1 faca
        escrever i;
    fim para;

    i <- 1;
    enquanto i <= 5 faca
        escrever i;
        i <- i + 1;
    fim enquanto;

    repita
        i <- i - 1;
    ate i = 0;
fim

Los bloques se delimitan con el nombre del comando en fim para; y fim enquanto;. Elige el paso y la condición para que el bucle alcance el final esperado.

08 · Reutilización

Módulos

Los módulos son bloques con nombre definidos fuera del principal y llamados por su nombre. Se declaran en variaveis con el tipo modulo; según la referencia oficial, pueden acceder a variables del bloque principal.

variaveis
    dizerOla: modulo;
inicio
    dizerOla;
fim

modulo dizerOla;
    escrever "Rutina reutilizada";
fim modulo;

Esta forma organiza tareas repetidas. El material de Mapler presenta módulos sin parámetros; no los confundas con funciones de otras variantes.

09 · Aplicación

Ejemplo completo

El ejemplo combina declaraciones, lectura, cálculo y una decisión. Solo usa estructuras descritas en la referencia de Mapler.

variaveis
    valor_a: real;
    valor_b: real;
    media: real;
inicio
    escrever "Primer valor:";
    ler valor_a;
    escrever "Segundo valor:";
    ler valor_b;
    media <- (valor_a + valor_b) / 2;
    escrever "Promedio: ", media;
    se media >= 7 entao
        escrever "Resultado suficiente";
    senao
        escrever "Repasa el contenido";
    fim se;
fim.

10 · Archivos

Extensión de archivo en Potoo IDE

El manual de Mapler indica archivos de texto con extensión .txt. En Potoo IDE, los archivos Mapler usan .mapler, una elección inspirada en el proyecto DesignLiquido/mapler. Ese repositorio se cita solo como referencia para la extensión adoptada; la sintaxis y las funciones descritas aquí provienen del manual y los ejemplos oficiales de Mapler.
