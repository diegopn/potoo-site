01 · Alcance

Acerca del dialecto

Portugol es un nombre que se usa para distintos pseudolenguajes. Esta documentación trata específicamente el dialecto Portugol 2.0; sus reglas no definen un estándar universal para todos los pseudolenguajes llamados Portugol.

La gramática y el léxico usados como base para esta referencia se indican en la sección de referencias. Orientan el alcance del dialecto Portugol 2.0 adoptado por Potoo IDE.

Objetivo del proyecto: implementar el dialecto completo de este pseudolenguaje. Los recursos descritos aquí no significan que ya se puedan ejecutar en la aplicación.

02 · Organización

Estructura de un programa

Un archivo comienza con programa y un bloque delimitado por llaves. Las inclusiones de bibliotecas aparecen al principio del bloque; después pueden venir declaraciones globales y funciones. La forma habitual de punto de entrada es una función llamada inicio.

programa {
    inclua biblioteca Matematica --> mat

    const inteiro tentativas = 3
    inteiro acertos = 0

    funcao inicio() {
        escreva("Bienvenido al ejercicio")
    }
}

Los bloques de funciones, condiciones y bucles usan { y }. El punto y coma se usa en los tres campos de la cabecera de para; los ejemplos habituales escriben un comando por línea y no terminan cada comando con punto y coma.

03 · Escritura

Nombres, comentarios y literales

  • Los identificadores empiezan con una letra ASCII o guion bajo; después pueden incluir letras ASCII, dígitos y guiones bajos. La gramática publicada no admite letras acentuadas en identificadores.
  • Las palabras clave se escriben sin acentos y la gramática las reconoce en minúsculas, por ejemplo programa, funcao y enquanto.
  • Los comentarios de línea empiezan con //; los comentarios de bloque se delimitan con /* y */.
  • Los números reales usan punto como separador decimal. Los textos usan comillas dobles y los caracteres individuales, comillas simples; el léxico también define escapes y literales hexadecimales.
  • Los valores lógicos son verdadeiro y falso.
// comentario de línea
/* comentario
   de bloque */
cadeia mensagem = "Hola"
caracter inicial = 'A'
real media = 7.5
logico aprovado = verdadeiro

04 · Datos

Tipos, variables y constantes

TipoUso

Declara el tipo antes del nombre. Una declaración puede agrupar nombres del mismo tipo e incluir una expresión inicial. La palabra clave const marca declaraciones constantes. Los valores y tipos deben ser compatibles.

inteiro idade = 18, ano
real altura = 1.72
const real pi_aproximado = 3.14
cadeia nome = "Lia"
logico concluiu = falso

Una variable declarada dentro de una función o bloque tiene alcance local; las declaraciones del cuerpo principal, fuera de las funciones, son globales. La lista de declaraciones también permite inicializadores de vectores y matrices, que se explican en Vectores y matrices.

La gramática oficial define los operadores mediante alternativas recursivas, pero no publica una tabla de precedencia clara para todas las combinaciones. Usa paréntesis para hacer explícito el orden, sobre todo al mezclar comparaciones, lógica y operaciones bit a bit.

Recomendación: la propia regla gramatical señala que la igualdad tiene prioridad baja, así que no dependas de un orden supuesto en expresiones compuestas.

06 · Interacción

Entrada y salida

escreva muestra una o más expresiones. Para saltar de línea, incluye la secuencia de escape \n en una cadena que pases a esa función. leia recibe datos para variables. La función predefinida limpa() limpia el área de salida. El crate independiente de Potoo IDE también ofrece escreva_linha como comodidad propia; no forma parte del dialecto oficial.

programa {
    funcao inicio() {
        cadeia nome
        escreva("¿Cuál es tu nombre? ")
        leia(nome)
        escreva("Hola, ", nome, "!\n")
    }
}

La manera de mostrar y leer datos puede depender de la implementación de la biblioteca o del entorno que ejecuta el algoritmo. Potoo IDE todavía no ofrece estos flujos dentro de la aplicación.

07 · Decisiones

Condiciones y selección

se ejecuta una rama cuando la expresión lógica es verdadera; senao define la rama alternativa. Los bloques pueden contener varios comandos. La selección múltiple usa escolha, etiquetas caso y la alternativa contrario.

se (nota >= 7) {
    escreva("Aprobado\n")
} senao {
    escreva("Sigue practicando\n")
}

escolha (opcao) {
    caso 1:
        escreva("Iniciar\n")
        pare
    caso contrario:
        escreva("Opción desconocida\n")
}

pare termina el caso actual de escolha o interrumpe un bucle. Usa una expresión de tipo lógico como condición.

08 · Bucles

Repetición

El dialecto define bucles condicionales y un bucle con inicialización, condición e incremento:

inteiro contador = 1
enquanto (contador <= 3) {
    escreva(contador, "\n")
    contador++
}

faca {
    contador--
} enquanto (contador > 0)

para (inteiro i = 0; i < 3; i++) {
    escreva(i, "\n")
}

enquanto evalúa antes de cada repetición; faca ... enquanto evalúa después del bloque. En para, los campos se separan por punto y coma y pueden inicializar una variable, comprobar una condición y actualizar el contador. pare termina el bucle actual.

09 · Colecciones

Vectores y matrices

Los vectores usan un índice entre corchetes; las matrices usan dos índices. Cada dimensión declarada debe ser una expresión constante de tipo entero y valor positivo; si hay un inicializador, el tamaño puede inferirse. La gramática también permite inicializar matrices por filas.

programa {
    funcao inicio() {
        inteiro notas[3] = {8, 9, 10}
        inteiro quadro[2][2] = {{1, 2}, {3, 4}}
        escreva(notas[0], "\n")
        escreva(quadro[1][0], "\n")
    }
}

Los índices son expresiones enteras. Los parámetros de función pueden declarar dimensiones sin fijar sus tamaños, por ejemplo inteiro valores[] o inteiro tabela[][].

10 · Reutilización

Funciones y parámetros

Una función puede declarar un tipo de retorno antes del nombre; omitir el tipo equivale a usarla sin valor de retorno, que también se puede escribir con vazio. Los parámetros tienen tipo y nombre, pueden separarse por comas y pueden recibir vectores o matrices. Un & antes del nombre indica paso por referencia.

funcao inteiro dobrar(inteiro valor) {
    retorne valor * 2
}

funcao atualizar(inteiro &total, inteiro acrescimo) {
    total += acrescimo
}

funcao inicio() {
    inteiro resultado = dobrar(4)
    atualizar(resultado, 1)
    escreva(resultado, "\n")
}

retorne termina la función y puede devolver una expresión. La referencia oficial describe llamadas dentro de expresiones, funciones con retorno y funciones sin retorno.

12 · Ejemplo

Programa completo

Este ejemplo combina declaración, entrada y salida, condición, función y expresión lógica:

programa {
    funcao logico eh_par(inteiro numero) {
        retorne numero % 2 == 0
    }

    funcao inicio() {
        inteiro valor
        escreva("Ingresa un número entero: ")
        leia(valor)

        se (eh_par(valor)) {
            escreva("El número es par\n")
        } senao {
            escreva("El número es impar\n")
        }
    }
}

13 · Compatibilidad

Qué funciona hoy en Potoo IDE

Potoo IDE está en desarrollo y todavía no integra el intérprete en la aplicación de escritorio. Por eso, esta página es una referencia del dialecto deseado, no una lista de funciones disponibles en la aplicación.

El repositorio de Potoo IDE contiene un crate independiente para el pseudolenguaje Portugol 2.0. Implementa un subconjunto: estructura de programas y funciones, declaraciones, tipos, vectores y matrices, paso por valor y referencia, operadores, control de flujo, entrada y salida, y partes de las bibliotecas Matematica, Texto, Tipos y Util. El propio crate identifica esta implementación como parcial; bibliotecas como Calendario, Objetos y Arquivos aún no están implementadas en él.

En desarrollo: la meta es avanzar hacia el dialecto completo. Hasta que se integre con la interfaz de escritorio, no se podrán escribir ni ejecutar estos ejemplos en Potoo IDE.

Referencias del pseudolenguaje Portugol 2.0

El dialecto Portugol 2.0 documentado aquí tiene su origen en Portugol Studio. Esta herramienta aparece solo como fuente de referencia; el nombre que Potoo IDE usa para el pseudolenguaje es Portugol 2.0.

  • Repositorio oficial de Portugol Studio, que identifica el pseudolenguaje como Portugol 2.0.
  • Gramática oficial y léxico oficial.
  • Ayuda oficial sobre entrada y salida, incluido el uso de \n para saltar de línea, y el analizador semántico, que enumera las funciones predefinidas.
  • Código fuente de las bibliotecas estándar y sus funciones documentadas.
  • Crate Portugol de Potoo IDE, su referencia de compatibilidad y el subconjunto implementado.

Las referencias pertenecen a proyectos distintos. Consúltalas para verificar detalles de comportamiento y compatibilidad antes de usar una función específica.
