01 · panorama

Qué es AlgoBox

AlgoBox combina un editor de algoritmos con un entorno de ejecución didáctico. El estudiante puede construir instrucciones en una interfaz estructurada o trabajar en modo de texto. El programa permite practicar variables, entrada y salida, condiciones y repeticiones sin exigir desde el primer ejercicio la sintaxis de un lenguaje de propósito general.

El modo paso a paso ayuda a seguir los cambios de valores y la elección de caminos. El entorno también documenta ejercicios con listas y simulaciones sencillas. La interfaz y los ejemplos oficiales están en francés.

Estado en Potoo IDE: AlgoBox está en evaluación. Esta página describe el proyecto independiente y no indica que exista una integración.

02 · objetivo

Público y enfoque

El proyecto se creó para enseñar algoritmos, especialmente en contextos escolares francófonos. El enfoque consiste en organizar el razonamiento en operaciones observables: definir datos, solicitar una entrada, transformar un valor y mostrar un resultado.

Antes de empezar un algoritmo, piensa en el problema antes de elegir bloques:

  1. especifica los datos conocidos y los que se deben introducir;
  2. identifica el resultado que debe mostrarse;
  3. ordena los pasos y las condiciones;
  4. ejecuta un caso pequeño y sigue cada valor.

Así, el editor estructurado representa el algoritmo y no es solo una forma de escribir texto.

03 · estructura

Organización y vocabulario

El editor textual utiliza palabras clave en francés. Un algoritmo típico tiene una sección de variables e indicadores explícitos de inicio y fin. Este fragmento muestra las formas documentadas de declarar un número, leer una entrada, asignar un valor y presentar el resultado:

VARIABLES
  n EST_DU_TYPE NOMBRE
  carre EST_DU_TYPE NOMBRE
DEBUT_ALGORITHME
  AFFICHER "Entrez un nombre"
  LIRE n
  carre PREND_LA_VALEUR n * n
  AFFICHER carre
FIN_ALGORITHME

El editor estructurado ayuda a insertar cada elemento en el lugar esperado. Si editas texto directamente, comprueba los acentos, las palabras reservadas y la puntuación en el manual de tu versión.

VARIABLESInicia las declaraciones.Declara cada variable antes de usarla.
x EST_DU_TYPE NOMBREDeclara una variable numérica.Los otros tipos son CHAINE y LISTE.
DEBUT_ALGORITHMEMarca el inicio del algoritmo.Las instrucciones ejecutables van después de esta línea.

04 · datos y expresiones

Variables, tipos y operadores

La documentación de AlgoBox presenta familias de datos para números, cadenas y listas. Una variable debe tener un tipo compatible con los valores que almacenará. La asignación se expresa con PREND_LA_VALEUR; la lectura y la visualización tienen instrucciones propias.

RecursoUso

CHAINEAlmacena texto.
LISTERepresenta una colección utilizada en ejercicios documentados.
LIRERecibe un valor durante la ejecución.

Las operaciones aritméticas y las comparaciones forman expresiones; usa paréntesis para aclarar el orden deseado. Consulta la lista oficial para conocer las conversiones y funciones específicas de las listas.

05 · flujo de control

Condiciones, bucles y ejecución

Los algoritmos pueden elegir un camino según una condición y repetir una secuencia. El entorno incluye un modo de ejecución paso a paso que muestra cómo las condiciones y variables influyen en el recorrido.

  • Condición: trata por separado casos diferentes.
  • Bucle contado: repite un bloque durante un intervalo o cantidad conocida.
  • Bucle condicional: repite mientras se cumpla la condición del ejercicio.
  • Lista: puede utilizarse en ejercicios que recopilan y recorren valores.

Al crear un bucle, deja clara la inicialización, la regla para continuar y la actualización del estado. En modo paso a paso, comprueba que cada repetición acerca el programa a su condición de salida.

El manual documenta bloques como SI, POUR y TANT_QUE, además de funciones locales. También describe comandos para dibujar puntos y segmentos en un gráfico y una instrucción PAUSE que ayuda a investigar la ejecución. Estas funciones dependen de las opciones del entorno y deben estudiarse con el manual de la versión correspondiente.

Forma o bloqueUso documentadoLímites y observaciones
== != < <= > >=Comprueba igualdad, desigualdad y orden.Elige la comparación adecuada para la condición.
ET, OUCombina condiciones en una expresión lógica.El manual muestra comprobaciones de intervalos y alternativas.
SI ALORSEjecuta un bloque condicional.El editor estructurado crea el bloque y sus límites.
TANT QUERepite mientras la condición siga siendo verdadera.Cada bucle tiene un límite de 500.000 iteraciones.
POUR ... DE ... A ...Recorre un intervalo numérico.La variable es numérica, aumenta de 1 en 1 y el valor inicial no debe superar el final.

El manual también limita el total de iteraciones del algoritmo a cinco millones. Estos límites protegen la ejecución, pero no sustituyen una condición de salida correcta.

06 · ejemplo guiado

Calcular el cuadrado de un número

El ejemplo inicial pide un número y muestra su cuadrado. En modo estructurado, selecciona primero las variables y añade después las acciones para visualizar, leer, asignar y presentar el resultado.

VARIABLES
  n EST_DU_TYPE NOMBRE
  carre EST_DU_TYPE NOMBRE
DEBUT_ALGORITHME
  AFFICHER "Entrez un nombre"
  LIRE n
  carre PREND_LA_VALEUR n * n
  AFFICHER "Carré : "
  AFFICHER carre
FIN_ALGORITHME

Ejecuta el ejemplo con n = 0, n = 1 y un valor negativo para verificar que la multiplicación produce el cuadrado esperado. Después añade una condición para distinguir números pares e impares y sigue sus instrucciones paso a paso.

07 · estudio y depuración

Cómo practicar

Elige un ejercicio sencillo y describe en lenguaje común qué debe suceder antes de abrir el editor. El modo paso a paso permite comparar esa descripción con el orden real de las instrucciones.

  • Ejecuta casos que cubran cada rama de una condición.
  • Observa el valor de una variable antes y después de cada asignación.
  • Prueba el límite de entrada que termina un bucle.
  • Para las listas, prueba una lista vacía, un elemento y varios elementos, si la operación lo permite.
  • Consulta la documentación en francés si no se reconoce una palabra clave o función.

Los bloques y el texto representan el mismo algoritmo solo si todas las instrucciones y límites son correctos. Comprueba el resultado, no solo la ausencia de errores sintácticos.

08 · versiones y alcance

Versiones y límites

AlgoBox es un entorno con gramática y herramientas propias. La edición mediante bloques, el modo de texto, las funciones de listas y la ejecución paso a paso son características de AlgoBox, no propiedades universales del pseudocódigo.

Las opciones y los detalles de instalación pueden cambiar entre versiones. Esta página resume el sitio y el manual oficiales; consulta la documentación enlazada para confirmar el comportamiento del programa descargado. AlgoBox sigue en evaluación para Potoo IDE.

9 · flujo de trabajo

Modos de edición y construcción

El manual recomienda el modo normal para quienes empiezan. Presenta el algoritmo como un árbol de bloques lógicos; el editor de texto permite escribir las instrucciones directamente. Ambos modos ayudan a practicar la misma lógica, pero el texto debe respetar la gramática de AlgoBox.

Modo o acciónFuncionamiento
Modo normalInserta una línea en la posición deseada y elige la instrucción o el bloque que ocupará esa línea.
Editor de textoEscribe los comandos directamente y comprueba las palabras clave, condiciones y asignaciones en el manual.
Editar un bloqueCambia los parámetros de una instrucción cuando está disponible el botón de edición.
Eliminar un bloqueAl borrar una condición o un bucle también se eliminan las instrucciones que contiene.

En modo normal, declara cada variable antes de usarla. Para insertar una instrucción, sitúa el cursor donde debe aparecer y pulsa Nueva línea (atajo Ctrl+Enter); después elige el comando. No se puede insertar una línea después de FIN_ALGORITHME. Al borrar un bloque SI, POUR o TANT_QUE, revisa todo su cuerpo: las instrucciones internas se eliminan junto con él.

Antes de guardar, asigna al algoritmo un nombre claro y describe brevemente su objetivo en el campo de presentación. El menú de archivos también permite imprimir o exportar el código. Exportar el algoritmo como página web puede limitar funciones como la ejecución paso a paso, la entrada progresiva de datos y la interrupción manual.

10 · herramientas de ejecución

Listas, funciones y seguimiento de ejecución

Las listas almacenan y recorren una secuencia de valores. Para leer o mostrar un elemento, el manual requiere el nombre de la lista y su posición; esta puede ser un número o una variable NOMBRE. La biblioteca documentada incluye cálculos estadísticos sobre un intervalo de posiciones, como media, varianza, desviación típica, mediana, cuartiles, mínimo, máximo y la posición de los extremos.

Algunos cálculos tienen requisitos previos: las funciones de cuartiles documentadas necesitan al menos cuatro elementos. Si el intervalo está vacío o la lista no cumple el requisito, el entorno informa de un error. Comprueba las posiciones inicial y final antes de llamar a una función, y compara el resultado con un conjunto pequeño que puedas calcular a mano.

La función numérica F1(x) permite definir en la interfaz una expresión en función de x e invocarla dentro de una asignación o condición. El panel de funciones locales también permite crear operaciones reutilizables, declarar variables locales e indicar el valor devuelto. El manual describe opciones gráficas para dibujar puntos y segmentos en un sistema de coordenadas, además del comando PAUSE para suspender la ejecución.

En el modo paso a paso se resalta la línea actual y se pueden observar los valores de las variables después de lecturas, asignaciones y bloques de repetición. Úsalo para localizar el primer punto en que un valor se aparta de lo esperado. El entorno limita cada bucle a 500.000 iteraciones como medida de seguridad; esto evita ejecuciones ilimitadas, pero no sustituye una condición de salida correcta.

Los cálculos con números reales también pueden presentar efectos de representación y redondeo. Al comparar resultados decimales, elige una tolerancia adecuada para la actividad en vez de suponer que el ordenador representará exactamente toda igualdad matemática.

11 · práctica con listas

Calcular y comprobar estadísticas de una lista

Una LISTE almacena números en posiciones numeradas. En esta función de AlgoBox, la primera posición es 1; indica la primera y la última posición del intervalo en cada cálculo. Las listas usan índices desde 1, mientras que operaciones de texto como substr usan una posición inicial 0. No reutilices un índice de una estructura en otra sin ajustar su base.

El programa calcula la suma, la media, el máximo y la posición del máximo para cuatro notas:

VARIABLES
  notas EST_DU_TYPE LISTE
  suma EST_DU_TYPE NOMBRE
  media EST_DU_TYPE NOMBRE
  mayor EST_DU_TYPE NOMBRE
DEBUT_ALGORITHME
  notas[1] PREND_LA_VALEUR 7:8:10:15
  suma PREND_LA_VALEUR ALGOBOX_SOMME(notas,1,4)
  media PREND_LA_VALEUR ALGOBOX_MOYENNE(notas,1,4)
  mayor PREND_LA_VALEUR ALGOBOX_MAXIMUM(notas,1,4)
  AFFICHER "Suma: "
  AFFICHER suma
  AFFICHER "Media: "
  AFFICHER media
  AFFICHER "Máximo: "
  AFFICHER mayor
  AFFICHER ALGOBOX_POS_MAXIMUM(notas,1,4)
FIN_ALGORITHME

Para este intervalo, la suma es 40, la media es 10, el máximo es 15 y su posición es 4. La tabla comprueba la suma sin depender de la función estadística:

PosiciónValor leídoSuma acumulada

41540

La biblioteca de listas documenta suma, media, varianza, desviación estándar, mediana, mínimo, máximo y las posiciones de los extremos. Los cuartiles tienen dos variantes: ALGOBOX_QUARTILE1/ALGOBOX_QUARTILE3 y sus variantes _BIS, que siguen definiciones estadísticas distintas. Cada una requiere un intervalo de al menos cuatro valores; comprueba cuál definición pide el ejercicio. Invertir las posiciones, elegir una fuera de la lista o incumplir esta precondición produce un error.

Si un resultado parece incorrecto, compara la llamada con las posiciones usadas, muestra la lista y calcula a mano un conjunto pequeño. En modo paso a paso, avanza una instrucción y observa los valores de las variables; AlgoBox también señala la última línea ejecutada cuando ocurre un error. PAUSE suspende temporalmente la ejecución y mostrar una variable ayuda a localizar la primera pasada incorrecta.
