01 · Panorama

Sobre Logic Basic

Logic Basic es un lenguaje de programación asociado a un entorno visual: además del código, un programa puede interactuar con una ventana, controles, dibujos, sonidos y archivos de datos. El manual del autor presenta el lenguaje mediante comandos y ejercicios progresivos, con un enfoque para principiantes.

Esta referencia resume los conceptos y formas de escritura del manual consultado. Como el material se organiza por comandos y funciones del entorno, consulta la fuente para conocer los detalles de cada opción visual.

02 · Organización

Programa, ventana y archivo

El manual describe dos áreas de trabajo: el código y la ventana donde el programa muestra resultados y controles. La ejecución recorre el código en secuencia hasta el final o hasta encontrar FimPrograma o FimJanela. Los archivos de código usan la extensión .LBC.

Una línea puede contener varios comandos separados por punto y coma; cada comando separado se trata como una línea lógica. El apóstrofo inicia un comentario en el código.

Memoria Nome
Nome = "Ana"
Posicione 1, 1
Escreva "Hola, ", Nome
FimPrograma

Orden del programa y extensiones

El archivo principal se ejecuta en secuencia, desde la primera instrucción hasta la última. FimPrograma termina la secuencia y deja abierta la ventana; FimJanela también la cierra. Las extensiones de código funcionan como fragmentos añadidos al código principal y son un lugar documentado para guardar rutinas llamadas por el programa. El manual recomienda declarar las memorias al comienzo del código principal.

ElementoCuándo usarloEfecto documentado
MemoriaEn el encabezado del código principal.Crea nombres que pueden guardar valores y recursos.
Extensión numeradaPara separar rutinas del flujo principal.Se añade al código principal durante la ejecución.
FimProgramaCuando el algoritmo debe terminar y la ventana permanecer abierta.Detiene el programa.
FimJanelaCuando también debe cerrarse la ventana.Detiene el programa y cierra la ventana.

03 · Datos

Memorias y valores

Memoria crea los nombres que guardan valores. El manual recomienda escribir estas declaraciones al inicio del código principal. Una memoria puede contener texto, números y elementos del entorno visual como objetos y sonidos. El mismo nombre puede recibir un nuevo valor durante la ejecución.

Memoria Nome, Pontos, Fundo
Nome = "Ana"
Pontos = 12
Fundo = "fundo-verde"

El texto va entre comillas. Un número sin comillas se trata como número y puede participar en cálculos; entre comillas, es texto. El manual usa coma decimal, por ejemplo 3,5. Los nombres de memoria no contienen espacios.

Interpretar el valor almacenado

Memoria enumera los nombres que puede usar el programa; el valor asignado determina cómo participa en una expresión. Las comillas importan: el texto que parece numérico sigue siendo texto. El manual consultado no muestra declaraciones de tipo para estas memorias.

FormaEjemploLectura
Literal de textoNome = "Ana"Guarda caracteres entre comillas.
NúmeroPontos = 12Valor numérico que puede usarse en un cálculo.
Texto que parece númeroPontos = "12"Sigue siendo texto; no se debe tratar como el número 12.
Memoria indexadaNome(0)Consulta una posición de una matriz declarada con tamaño.

04 · Expresiones

Asignación y operadores

Fuera de una condición, = asigna un valor. Dentro de una condición, = compara valores. El lenguaje documenta operaciones aritméticas, actualizaciones compuestas y comparaciones. SIM y NAO representan valores lógicos en los ejemplos del manual.

GrupoFormas documentadasUso
Aritméticos+ - * / %Cálculo y resto de la división.
Actualización++ -- += -=Incrementar, decrementar o actualizar un valor.
Comparación= < > <= >= <>Probar igualdad y orden en una condición.
LógicosE OUCombinar condiciones.
Memoria X, Y, Soma
X = 8
Y = 3
Soma = X + Y
Soma += 1
Se Soma >= 12
Escreva "Alcanzó el valor"
FimSe

Los operadores y el manejo numérico siguen el manual de Logic Basic. La escritura de los comandos en los ejemplos sigue las formas del autor.

05 · Interacción

Entrada, mensajes y salida

Escreva muestra uno o más elementos en la ventana, en el orden indicado. Posicione define la posición de salida y LimpaJanela limpia el área visual. Mensagem muestra un mensaje en un cuadro de diálogo.

EntraTexto solicita un texto y devuelve lo escrito a una memoria. El manual también describe controles como cajas de texto, listas, opciones y casillas; sus valores pueden leerse con Componente Valor.

Memoria Nome
Nome = EntraTexto, "Escribe tu nombre:"
LimpaJanela
Posicione 1, 1
Escreva "Hola, ", Nome
Mensagem "Registro completado"

Referencia de comandos de interacción

Los argumentos de un comando se separan con comas. Escreva presenta cada argumento en secuencia; las comillas distinguen el texto literal del nombre de una memoria. La ventana predeterminada usa coordenadas que comienzan en cero, aunque Janela puede cambiar su resolución.

FormaResultadoDetalle importante
Posicione fila, columnaDefine la posición de la próxima salida en la ventana.La cuadrícula predeterminada tiene 27 filas y 79 columnas, numeradas de 0 a 26 y de 0 a 78.
Escreva expresión, ...Muestra los argumentos en secuencia en una misma línea lógica.El texto literal va entre comillas; un nombre de memoria sin comillas aporta su contenido.
Mensagem textoAbre un cuadro de mensaje centrado.No usa la posición establecida por Posicione.
nombre = EntraTexto, preguntaSolicita texto y guarda la respuesta en una memoria.La memoria debe estar declarada.
Componente Valor, nombreLee el valor escrito en un control.Primero se crea el control con Componente.
AguardePausa hasta una interacción o el tiempo configurado.Puede esperar una tecla, un clic en botón/objeto o unos segundos; el resultado de la interacción puede quedar en Retorno.

El punto y coma permite escribir varios comandos en una misma línea física, pero el manual considera cada comando separado como una línea lógica. Esto importa al leer el depurador y al usar saltos a etiquetas.

06 · Decisiones y repetición

Se, CasoContrario y VaPara

Se ejecuta instrucciones cuando una condición es verdadera. CasoContrario define la alternativa opcional y FimSe cierra el bloque. Para repetir comandos, el manual presenta etiquetas y el comando VaPara, que transfiere la ejecución a una línea identificada por su nombre.

Memoria Tentativa
Tentativa = 0
INICIO
Tentativa = Tentativa + 1
Escreva "Intento ", Tentativa
Se Tentativa < 3
VaPara INICIO
CasoContrario
Escreva "Fin de los intentos"
FimSe

Esta forma permite crear bucles, pero requiere controlar explícitamente el estado que detiene la repetición. Un salto incorrecto puede provocar un bucle infinito.

Consulta de las formas de control

FormaEfectoPunto de atención
Se condición ... FimSeEjecuta el bloque cuando la comparación es verdadera.= compara dentro de una condición, aunque asigna fuera de ella.
CasoContrarioMarca el bloque alternativo de un Se.Úsalo dentro del bloque correspondiente y ciérralo con FimSe.
ROTULO seguido de VaPara ROTULORetoma la ejecución en la línea identificada.Actualiza el valor que controla la condición antes de volver al inicio.

El salto implementa la repetición mediante el flujo del programa: la etiqueta marca el comienzo y la condición decide si se vuelve a ella. Antes de ejecutar, recorre una iteración a mano y confirma que el valor comprobado avanza hacia la salida.

07 · Reutilización

Funciones y extensiones

El manual describe rutinas con nombre fuera del flujo principal. Execute Nombre() llama una rutina y Retorne devuelve la ejecución al comando siguiente al punto de llamada. Una rutina puede llamar otras rutinas y ser recursiva. El material también presenta paneles de extensión para organizar código reutilizable.

Escreva "Antes de la rutina"
Execute Saudacao()
Escreva "Después de la rutina"
FimPrograma

Saudacao()
Escreva "¡Hola!"
Retorne

Usa nombres coherentes y asegúrate de que toda ejecución que entre en la rutina alcance Retorne, para evitar que el flujo continúe con instrucciones que no forman parte de ella.

Rutinas, llamadas y retorno

Una rutina con nombre se escribe después del terminador del programa principal o en una extensión. La llamada Execute Nombre() transfiere el control a ella; Retorne vuelve al comando siguiente a la llamada. El manual introductorio describe este retorno como flujo de ejecución, no como una expresión que devuelve un valor calculado. En sus ejemplos básicos, las memorias compartidas permiten intercambiar datos: declárelas y lea o actualice su contenido dentro de la rutina.

Memoria Resultado
Resultado = "listo"
Execute ExibaResultado()
FimPrograma

ExibaResultado()
Escreva "Estado: ", Resultado
Retorne

Separe una rutina cuando un conjunto de comandos tenga una responsabilidad clara o se llame desde más de un lugar. En una rutina recursiva, cada camino debe llegar a un caso de parada o a Retorne; de lo contrario, las llamadas pueden seguir acumulándose.

08 · Colecciones

Matrices

Una memoria puede declararse con una cantidad de posiciones entre paréntesis. Los índices comienzan en cero. Por ejemplo, Memoria Nome(20) crea las posiciones desde Nome(0) hasta Nome(19). Una variable numérica puede servir como índice dentro de un bucle.

Memoria Nome(3), I
Nome(0) = "Ana"
Nome(1) = "Beto"
Nome(2) = "Caio"
I = 0
INICIO
Escreva Nome(I)
I = I + 1
Se I < 3
VaPara INICIO
FimSe

ProcureMatriz busca un valor en una matriz y devuelve el índice correspondiente; si no lo encuentra, el manual indica que devuelve -1.

09 · Recursos visuales

Ventana, controles y multimedia

Los comandos visuales pueden posicionar texto, dibujar objetos, mostrar imágenes y responder a interacciones. Componente crea controles de formulario; Desenhe muestra objetos o recursos visuales; Aguarde pausa la ejecución o recibe una interacción según los argumentos descritos en el manual.

El material también documenta el ratón, el sonido y el vídeo. La configuración de canales, posiciones, dimensiones y controles depende de los parámetros de cada comando; consulta la fuente antes de usar las opciones avanzadas.

LimpaJanela
Posicione 5, 5
Desenhe "personagem"
Aguarde

Depurar siguiendo el estado del programa

El modo Depurar del entorno muestra las líneas de comando a medida que se ejecutan. Compare la instrucción actual con el resultado en la ventana y con los valores de las memorias utilizadas. El manual recomienda comprobar que cada memoria esté declarada y que el comando esté escrito correctamente.

SíntomaQué comprobar primero
Se muestra un nombre literalmente.Compruebe si se declaró con Memoria y recibió el valor esperado.
El texto aparece en otra posición.Revise el orden de argumentos de Posicione fila, columna y si las coordenadas caben en la resolución de la ventana.
El bucle no termina.Observe si cambia la memoria comprobada por Se antes del salto VaPara.
Una rutina no vuelve al punto de llamada.Siga el camino ejecutado y confirme que llega a Retorne.
Una interacción no actualiza la memoria.Compruebe que el control se creó primero y que la respuesta se lee con Componente Valor o Retorno, según el comando.

10 · Datos persistentes

Base de datos nativa

El manual describe bloques BD ... FimBD para definir campos y el comando AbreBD para abrir un archivo de datos. Los campos se completan mediante el nombre de la base y del campo; AdicionaRegistro guarda un registro, LeRegistro lee por posición y FechaBD cierra el archivo. También se documentan comandos para ordenar, buscar y contar registros.

ComandoFinalidad en el manual
BD ... FimBDDefinir los campos de una tabla.
AbreBD / FechaBDAbrir o cerrar el archivo asociado.
AdicionaRegistroGuardar los campos como un nuevo registro.
LeRegistroLeer un registro por posición.
OrdemBD, ProcureOrdenar o localizar registros.
TotalRegistrosObtener el número de registros.

La base usa archivos propios y una definición de campos. Antes de leer o guardar registros, sigue la secuencia de apertura y cierre descrita en el manual.

Esquema, apertura e índices de registros

Una declaración BD asocia un nombre lógico con una ruta y enumera cada campo de la tabla junto con su tamaño; se ubica en el encabezado después de Memoria. Los archivos de datos usan la extensión .LBA, que se puede omitir en AbreBD. Cada base solo puede tener un archivo abierto a la vez: ciérrelo antes de elegir otro archivo para el mismo esquema.

Los registros se indexan desde cero. Si TotalRegistros devuelve T, los índices válidos van de 0 a T - 1. Ejecute OrdemBD antes de la rutina que utiliza el ordenamiento; luego las lecturas siguen ese orden hasta elegir Sequencial u otro orden. Procure usa el índice actual y devuelve -1 si no encuentra el registro.

Una secuencia segura es: definir los campos, abrir un archivo, completar los campos de un registro y guardarlo con AdicionaRegistro; para consultar, obtener la cantidad o buscar una posición, leer con LeRegistro y cerrar con FechaBD al terminar.

11 · Aplicación

Ejemplo integrado

El ejemplo usa memorias, entrada y una condición para mostrar un saludo personalizado. Reúne comandos básicos sin depender de funciones gráficas avanzadas.

Memoria Nome, Pontos
Nome = EntraTexto, "¿Cómo te llamas?"
Pontos = 0
LimpaJanela
Posicione 1, 1
Escreva "Bienvenido, ", Nome
Se Nome = ""
Mensagem "Escribe un nombre para continuar"
CasoContrario
Pontos = Pontos + 1
Escreva "Puntos: ", Pontos
FimSe
FimPrograma
