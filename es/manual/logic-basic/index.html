01 · Panorama

Sobre Logic Basic

Logic Basic es un lenguaje de programación asociado a un entorno visual: además del código, un programa puede interactuar con una ventana, controles, dibujos, sonidos y archivos de datos. El manual del autor presenta el lenguaje mediante comandos y ejercicios progresivos, con un enfoque para principiantes.

Esta referencia resume los conceptos y formas de escritura del manual consultado. Como el material se organiza por comandos y funciones del entorno, consulta la fuente para conocer los detalles de cada opción visual.

02 · Organización

Programa, ventana y archivo

El manual describe dos áreas de trabajo: el código y la ventana donde el programa muestra resultados y controles. La ejecución recorre el código en secuencia hasta el final o hasta encontrar FimPrograma o FimJanela. Los archivos de código usan la extensión .LBC.

Una línea puede contener varios comandos separados por punto y coma; cada comando separado se trata como una línea lógica. El apóstrofo inicia un comentario en el código.

Memoria Nome
Nome = "Ana"
Posicione 1, 1
Escreva "Hola, ", Nome
FimPrograma

03 · Datos

Memorias y valores

Memoria crea los nombres que guardan valores. El manual recomienda escribir estas declaraciones al inicio del código principal. Una memoria puede contener texto, números y elementos del entorno visual como objetos y sonidos. El mismo nombre puede recibir un nuevo valor durante la ejecución.

Memoria Nome, Pontos, Fundo
Nome = "Ana"
Pontos = 12
Fundo = "fundo-verde"

El texto va entre comillas. Un número sin comillas se trata como número y puede participar en cálculos; entre comillas, es texto. El manual usa coma decimal, por ejemplo 3,5. Los nombres de memoria no contienen espacios.

04 · Expresiones

Asignación y operadores

Fuera de una condición, = asigna un valor. Dentro de una condición, = compara valores. El lenguaje documenta operaciones aritméticas, actualizaciones compuestas y comparaciones. SIM y NAO representan valores lógicos en los ejemplos del manual.

Aritméticos+ - * / %Cálculo y resto de la división.
Actualización++ -- += -=Incrementar, decrementar o actualizar un valor.
Comparación= < > <= >= <>Probar igualdad y orden en una condición.
LógicosE OUCombinar condiciones.
Memoria X, Y, Soma
X = 8
Y = 3
Soma = X + Y
Soma += 1
Se Soma >= 12
Escreva "Alcanzó el valor"

Los operadores y el manejo numérico siguen el manual de Logic Basic. La escritura de los comandos en los ejemplos sigue las formas del autor.

05 · Interacción

Entrada, mensajes y salida

Escreva muestra uno o más elementos en la ventana, en el orden indicado. Posicione define la posición de salida y LimpaJanela limpia el área visual. Mensagem muestra un mensaje en un cuadro de diálogo.

EntraTexto solicita un texto y devuelve lo escrito a una memoria. El manual también describe controles como cajas de texto, listas, opciones y casillas; sus valores pueden leerse con Componente Valor.

Memoria Nome
Nome = EntraTexto, "Escribe tu nombre:"
LimpaJanela
Posicione 1, 1
Escreva "Hola, ", Nome
Mensagem "Registro completado"

06 · Decisiones y repetición

Se, CasoContrario y VaPara

Se ejecuta instrucciones cuando una condición es verdadera. CasoContrario define la alternativa opcional y FimSe cierra el bloque. Para repetir comandos, el manual presenta etiquetas y el comando VaPara, que transfiere la ejecución a una línea identificada por su nombre.

Memoria Tentativa
Tentativa = 0
INICIO
Tentativa = Tentativa + 1
Escreva "Intento ", Tentativa
Se Tentativa < 3
VaPara INICIO
CasoContrario
Escreva "Fin de los intentos"
FimSe

Esta forma permite crear bucles, pero requiere controlar explícitamente el estado que detiene la repetición. Un salto incorrecto puede provocar un bucle infinito.

07 · Reutilización

Funciones y extensiones

El manual describe rutinas con nombre fuera del flujo principal. Execute Nombre() llama una rutina y Retorne devuelve la ejecución al comando siguiente al punto de llamada. Una rutina puede llamar otras rutinas y ser recursiva. El material también presenta paneles de extensión para organizar código reutilizable.

Escreva "Antes de la rutina"
Execute Saudacao()
Escreva "Después de la rutina"
FimPrograma

Saudacao()
Escreva "¡Hola!"
Retorne

Usa nombres coherentes y asegúrate de que toda ejecución que entre en la rutina alcance Retorne, para evitar que el flujo continúe con instrucciones que no forman parte de ella.

08 · Colecciones

Matrices

Una memoria puede declararse con una cantidad de posiciones entre paréntesis. Los índices comienzan en cero. Por ejemplo, Memoria Nome(20) crea las posiciones desde Nome(0) hasta Nome(19). Una variable numérica puede servir como índice dentro de un bucle.

Memoria Nome(3), I
Nome(0) = "Ana"
Nome(1) = "Beto"
Nome(2) = "Caio"
I = 0
INICIO
Escreva Nome(I)
I = I + 1
Se I < 3
VaPara INICIO
FimSe

ProcureMatriz busca un valor en una matriz y devuelve el índice correspondiente; si no lo encuentra, el manual indica que devuelve -1.

09 · Recursos visuales

Ventana, controles y multimedia

Los comandos visuales pueden posicionar texto, dibujar objetos, mostrar imágenes y responder a interacciones. Componente crea controles de formulario; Desenhe muestra objetos o recursos visuales; Aguarde pausa la ejecución o recibe una interacción según los argumentos descritos en el manual.

El material también documenta el ratón, el sonido y el vídeo. La configuración de canales, posiciones, dimensiones y controles depende de los parámetros de cada comando; consulta la fuente antes de usar las opciones avanzadas.

LimpaJanela
Posicione 5, 5
Desenhe "personagem"
Aguarde

10 · Datos persistentes

Base de datos nativa

El manual describe bloques BD ... FimBD para definir campos y el comando AbreBD para abrir un archivo de datos. Los campos se completan mediante el nombre de la base y del campo; AdicionaRegistro guarda un registro, LeRegistro lee por posición y FechaBD cierra el archivo. También se documentan comandos para ordenar, buscar y contar registros.

ComandoFinalidad en el manual
BD ... FimBDDefinir los campos de una tabla.
AbreBD / FechaBDAbrir o cerrar el archivo asociado.
AdicionaRegistroGuardar los campos como un nuevo registro.
LeRegistroLeer un registro por posición.
OrdemBD, ProcureOrdenar o localizar registros.
TotalRegistrosObtener el número de registros.

La base usa archivos propios y una definición de campos. Antes de leer o guardar registros, sigue la secuencia de apertura y cierre descrita en el manual.

11 · Aplicación

Ejemplo integrado

El ejemplo usa memorias, entrada y una condición para mostrar un saludo personalizado. Reúne comandos básicos sin depender de funciones gráficas avanzadas.

Memoria Nome, Pontos
Nome = EntraTexto, "¿Cómo te llamas?"
Pontos = 0
LimpaJanela
Posicione 1, 1
Escreva "Bienvenido, ", Nome
Se Nome = ""
Mensagem "Escribe un nombre para continuar"
CasoContrario
Pontos = Pontos + 1
Escreva "Puntos: ", Pontos
FimSe
FimPrograma
