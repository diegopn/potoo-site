01 · Visão geral

O que é o Potoo IDE

O Potoo IDE é um projeto de ambiente desktop para estudantes e professores que aprendem e ensinam lógica de programação por meio de pseudolinguagens. A proposta é reunir escrita de algoritmos, ajuda contextual e acompanhamento de resultados numa interface simples.

O projeto está no começo. Este manual descreve os objetivos e planos e indica o que segue em desenvolvimento.

Como ler este manual: “Planejado” identifica uma meta do produto. “Disponível” descreve algo que existe na base atual do aplicativo.

02 · Estado atual

O que já existe

A base inicial abre uma janela do Potoo IDE com uma mensagem de boas-vindas. O editor, a seleção de linguagem, a execução de algoritmos, a ajuda contextual e a depuração ainda não foram implementados.

Por isso, ainda não é possível criar um projeto de programação, executar pseudocódigo ou acompanhar erros pelo aplicativo.

Em desenvolvimento: as próximas etapas previstas incluem a interface principal, os painéis da IDE e a definição de como integrar interpretadores independentes.

03 · Experiência prevista

Como o fluxo deverá funcionar

O caminho abaixo é a experiência desejada, não um tutorial de recursos disponíveis:

  1. Escolher uma pseudolinguagem para o exercício.
  2. Escrever e organizar os passos do algoritmo no editor.
  3. Consultar uma explicação contextual sobre uma linha ou conceito.
  4. Executar o código e ler a saída e os problemas em painéis de apoio.

O projeto ainda precisa definir a comunicação com cada interpretador, o formato das mensagens de erro e quais recursos de depuração serão possíveis.

04 · Pseudolinguagens

Quais linguagens estão no escopo

  • Portugol: está no escopo inicial do projeto; ainda não há interpretador integrado.
  • VisuAlg: também está no escopo inicial; a integração técnica ainda será definida.
  • PSeInt e Linotte: são possibilidades em avaliação, sem compromisso de integração nesta etapa.

Os interpretadores são projetos independentes. Antes de escolher uma integração, será necessário avaliar compatibilidade, limites técnicos e licenças.

05 · Editor e ajuda

O que a proposta pretende oferecer

  • Editor de pseudocódigo: espaço para escrever algoritmos sem distrações desnecessárias.
  • Ajuda contextual: explicação ligada à linha selecionada e ao conceito envolvido.
  • Painéis inferiores: área prevista para saída, problemas e depuração.
  • Várias linguagens: seleção entre pseudolinguagens depois que as integrações forem definidas.
Importante: esta lista descreve metas do produto. Nenhum dos itens acima está disponível na versão inicial da aplicação.

06 · Desenvolvimento

Como acompanhar o desenvolvimento

O Potoo IDE está em desenvolvimento. A base atual é uma janela de boas-vindas; o editor, as integrações com pseudolinguagens e os painéis planejados ainda serão construídos.

O projeto não anunciou uma data de lançamento. Esta página apresenta o estado conhecido e será atualizada conforme a aplicação avance.

08 · Perguntas frequentes

Dúvidas comuns

Já posso programar no Potoo IDE?

Ainda não. A versão inicial abre uma janela de boas-vindas; editor e execução de algoritmos estão em desenvolvimento.

Quais pseudolinguagens já funcionam?

Nenhuma está integrada nesta etapa. Portugol e VisuAlg fazem parte do escopo inicial; PSeInt e Linotte seguem em avaliação.

Quando o aplicativo ficará pronto?

O projeto continua em desenvolvimento e ainda não tem uma data de lançamento anunciada.
