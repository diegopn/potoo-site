01 · Visão geral

O que é o Potoo IDE

O Potoo IDE é um ambiente desktop para estudantes e professores que aprendem e ensinam lógica de programação com as variantes da família Portugol, a pseudolinguagem Calango e a linguagem de programação Potigol. A aplicação reúne editor, projetos e execução de algoritmos.

O projeto continua em desenvolvimento: essas opções já podem ser usadas no aplicativo, enquanto a cobertura de recursos e as ferramentas de apoio à aprendizagem evoluem.

Como ler este manual: “Planejado” identifica uma meta do produto. “Disponível” descreve algo disponível no Potoo IDE.

02 · Estado atual

O que já está disponível

O Potoo IDE permite criar e editar projetos e executar algoritmos em Portugol Studio 2.0, VisuAlg, G-Portugol, Mapler, Calango e Potigol. Portugol Studio 2.0, VisuAlg, G-Portugol e Mapler são variantes da família Portugol; Calango é uma pseudolinguagem e Potigol é uma linguagem de programação. A cobertura de recursos segue em evolução.

Em desenvolvimento: a cobertura de comandos e os recursos de apoio à aprendizagem seguem evoluindo.

03 · Fluxo de uso

Como criar e executar um algoritmo

O fluxo básico já está disponível no aplicativo:

  1. Criar um projeto e escolher uma linguagem ou variante disponível.
  2. Escrever e organizar os passos do algoritmo no editor.
  3. Executar o programa e fornecer os dados solicitados.
  4. Consultar a saída, os diagnósticos e os recursos de depuração disponíveis.

A cobertura de diagnósticos e depuração varia conforme a linguagem ou variante e continua sendo aprimorada.

04 · Linguagens e pseudolinguagens

Portugol, Calango e Potigol já estão disponíveis

Portugol reúne pseudolinguagens didáticas que expressam algoritmos em português; cada variante define suas próprias regras. O Potoo IDE oferece Portugol Studio 2.0, VisuAlg, G-Portugol e Mapler. Calango é outra pseudolinguagem disponível, enquanto Potigol é uma linguagem de programação com sintaxe em português.

05 · Recursos da aplicação

O que você pode fazer

  • Editor de algoritmos: criar e editar arquivos de programa dentro de projetos.
  • Execução: executar algoritmos, fornecer dados de entrada e consultar a saída.
  • Diagnósticos: mensagens associadas à origem de problemas no código.
  • Depuração: acompanhar a execução com os controles disponíveis para cada pseudolinguagem ou linguagem.
Compatibilidade: as regras e os recursos variam entre cada variante e pseudolinguagem. Consulte a referência correspondente para conhecer a sintaxe documentada; a cobertura no Potoo IDE continua evoluindo.
