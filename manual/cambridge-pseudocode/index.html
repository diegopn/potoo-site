01 · visão geral

O que é Cambridge pseudocode

Cambridge pseudocode é uma notação convencional usada para apresentar algoritmos em cursos e avaliações de Computer Science. Palavras-chave em inglês e blocos delimitados tornam o fluxo visível sem exigir que a pessoa escolha uma linguagem de programação executável.

O guia para professores especifica formas esperadas em respostas e materiais. Em questões, use a notação fornecida pela Cambridge International, mesmo que outra linguagem seja mais familiar.

Estado no Potoo IDE: a notação está em avaliação. A existência deste manual não significa que programas escritos nela sejam executáveis no aplicativo.

02 · contexto de avaliação

Guias e anos de exame

A Cambridge International publica guias de pseudocódigo associados aos programas de estudo. A edição aplicável depende do ano de exame; atualizações podem alterar exemplos, regras ou recomendações para professores.

Para exames de 2026, esta página segue o guia de 2026. O guia publicado para 2027–2029 aplica-se aos exames desses três anos. Compare o ano da sua avaliação com a capa do PDF antes de preparar respostas; uma edição futura não deve ser aplicada retroativamente a exames anteriores.

O propósito do pseudocódigo é tornar a lógica legível e consistente para quem escreve e corrige respostas, não definir uma plataforma de execução.

03 · dados

Declarações, tipos e atribuição

O guia representa declarações com DECLARE, nome de identificador, dois-pontos e tipo. A atribuição usa uma seta apontando para a variável. Tipos comuns incluem inteiros, reais, caracteres, cadeias e valores booleanos.

DECLARE mark : INTEGER
DECLARE passed : BOOLEAN
mark ← 72
passed ← mark >= 50
TipoUso habitual
INTEGERValores inteiros.
REALValores numéricos com fração.
CHAR / STRINGUm caractere ou uma sequência de texto.
BOOLEANCondições verdadeiras ou falsas.

O guia também especifica declaração de vetores e, conforme o curso, outras estruturas. Escreva tipos e limites como aparecem no documento vigente.

04 · entrada e saída

Ler e apresentar dados

INPUT recebe um valor e OUTPUT apresenta texto ou resultado. Em respostas, indique cada operação de entrada e saída explicitamente para que a interação do algoritmo fique clara.

DECLARE name : STRING
INPUT name
OUTPUT "Hello, ", name

Ao analisar a saída, siga a ordem dos argumentos e as convenções do guia para separar ou concatenar valores. Não confunda a notação de avaliação com a sintaxe de leitura de um console específico.

05 · controle de fluxo

Seleção e laços

As palavras de controle indicam o início e o fim de cada bloco. Cambridge pseudocode inclui seleção com IF, alternativas e seleção por casos, além de laços FOR, WHILE e REPEAT.

IF mark >= 50 THEN
    OUTPUT "Pass"
ELSE
    OUTPUT "Retry"
ENDIF

Em um FOR, explicite o intervalo e a direção do contador; em um WHILE, a condição é verificada antes do corpo; em um REPEAT, verifique se a condição é avaliada depois das instruções conforme o guia. Escreva cada delimitador de fechamento corretamente.

06 · coleções

Vetores e estruturas

Vetores armazenam vários valores de um tipo e são acessados por índice. O guia permite declarar dimensão e limites; não presuma que todo vetor começa em 0 ou em 1 sem ler a declaração específica.

O pseudocódigo também documenta registros e estruturas de dados quando o nível do curso exige esses tópicos. Para cada coleção:

  • anote tipo e dimensão;
  • verifique que cada índice está dentro dos limites;
  • distinga o tamanho da posição atual;
  • ao percorrer, confirme o primeiro e o último valor do contador.

Respostas de exame precisam manter os mesmos nomes e limites entre declaração, acesso e laço.

ElementoLeituraVerificação
Declaração ARRAY[1:5]Limites inclusivos de 1 a 5.Há cinco posições; o índice inicial está declarado.
A[index]Elemento de uma posição.Confira se index está dentro dos limites.
A[row, column]Elemento de uma matriz.Valide cada dimensão separadamente.

07 · rotinas

Procedimentos e funções

Procedimentos nomeiam ações reutilizáveis; funções calculam e devolvem um resultado. Cabeçalhos identificam parâmetros e, para funções, o tipo de retorno conforme a convenção do guia. Chamadas transferem controle para a rotina e continuam no ponto seguinte ao retorno.

Ao escrever uma rotina, documente o propósito e escolha parâmetros suficientes para evitar dependência de variáveis externas. A passagem de parâmetros e o escopo de variáveis são avaliados conforme as regras publicadas no guia daquele ano.

Não misture sintaxe de pseudocódigo Cambridge com declarações de Pascal, Python ou pseudocódigo de outra banca.

08 · exemplo guiado

Somar os elementos de um vetor

Para somar os elementos de um vetor, inicialize o acumulador, percorra todas as posições válidas e adicione cada elemento. A declaração abaixo ilustra um vetor de 1 a 5; use os limites que a questão fornecer.

DECLARE numbers : ARRAY[1:5] OF INTEGER
DECLARE total : INTEGER
DECLARE index : INTEGER

total ← 0
FOR index ← 1 TO 5
    total ← total + numbers[index]
NEXT index
OUTPUT total

O exemplo demonstra atribuição, índice e laço. Uma resposta completa também precisa mostrar como os valores de numbers foram lidos ou definidos, conforme o enunciado. Trace o acumulador após cada iteração para evitar omitir o primeiro ou o último elemento.

09 · percurso completo

Do enunciado ao relatório da turma

Considere uma turma com três estudantes. O algoritmo lê o nome e a nota inteira de cada pessoa, rejeita notas fora de 0 a 100, classifica o resultado e, no fim, mostra as três classificações, a média e quantas pessoas alcançaram a aprovação. O limite fixo de três estudantes deixa explícitos os limites do vetor e do laço.

RequisitoRegra adotadaComo o programa atende
EntradaTrês nomes e três notas inteiras entre 0 e 100.O vetor guarda três registros; um laço lê cada estudante.
ValidaçãoNota menor que 0 ou maior que 100 não pode ser aceita.REPEAT ... UNTIL repete a leitura até a nota estar no intervalo.
Classificação80–100: Distinction; 50–79: Pass; 0–49: Resit.Uma função aplica os limites em ordem, do maior para o menor.
RelatórioMostrar cada resultado, a média e a quantidade de aprovados.Um procedimento apresenta cada registro; acumuladores calculam o resumo.

O programa a seguir combina formas descritas no guia de Cambridge 9618 para 2027–2029: declarações, registros, vetores, entrada e saída, seleção, repetição, procedimentos e funções. É um exercício didático original, não uma questão oficial nem um programa executável no Potoo IDE.

Programa completo

CONSTANT PassMark = 50
CONSTANT DistinctionMark = 80

TYPE StudentRecord
    DECLARE Name : STRING
    DECLARE Mark : INTEGER
    DECLARE Category : STRING
ENDTYPE

FUNCTION GetCategory(Mark : INTEGER) RETURNS STRING
    IF Mark < 0 OR Mark > 100 THEN
        RETURN "Invalid"
    ELSE
        IF Mark >= DistinctionMark THEN
            RETURN "Distinction"
        ELSE
            IF Mark >= PassMark THEN
                RETURN "Pass"
            ELSE
                RETURN "Resit"
            ENDIF
        ENDIF
    ENDIF
ENDFUNCTION

PROCEDURE DisplayStudent(Name : STRING, Mark : INTEGER, Category : STRING)
    OUTPUT Name, " - ", Mark, " - ", Category
ENDPROCEDURE

DECLARE Students : ARRAY[1:3] OF StudentRecord
DECLARE Index : INTEGER
DECLARE PassedCount : INTEGER
DECLARE TotalMarks : INTEGER
DECLARE ClassAverage : REAL

PassedCount ← 0
TotalMarks ← 0

FOR Index ← 1 TO 3
    OUTPUT "Student name:"
    INPUT Students[Index].Name
    REPEAT
        OUTPUT "Enter a mark from 0 to 100:"
        INPUT Students[Index].Mark
    UNTIL (Students[Index].Mark >= 0) AND (Students[Index].Mark <= 100)

    Students[Index].Category ← GetCategory(Students[Index].Mark)
    TotalMarks ← TotalMarks + Students[Index].Mark

    IF Students[Index].Mark >= PassMark THEN
        PassedCount ← PassedCount + 1
    ENDIF
NEXT Index

ClassAverage ← TotalMarks / 3

OUTPUT "Report:"
FOR Index ← 1 TO 3
    CALL DisplayStudent(Students[Index].Name,
                        Students[Index].Mark,
                        Students[Index].Category)
NEXT Index
OUTPUT "Class average: ", ClassAverage
OUTPUT "Passed: ", PassedCount, " of 3"

Como os recursos se conectam

ConstruçãoResponsabilidadePonto de atenção
StudentRecordAgrupa nome, nota e classificação de uma pessoa.Os campos são acessados com ponto.
Students[1:3]Armazena os três registros em posições numeradas de 1 a 3.Os limites usados na declaração e nos laços coincidem.
GetCategoryDevolve uma classificação como valor de uma função.Os limites são verificados do maior para o menor; a função também protege a faixa inválida.
DisplayStudentApresenta um resultado por chamada.A chamada de procedimento começa com CALL e é uma instrução completa.
REPEAT ... UNTILValida uma nota antes de armazená-la no resumo.A condição é verificada depois da leitura; haverá pelo menos uma tentativa.
FOR, TotalMarks e PassedCountPercorrem o vetor, somam as notas e contam aprovações.A média usa /, cujo resultado é REAL mesmo com operandos inteiros.

Na primeira passagem, TotalMarks e PassedCount são atualizados junto com cada registro. Na segunda, o programa apenas apresenta os dados já guardados. Essa separação evita recalcular a classificação e permite conferir o relatório depois da leitura completa.

Rastreamento com um conjunto pequeno de dados

Suponha que as entradas válidas sejam Ada/84, Rui/63 e Lia/42. A tabela mostra os acumuladores depois de cada volta do primeiro laço:

ÍndiceNome / notaCategoriaTotal após a voltaAprovados
1Ada / 84Distinction841
2Rui / 63Pass1472
3Lia / 42Resit1892

O resultado final é média 189 / 3 = 63.0 e 2 aprovados de 3. A divisão produz um valor REAL; a apresentação exata de casas decimais depende da convenção da resposta escrita.

10 · respostas de exame

Como escrever e conferir respostas

Em uma resposta de exame, a consistência ajuda tanto quanto a ideia do algoritmo. Use nomes descritivos, indentação estável e os delimitadores de bloco previstos no guia.

  • Declare variáveis e vetores antes do uso, quando exigido.
  • Confira que o tipo de cada variável corresponde aos valores atribuídos.
  • Trace pelo menos um caso normal e um caso de limite.
  • Verifique a condição de término e a atualização dos contadores.
  • Para funções, confira todos os caminhos de retorno.

O pseudocódigo comunica o algoritmo; clareza e fidelidade ao padrão do ano de exame facilitam sua leitura e avaliação.

11 · operadores e seleção

Operadores e seleção por casos

As convenções de operadores da Cambridge diferem em alguns pontos de outras linguagens: DIV fornece o quociente inteiro, MOD o resto, e <> significa “diferente de”. Comparações produzem um valor booleano; use parênteses quando uma expressão combinar várias operações.

CASE organiza alternativas para um mesmo identificador. Os intervalos deste exemplo pressupõem notas na escala de 0 a 100:

CASE OF Mark
    80 TO 100 : OUTPUT "Distinction"
    50 TO 79 : OUTPUT "Pass"
    OTHERWISE : OUTPUT "Resit"
ENDCASE

As alternativas são verificadas em sequência. Quando uma corresponde ao valor, seu bloco é executado e o fluxo continua depois de ENDCASE. OTHERWISE, quando usado, fica por último e cobre os valores que não correspondem às opções anteriores. Antes de escrever faixas, confira se elas não deixam lacunas ou se sobrepõem para os dados permitidos pelo enunciado.

GrupoFormasFunção
Aritmética inteiraDIV, MODQuociente inteiro e resto.
Comparação=, <>, <, >, <=, >=Produz um valor BOOLEAN.
LógicaAND, OR, NOTCombina ou inverte condições booleanas.

12 · cadeias

Usar funções de texto fornecidas

O guia descreve funções como LENGTH, MID e RIGHT para contar caracteres, extrair um trecho ou obter o final de uma cadeia. Em exames, as funções de manipulação de texto necessárias são fornecidas no enunciado; não presuma que a assinatura seja igual à de outra linguagem.

DECLARE ItemCode : STRING
INPUT ItemCode
IF LENGTH(ItemCode) >= 3 THEN
    OUTPUT MID(ItemCode, 1, 3)
ELSE
    OUTPUT ItemCode
ENDIF

A condição protege a extração do trecho quando o texto tem menos de três caracteres. Ao resolver uma questão, destaque na descrição da função qual posição inicia a seleção e quantos caracteres são pedidos. Depois teste uma cadeia exatamente do tamanho mínimo e outra maior, além do caso curto.

FunçãoResultadoExemplo
LENGTH(text)Quantidade de caracteres.LENGTH("Happy Days") resulta em 10.
MID(text, start, count)Trecho com o comprimento indicado.MID("ABCDEFGH", 2, 3) resulta em BCD.
RIGHT(text, count)Os caracteres finais.RIGHT("ABCDEFGH", 3) resulta em FGH.

13 · subprogramas

Escolher passagem por valor ou referência

Procedimentos recebem parâmetros por valor, a menos que o guia ou o enunciado indique outro modo. Com passagem por valor, o parâmetro funciona como uma cópia local. BYREF sinaliza que o procedimento pode alterar a variável fornecida na chamada.

PROCEDURE AddBonus(BYREF Score : INTEGER, BYVAL Bonus : INTEGER)
    Score ← Score + Bonus
ENDPROCEDURE
CALL AddBonus(CurrentScore, 5)

Após a chamada, CurrentScore aumenta em cinco porque Score é passado por referência; Bonus continua sendo parâmetro por valor. Observe que a chamada de procedimento é uma instrução completa e começa com CALL.

Uma função é diferente: ela devolve um valor único e a chamada entra em uma expressão ou atribuição. O guia orienta a não usar CALL para chamar funções nem passagem por referência para seus parâmetros. Ao ler uma rotina, identifique o tipo de subprograma, os parâmetros e o local onde o resultado é usado.

FormaEfeitoUso
Padrão / BYVALO procedimento recebe o valor do argumento.Alterações locais não substituem a variável original.
BYREFO parâmetro referencia a variável fornecida.O procedimento pode alterar o argumento do chamador.
Parâmetro de funçãoA função devolve um valor; não recebe parâmetro por referência.Use a chamada em expressão e não escreva CALL.

14 · estruturas avançadas

Tipos definidos, arquivos e objetos

O guia Cambridge 9618 descreve mais do que variáveis, vetores e laços básicos. No exame, use os tipos e as operações que o guia do ano da prova autoriza; estes exemplos seguem o guia de 2027–2029. Cada construção abaixo representa uma convenção da especificação curricular, não um recurso de um interpretador geral.

ConstruçãoForma documentadaUso e limite
EnumeraçãoTYPE Season = (Spring, Summer, Autumn, Winter)Restringe um valor a uma lista explícita de alternativas nomeadas.
PonteiroTYPE TIntPointer = ^INTEGERRepresenta uma referência a uma posição de memória do tipo indicado; a variável é declarada com o nome do tipo.
RegistroTYPE StudentRecord ... ENDTYPEAgrupa campos heterogêneos, acessados por notação de ponto, como Pupil.YearGroup.
ConjuntoTYPE LetterSet = SET OF CHARAgrupa valores de um tipo e pode ser definido com DEFINE.
Arquivo textoOPENFILE, READFILE, WRITEFILE, EOF, CLOSEFILELê linhas sequencialmente; abrir em WRITE cria ou substitui o conteúdo.
Arquivo aleatórioSEEK, GETRECORD, PUTRECORDMove o ponteiro do arquivo para um registro e lê ou substitui esse registro.
ClasseCLASS, PRIVATE, PUBLIC, INHERITS, SUPERDefine propriedades, métodos, construtor NEW e herança no guia de exame.

Este exemplo lê um arquivo de texto linha a linha, troca linhas vazias por hífens e fecha os dois arquivos. EOF é testado antes de READFILE, de modo que um arquivo vazio não tenta uma leitura inexistente:

DECLARE LineOfText : STRING
OPENFILE "Input.txt" FOR READ
OPENFILE "Output.txt" FOR WRITE
WHILE NOT EOF("Input.txt")
    READFILE "Input.txt", LineOfText
    IF LineOfText = "" THEN
        WRITEFILE "Output.txt", "----------------------------"
    ELSE
        WRITEFILE "Output.txt", LineOfText
    ENDIF
ENDWHILE
CLOSEFILE "Input.txt"
CLOSEFILE "Output.txt"

O modo APPEND mantém o conteúdo existente e grava após ele; WRITE substitui o arquivo. Em arquivos de acesso aleatório, explique como o endereço do registro é calculado antes de usar SEEK; PUTRECORD substitui o registro na posição atual. Para definir classes, o guia usa procedimentos de construção chamados NEW e SUPER.NEW(...) para inicializar a parte herdada. Consulte o guia aplicável ao ano, pois os exemplos de exame e o programa de estudos têm períodos próprios.

15 · versões e escopo

Versões e limites

Use o guia de 2026 para exames desse ano e o guia de 2027–2029 para as avaliações correspondentes. Consulte a página oficial do curso para localizar uma edição posterior.

Cambridge pseudocode não define compilador, biblioteca padrão executável ou compatibilidade com uma linguagem concreta. Esta documentação descreve convenções de avaliação e não afirma que o Potoo IDE as interprete.
