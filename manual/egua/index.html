01 · linguagem e referência

Visão geral e versão

Égua é uma linguagem interpretada cuja sintaxe e mensagens usam vocabulário em português. Ela reúne programação imperativa, funções como valores e orientação a objetos. O interpretador oficial percorre a estrutura do programa para executá-la; a implementação distribuída pelo projeto oferece uma linha de comando e uma experiência no navegador.

Este manual transforma os tópicos oficiais em uma referência contínua: parte da forma de escrever um arquivo, acompanha as regras que mudam o resultado de uma expressão e chega às funções integradas, bibliotecas e estratégias de depuração. Os nomes acentuados fazem parte da linguagem: escreva função, senão, padrão e aleatório com a grafia mostrada.

Base desta edição: versão oficial 1.3.16 e documentação consultada em 17 de novembro de 2026. A documentação web é atualizada ao longo do tempo; quando uma regra depende do interpretador, este manual identifica a versão de referência.

02 · ambiente de execução

Ambientes de execução

O mesmo algoritmo pode ser estudado em um editor de navegador ou executado como arquivo no ambiente Node.js. O projeto oficial indica Node.js 18 ou posterior para a instalação pela linha de comando.

AmbienteComo começarQuando é útil
Editor no navegadorAbrir a plataforma online e escrever no editor.Primeiro contato, demonstrações e experimentos sem instalar o interpretador.
Arquivo localInstalar o pacote oficial com npm i -g egua e executar egua programa.egua.Guardar programas em arquivos .egua e executá-los pelo terminal.
REPLExecutar egua sem informar um arquivo.Testar expressões e pequenas instruções interativamente.

O exemplo mínimo de um arquivo é uma instrução de saída:

escreva("Olá, mundo!");

O REPL mantém uma sessão interativa, enquanto uma execução de arquivo processa o conteúdo do arquivo informado. Para programas que precisam ser reproduzidos depois, salve o código em um arquivo e registre qual versão do interpretador foi usada.

03 · forma do código

Escrita e estrutura

Um arquivo combina declarações, instruções e blocos entre chaves. A indentação não define os blocos: as chaves definem. Use ponto e vírgula ao final de declarações e instruções simples; as expressões do cabeçalho de para também são separadas por ponto e vírgula.

ElementoFormaLeitura
Comentário de linha// observaçãoO interpretador ignora o restante da linha.
Declaraçãovar total = 0;Cria um nome; a expressão inicial é opcional.
Atribuiçãototal = total + 1;Atualiza uma variável ou uma posição/propriedade acessível.
Chamadaescreva(total);Chama uma função com argumentos entre parênteses.
Bloco{ ... }Agrupa instruções e cria um escopo local.
Texto"Olá" ou 'Olá'Usa aspas simples ou duplas.

Identificadores diferenciam maiúsculas de minúsculas. Na versão de referência, podem começar com sublinhado, letra latina ou letras acentuadas usadas em português; depois do primeiro caractere, também podem conter algarismos. Não use uma palavra reservada como nome de variável. Comentários documentados usam //; não suponha que comentários de bloco no formato /* ... */ sejam aceitos.

// O cálculo fica separado da apresentação.
var raio = 3;
var area = 3.14159 * raio ** 2;
escreva(area);

escreva recebe uma expressão e apresenta seu valor. Para imprimir vários itens, use chamadas separadas ou combine textos com +; não trate a função como uma lista de argumentos de impressão.

04 · estado e escopo

Variáveis e escopo

var declara um nome sem anotar um tipo. O tipo vem do valor armazenado e pode mudar quando uma nova atribuição é feita. Sem inicializador, a variável recebe nulo. Uma atribuição usa =; a comparação de igualdade usa ==.

var tentativas;          // nulo
tentativas = 0;
tentativas = tentativas + 1;
escreva(tentativas);     // 1

O escopo informa onde o nome pode ser lido. Uma declaração feita fora de blocos é global. Uma declaração dentro de um bloco fica local a ele; blocos internos podem ler e alterar nomes externos. Declarar o mesmo nome dentro de um bloco interno cria um nome local que oculta temporariamente o externo.

var mensagem = "fora";
{
  var mensagem = "dentro";
  escreva(mensagem); // dentro
}
escreva(mensagem);   // fora

Funções também formam escopos. Seus parâmetros são nomes locais, e uma função anônima pode usar um valor disponível no contexto em que foi criada. Esse fechamento sobre o contexto permite criar operações especializadas sem transformar cada valor em argumento explícito:

var fator = 3;
var multiplicar = função(valor) {
  retorna valor * fator;
};
escreva(multiplicar(4)); // 12

Não leia uma variável local no próprio inicializador. Primeiro declare um valor válido e só então atualize-o. Para evitar que um nome oculte outro sem intenção, escolha nomes diferentes para acumuladores, parâmetros e variáveis de blocos internos.

Textos, listas e dicionários

Os índices de texto e lista começam em zero. Textos também aceitam índices negativos, contados do fim: -1 representa o último caractere. A documentação oficial descreve erro ao ler uma posição inexistente de lista. Atribuir além do fim amplia a lista; posições puladas recebem nulo.

OperaçãoExemploEfeito

Substituirnotas[1] = 7;Troca o elemento existente na posição 1.
Ampliar listanotas[3] = 9;Cria posições até 3; lacunas entre o fim anterior e a nova posição tornam-se nulo.

Ler dicionárioaluna["nome"]Obtém o valor associado à chave.
var notas = [8, 6.5];
notas[3] = 9;
escreva(notas); // [8, 6.5, nulo, 9]

var aluna = {"nome": "Ana", "turma": 2};
escreva(aluna["nome"]); // Ana

Use listas quando a posição e a ordem dos itens importarem; use dicionários quando a chave descrever o dado. O operador em testa se um valor pertence a uma lista, se um caractere aparece em um texto ou se uma chave existe em um dicionário.

06 · cálculo e avaliação

Expressões e precedência

Uma expressão combina valores, nomes, chamadas e operadores. Parênteses deixam a intenção explícita. O quadro resume os grupos de operadores da versão 1.3.16; as linhas superiores são avaliadas antes das inferiores.

GrupoFormasRegra prática
Aritmética** * / % + -Potência, multiplicação, divisão, resto, soma e subtração.
Comparação numérica> >= < <=Compara dois números e produz um valor lógico.
Igualdade== !=Compara tipo e valor; 4 == "4" resulta em falso. Na implementação 1.3.16, listas, dicionários e instâncias se comparam por identidade.
Lógicose ouAvaliação curta: e não avalia o lado direito se o esquerdo for falso; ou não o avalia se o esquerdo for verdadeiro.
PertencimentoemTesta elemento em lista/texto ou chave em dicionário.
Bits! ~ & ^ | << >>! nega a veracidade; ~ e os demais operam sobre bits numéricos.
Atribuição=Armazena um valor; associa da direita para a esquerda, então a = b = 3 equivale a a = (b = 3).
OrdemOperadoresExemplo de agrupamento
1 · primeiroParênteses, chamada, acesso por ponto e índiceobjeto.metodo(x)[0]
2Unários - ! ~-(x)
3**2 ** 3
4* / %a * b / c
5+ -a + b - c
6–8<< >>, depois &, depois | ^Deslocamentos antes das combinações bit a bit.
9–10> >= < <=, depois == !=Comparação numérica antes de igualdade.

Na implementação marcada como 1.3.16, cadeias de potências são agrupadas da esquerda para a direita: 2 ** 3 ** 2 equivale a (2 ** 3) ** 2. Use parênteses se o exercício exigir outra associação. O operador + aceita dois números ou dois textos; misturar um número e um texto provoca erro em vez de conversão automática.

A veracidade também importa fora de uma comparação: apenas falso e nulo são falsos; números, textos, listas e dicionários, inclusive vazios, são verdadeiros. e e ou retornam o operando selecionado, não necessariamente um dos literais lógicos. Use uma comparação quando o resultado precisar ser explicitamente verdadeiro ou falso.

07 · fluxo de execução

Decisões e repetições

Condições escolhem qual bloco executar; laços repetem um bloco; seletores escolhem entre vários casos. Os blocos são delimitados por chaves e podem conter outros blocos.

FormaComportamentoQuando usar
se (condição) { ... }Executa o bloco quando a condição é verdadeira.Uma decisão binária ou um caso principal.
senãose (condição)Testa outra condição se as anteriores falharam.Faixas ordenadas de classificação; escreva junto, sem espaço, nessa forma reservada.
senão { ... }Executa quando nenhum ramo anterior foi selecionado.Tratar os casos restantes.
enquanto (condição) { ... }Testa antes de cada repetição; pode executar zero vezes.Repetir até uma condição deixar de valer.
para (início; teste; passo) { ... }Executa início uma vez, testa antes do corpo e aplica o passo depois.Contagem ou percurso com atualização previsível.
fazer { ... } enquanto (condição)Executa o corpo primeiro e testa depois; executa ao menos uma vez.Repetir uma ação que precisa ocorrer antes do primeiro teste.
pausa;Encerra o laço corrente ou uma seleção escolha.Sair quando um item procurado for encontrado.
continua;Pula o restante do corpo e segue para a próxima repetição.Ignorar um item sem encerrar o laço.
escolha / caso / padrãoCompara uma expressão com cada caso; padrão cobre a ausência de correspondência.Selecionar uma ação entre alternativas discretas.
tente / pegue / senão / finalmentePermite tratar uma falha, executar um ramo de sucesso opcional e uma etapa final.Importações ou operações que podem falhar em tempo de execução.
var notas = [8, 5.5, 9];
para (var i = 0; i < tamanho(notas); i = i + 1) {
  se (notas[i] >= 7) {
    escreva("Aprovada");
  } senãose (notas[i] >= 5) {
    escreva("Recuperação");
  } senão {
    escreva("Reprovada");
  }
}

Em para, as três partes podem ser omitidas individualmente. Um teste omitido não oferece condição de parada, então o laço continua até que o corpo o encerre com pausa. Ao depurar, registre valor inicial, teste, atualização e número de voltas. Em escolha, os casos usam igualdade estrita; mais de um caso pode ser executado se mais de um rótulo tiver o mesmo valor. pausa encerra a seleção; a ausência de padrão não faz nada quando nenhum caso corresponde.

A referência web mostra ponto e vírgula depois do exemplo fazer ... enquanto, mas o parser da tag 1.3.16 não consome esse terminador como parte do laço. Há outra diferença de grafia: o guia web atual escreve senão se com espaço, mas o lexer da tag reserva senãose como uma palavra. Os exemplos desta edição seguem a forma aceita pelo interpretador marcado. Em código destinado a essa versão, não misture convenções de versões diferentes.

08 · composição e reuso

Funções e parâmetros

Uma função nomeada usa função, nome, parâmetros e bloco. Ela pode executar efeitos, retornar um valor com retorna ou encerrar sem valor. As funções são chamadas com parênteses e argumentos posicionais; o exemplo recebe dois valores e devolve um resultado reutilizável.

função média(a, b) {
  retorna (a + b) / 2;
}
var resultado = média(8, 10);
escreva(resultado); // 9

O retorno encerra a execução da função naquele ponto. Se não houver retorno com valor, a chamada produz nulo. Uma função anônima usa a mesma palavra-chave, mas pode ser guardada em variável ou passada como argumento. Isso é útil com mapear, filtrar e reduzir, que recebem uma função de transformação, teste ou acumulação.

var dobrados = mapear([1, 2, 3], função(n) {
  retorna n * 2;
});
escreva(dobrados); // [2, 4, 6]

A gramática da versão 1.3.16 também admite parâmetros com valor padrão simples e um parâmetro final precedido de * para reunir argumentos restantes. Como esses detalhes não aparecem em todos os guias oficiais, confira-os no interpretador específico antes de usá-los em material compartilhado:

FormaExemploEfeito
Valor padrãofunção saudar(nome = "visitante") { ... }Usa o valor indicado se o argumento não for fornecido.
Argumentos restantesfunção somar(*valores) { ... }Agrupa os argumentos restantes em uma lista no parâmetro final.

Para manter chamadas fáceis de revisar, use poucos parâmetros, prefira nomes que expliquem o papel de cada argumento e retorne valores que possam ser testados separadamente. Uma função que calcula não precisa também imprimir: separar cálculo e apresentação permite reutilizar o resultado.

09 · orientação a objetos

Classes e objetos

classe descreve métodos e pode herdar de uma classe base com herda. Chamar o nome da classe cria uma instância. Métodos são declarados dentro das chaves sem escrever função; o método construtor recebe os argumentos usados na criação. Dentro de um método, isto referencia a instância atual.

classe Contador {
  construtor(valor_inicial) {
    isto.valor = valor_inicial;
  }

  avançar() {
    isto.valor = isto.valor + 1;
    retorna isto.valor;
  }
}

var contador = Contador(2);
escreva(contador.avançar()); // 3

Uma propriedade pode ser lida ou alterada com ponto, como contador.valor. A herança reutiliza métodos; super acessa um método definido na classe pai:

classe Animal {
  apresentar() {
    retorna "animal";
  }
}

classe Cachorro herda Animal {
  apresentar() {
    retorna super.apresentar() + " doméstico";
  }
}

var bicho = Cachorro();
escreva(bicho.apresentar());

Use uma classe quando várias instâncias precisarem guardar estados independentes com operações relacionadas. Se o problema exige apenas transformar uma entrada em uma saída, uma função tende a deixar a dependência mais visível. A documentação não apresenta palavras-chave de visibilidade como público e privado; não atribua a propriedades regras de encapsulamento que a linguagem não documenta.

Escolher uma operação pelo efeito esperado torna o código mais legível do que usar um laço com variáveis auxiliares para todos os casos.

As chamadas HTTP são síncronas e podem aguardar até 30 segundos. A documentação relata falha para erros de rede, URLs inválidas e respostas 4xx/5xx; não há suporte documentado a cabeçalhos personalizados. Evite essas chamadas em laços longos. Na biblioteca de tempo, respeite o formato explícito e teste datas de limite, como o último dia do mês.

var matemática = importar("matemática");
var notas = [6, 8, 10];
escreva(matemática.média(notas)); // 8

Importar uma biblioteca deixa explícita a dependência do programa. Não chame importar dentro de cada repetição: importe uma vez e reutilize o módulo.

12 · exemplo desenvolvido

Programa guiado: classificar e resumir notas

O exemplo combina uma função nomeada, um filtro, uma redução, uma condição e conversão para texto. Antes de executar, identifique os dados de entrada, a regra de aprovação e o caso em que a lista filtrada fica vazia.

função aprovado(nota) {
  retorna nota >= 7;
}

var notas = [8, 6, 9.5, 7, 5];
var aprovadas = filtrar(notas, aprovado);
var soma = reduzir(aprovadas, função(total, nota) {
  retorna total + nota;
}, 0);

escreva("Quantidade de notas:");
escreva(tamanho(notas));
escreva("Aprovadas:");
escreva(aprovadas);

se (tamanho(aprovadas) > 0) {
  var média = soma / tamanho(aprovadas);
  escreva("Média das aprovadas:");
  escreva(média);
} senão {
  escreva("Nenhuma nota atingiu a média.");
}

O acumulador de reduzir começa em zero e recebe cada nota aprovada somada ao total anterior. Para esta entrada, o filtro devolve [8, 9.5, 7], o acumulador termina em 24.5 e a média é aproximadamente 8.17.

EtapaValor observadoPor que importa
Entrada[8, 6, 9.5, 7, 5]Lista original, preservada pelo filtro.
Predicado aprovadoverdadeiro para 8, 9.5 e 7A regra está concentrada em um lugar.
Saída de filtrar[8, 9.5, 7]Itens para os quais a função retorna verdadeiro.
Redução0 → 8 → 17.5 → 24.5Mostra como cada item altera o acumulador.
Resultado24.5 / 3 ≈ 8.17A divisão só ocorre quando há pelo menos uma aprovação.

Para ampliar o exercício, conte as notas abaixo de 7 com outro filtro, calcule a maior nota com a biblioteca matemática ou receba uma lista diferente. Teste também []: o ramo alternativo deve ser executado sem tentar dividir por zero.

13 · leitura de falhas

Erros e depuração

Separe erros de escrita, de resolução de nomes e de execução. A mensagem costuma indicar o token ou a linha mais próxima do problema; a causa pode estar na instrução anterior, como uma chave ou ponto e vírgula ausente.

SintomaO que conferirAjuste típico
Esperava ; ou }Final da declaração e abertura/fechamento do bloco anterior.Feche cada instrução simples e confira pares de chaves.
Nome não reconhecidoGrafia, acento e escopo da variável.Declare antes de usar; confirme matemática e demais nomes acentuados.
Uma variável não pode ser lida no inicializadorDeclaração como var x = x;.Inicialize a partir de outro valor ou atribua depois da declaração.
+ falha em tempo de execuçãoUm lado é número e o outro é texto, ou tipos incompatíveis.Converta explicitamente com texto/real/inteiro quando apropriado.
Índice de lista sinaliza erroLista vazia, limite superior e cálculo do índice.Confira tamanho(lista) e teste a primeira/última posição.
pausa ou continua fora de laçoO bloco está dentro de enquanto, para ou fazer?Mova o controle para o corpo do laço correspondente.
Importação ou HTTP falhaNome do módulo, acentos, URL, rede e status da resposta.Confirme o módulo e trate falhas de rede em pegue.
  1. Reduza o programa até a menor sequência que ainda reproduz o problema.
  2. Mostre os valores intermediários com escreva, uma expressão por chamada.
  3. Teste limites: lista vazia, um item, índice inicial/final e os dois ramos de uma condição.
  4. Altere uma regra por vez e repita a mesma entrada para saber qual mudança corrigiu o resultado.
  5. Registre versão do interpretador, arquivo e entrada; isso ajuda a reconhecer diferenças entre versões.

14 · prática orientada

Roteiro de estudo

Uma sequência curta que usa o mesmo conjunto de ideias em problemas progressivamente maiores:

  1. Saída e expressões: calcule área e perímetro de um círculo. Verifique a precedência de multiplicação e potência e compare o resultado com uma conta manual.
  2. Decisões: classifique uma nota em três faixas. Crie entradas abaixo de 5, entre 5 e 7 e a partir de 7 para cobrir cada ramo.
  3. Repetições: percorra uma lista por índice. Registre o valor de i, a condição de parada e quantas vezes o corpo é executado.
  4. Funções: extraia a regra de aprovação para uma função que devolve um lógico. Teste-a isoladamente antes de aplicá-la à lista.
  5. Programação funcional: implemente filtro e média com as funções integradas; trate explicitamente lista vazia.
  6. Objetos e módulos: crie uma classe para guardar um estado que muda ao longo do tempo e importe somente uma biblioteca necessária ao exercício.

Em cada etapa, escreva também um caso que deveria falhar ou produzir outro ramo. Uma explicação do valor esperado antes da execução é uma forma simples de conferir se o algoritmo representa de fato o problema.

15 · escopo de compatibilidade

Versão e limites desta referência

Égua evolui junto com seu interpretador. O manual oficial, a aplicação online, o pacote publicado e implementações independentes podem não expor exatamente o mesmo conjunto de recursos. Esta página descreve a linguagem oficial tomando a versão 1.3.16 como referência e marca detalhes encontrados no código dessa versão quando o guia web é mais breve.

Em particular, o catálogo de funções e bibliotecas acima segue as páginas oficiais; os detalhes sobre precedência, parâmetros opcionais e terminadores de laço foram conferidos também no parser e no interpretador marcados como 1.3.16. Uma implementação que cubra apenas parte da linguagem pode não reconhecer listas, classes, exceções, importações ou bibliotecas descritas aqui. Confirme o quadro de compatibilidade do ambiente que executará seu programa antes de reutilizar os exemplos.
