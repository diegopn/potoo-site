01 · Escopo

Sobre o dialeto

Portugol é um nome usado por diferentes pseudolinguagens. Esta documentação trata especificamente do dialeto Portugol 2.0; as regras abaixo não definem um padrão universal para todas as pseudolinguagens chamadas Portugol.

A gramática e o léxico usados como base para esta referência estão indicados na seção de referências. Eles orientam o escopo do dialeto Portugol 2.0 adotado pelo Potoo IDE.

Objetivo do projeto: implementar o dialeto completo desta pseudolinguagem. Os recursos descritos nesta página não significam que já possam ser executados no aplicativo.

02 · Organização

Estrutura de um programa

Um arquivo começa com programa e um bloco delimitado por chaves. As inclusões de bibliotecas aparecem no início do bloco; depois podem vir declarações globais e funções. A forma usual de ponto de entrada é a função chamada inicio.

programa {
    inclua biblioteca Matematica --> mat

    const inteiro tentativas = 3
    inteiro acertos = 0

    funcao inicio() {
        escreva("Bem-vindo ao exercício")
    }
}

Blocos de funções, condições e laços usam { e }. O ponto e vírgula é usado nos três campos do cabeçalho de para; os exemplos tradicionais escrevem um comando por linha e não terminam cada comando com ponto e vírgula.

03 · Escrita

Nomes, comentários e literais

  • Identificadores começam com uma letra ASCII ou sublinhado; depois podem conter letras ASCII, dígitos e sublinhados. A gramática publicada não admite letras acentuadas em identificadores.
  • As palavras-chave são escritas sem acentos e a gramática as reconhece na forma minúscula, por exemplo programa, funcao e enquanto.
  • Comentários de linha começam com //; comentários de bloco ficam entre /* e */.
  • Números reais usam ponto como separador decimal. Textos usam aspas duplas e caracteres individuais usam aspas simples; o léxico também define escapes e literais hexadecimais.
  • Valores lógicos são verdadeiro e falso.
// comentário de linha
/* comentário
   em bloco */
cadeia mensagem = "Olá"
caracter inicial = 'A'
real media = 7.5
logico aprovado = verdadeiro

04 · Dados

Tipos, variáveis e constantes

TipoUso

caracterUm caractere.
cadeiaSequência de caracteres.
vazioIndica função sem valor de retorno.

Declare o tipo antes do nome. Uma declaração pode agrupar nomes do mesmo tipo e pode incluir uma expressão inicial. A palavra-chave const marca declarações constantes. Valores e tipos precisam ser compatíveis.

inteiro idade = 18, ano
real altura = 1.72
const real pi_aproximado = 3.14
cadeia nome = "Lia"
logico concluiu = falso

Uma variável declarada dentro de uma função ou bloco tem escopo local; declarações no corpo principal, fora das funções, são globais. A forma de uma lista de declarações também permite inicializadores de vetores e matrizes, detalhados na seção Vetores e matrizes.

05 · Expressões

Operadores e precedência

A gramática oficial define os operadores em alternativas recursivas, mas não publica uma tabela de precedência clara para todas as combinações. Use parênteses para explicitar a ordem, especialmente ao misturar comparações, lógica e operações bit a bit.

Prática recomendada: a própria regra gramatical traz uma observação de que igualdade tem prioridade baixa, então não dependa de uma ordem presumida para expressões compostas.

06 · Interação

Entrada e saída

escreva apresenta uma ou mais expressões. Para quebrar a linha, inclua a sequência de escape \n numa cadeia passada a essa função. leia recebe dados para variáveis. A função predefinida limpa() limpa a área de saída. A implementação independente do Potoo IDE também oferece escreva_linha como conveniência própria; ela não pertence ao dialeto oficial.

programa {
    funcao inicio() {
        cadeia nome
        escreva("Qual é o seu nome? ")
        leia(nome)
        escreva("Olá, ", nome, "!\n")
    }
}

A forma de exibir e ler dados pode depender da implementação da biblioteca ou do ambiente que executa o algoritmo. O Potoo IDE ainda não oferece esses fluxos dentro do aplicativo.

07 · Decisões

Condições e seleção

se executa um ramo quando a expressão lógica é verdadeira; senao define o ramo alternativo. Os blocos podem conter vários comandos. A seleção múltipla usa escolha, rótulos caso e o caso alternativo contrario.

se (nota >= 7) {
    escreva("Aprovado\n")
} senao {
    escreva("Continue praticando\n")
}

escolha (opcao) {
    caso 1:
        escreva("Iniciar\n")
        pare
    caso contrario:
        escreva("Opção desconhecida\n")
}

pare encerra o caso atual de escolha ou interrompe um laço. Use uma expressão do tipo lógico como condição.

08 · Laços

Repetição

O dialeto define laços condicionais e um laço com inicialização, condição e incremento:

inteiro contador = 1
enquanto (contador <= 3) {
    escreva(contador, "\n")
    contador++
}

faca {
    contador--
} enquanto (contador > 0)

para (inteiro i = 0; i < 3; i++) {
    escreva(i, "\n")
}

enquanto testa antes de cada repetição; faca ... enquanto testa depois do bloco. Em para, os campos são separados por ponto e vírgula e podem inicializar uma variável, testar uma condição e atualizar o contador. pare encerra o laço atual.

09 · Coleções

Vetores e matrizes

Vetores usam um índice entre colchetes; matrizes usam dois índices. Quando o tamanho é informado, deve ser uma expressão inteira constante e positiva; em declarações com inicializador, ele pode ser inferido. A gramática também permite matrizes inicializadas por linhas.

programa {
    funcao inicio() {
        inteiro notas[3] = {8, 9, 10}
        inteiro quadro[2][2] = {{1, 2}, {3, 4}}
        escreva(notas[0], "\n")
        escreva(quadro[1][0], "\n")
    }
}

Os índices são expressões inteiras. Parâmetros de função podem declarar dimensões sem fixar os tamanhos, por exemplo inteiro valores[] ou inteiro tabela[][].

10 · Reuso

Funções e parâmetros

Uma função pode declarar um tipo de retorno antes do nome; omitir o tipo equivale ao uso sem valor de retorno, que também pode ser escrito com vazio. Parâmetros têm tipo e nome, podem ser separados por vírgulas e podem receber vetores ou matrizes. Um & antes do nome indica passagem por referência.

funcao inteiro dobrar(inteiro valor) {
    retorne valor * 2
}

funcao atualizar(inteiro &total, inteiro acrescimo) {
    total += acrescimo
}

funcao inicio() {
    inteiro resultado = dobrar(4)
    atualizar(resultado, 1)
    escreva(resultado, "\n")
}

retorne encerra a função e pode devolver uma expressão. A referência oficial descreve chamadas de função em expressões, funções com retorno e funções sem retorno.

12 · Exemplo

Programa completo

Este exemplo junta declaração, entrada e saída, condição, função e expressão lógica:

programa {
    funcao logico eh_par(inteiro numero) {
        retorne numero % 2 == 0
    }

    funcao inicio() {
        inteiro valor
        escreva("Digite um número inteiro: ")
        leia(valor)

        se (eh_par(valor)) {
            escreva("O número é par\n")
        } senao {
            escreva("O número é ímpar\n")
        }
    }
}

13 · Compatibilidade

O que já funciona no Potoo IDE

O Potoo IDE está em desenvolvimento e ainda não integra o interpretador à aplicação desktop. Portanto, esta página é uma referência do dialeto desejado, não uma lista de recursos disponíveis no aplicativo.

O repositório do Potoo IDE contém uma implementação independente da pseudolinguagem Portugol 2.0. Ela cobre um subconjunto: estrutura de programa e funções, declarações, tipos, vetores e matrizes, passagem por valor e referência, operadores, controle de fluxo, entrada e saída e partes das bibliotecas Matematica, Texto, Tipos e Util. Essa implementação ainda é parcial; bibliotecas como Calendario, Objetos e Arquivos não estão disponíveis nela.

Em desenvolvimento: a meta é avançar para o dialeto completo. Até a integração com a interface desktop acontecer, não é possível escrever ou executar esses exemplos no Potoo IDE.

14 · Leitura adicional

Referências da pseudolinguagem Portugol 2.0

O dialeto Portugol 2.0 documentado nesta página tem origem no Portugol Studio. Essa ferramenta aparece aqui somente como fonte de referência; o nome usado pelo Potoo IDE para a pseudolinguagem é Portugol 2.0.

  • Repositório oficial do Portugol Studio, que identifica a pseudolinguagem como Portugol 2.0.
  • Gramática oficial e léxico oficial.
  • Ajuda oficial de entrada e saída, incluindo o uso de \n para pular linha, e analisador semântico, que lista as funções predefinidas.
  • Código-fonte das bibliotecas padrão e suas funções documentadas.
  • Implementação de Portugol 2.0 no Potoo IDE, sua referência de compatibilidade e o subconjunto implementado.

As referências são mantidas por projetos distintos. Consulte-as para conferir detalhes de comportamento e compatibilidade antes de usar uma função específica.
