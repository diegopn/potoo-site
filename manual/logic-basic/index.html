01 · Visão geral

Sobre Logic Basic

Logic Basic é uma linguagem de programação associada a um ambiente visual: além do código, o programa pode interagir com uma janela, componentes, desenhos, sons e arquivos de dados. O manual do autor apresenta a linguagem por comandos e exercícios progressivos, com uma abordagem voltada a iniciantes.

Esta referência resume os conceitos e as formas de escrita documentados no manual consultado. Como o material é organizado por comandos e recursos do ambiente, consulte a fonte para obter detalhes de cada opção visual.

02 · Organização

Programa, janela e arquivo

O manual descreve duas áreas de trabalho: o código e a janela em que o programa apresenta resultados e componentes. A execução percorre o código em sequência até o final ou até encontrar FimPrograma ou FimJanela. Arquivos de código são identificados pela extensão .LBC.

Uma linha pode conter vários comandos separados por ponto e vírgula; cada comando separado é tratado como uma linha lógica. O apóstrofo introduz um comentário no código.

Memoria Nome
Nome = "Ana"
Posicione 1, 1
Escreva "Olá, ", Nome
FimPrograma

03 · Dados

Memórias e valores

Memoria cria os nomes usados para guardar valores. O manual recomenda colocar essas declarações no início do código principal. Uma memória pode conter texto, números e elementos do ambiente visual, como objetos e sons. O mesmo nome pode receber um valor novo durante a execução.

Memoria Nome, Pontos, Fundo
Nome = "Ana"
Pontos = 12
Fundo = "fundo-verde"

Textos ficam entre aspas. Um número sem aspas é tratado como número e pode participar de cálculos; entre aspas, é texto. O manual usa vírgula como separador decimal, por exemplo 3,5. Nomes de memórias não contêm espaços.

04 · Expressões

Atribuição e operadores

Fora de uma condição, = atribui um valor. Em uma condição, = compara valores. A linguagem documenta operações aritméticas, atualizações compostas e comparações. SIM e NAO representam valores lógicos nos exemplos do manual.

Atualização++ -- += -=Incrementar, decrementar ou atualizar um valor.
Comparação= < > <= >= <>Testar igualdade e ordem dentro de uma condição.
LógicosE OUCombinar condições.

Y = 3

Escreva "Atingiu o valor"

Os operadores e o tratamento de números seguem o manual do Logic Basic. A grafia dos nomes de comandos nos exemplos acompanha a forma apresentada pelo autor.

05 · Interação

Entrada, mensagens e saída

Escreva apresenta um ou mais itens na janela, na ordem em que aparecem. Posicione define a posição da saída e LimpaJanela limpa a área visual. Mensagem exibe uma mensagem em uma caixa de diálogo.

EntraTexto solicita um texto e retorna o que foi digitado para uma memória. O manual também descreve componentes de interface como caixas de texto, listas, opções e caixas de seleção; seus valores podem ser lidos com Componente Valor.

Memoria Nome
Nome = EntraTexto, "Digite seu nome:"
LimpaJanela
Posicione 1, 1
Escreva "Olá, ", Nome
Mensagem "Cadastro concluído"

06 · Decisões e repetição

Se, CasoContrario e VaPara

Se executa instruções quando uma condição é verdadeira. CasoContrario define a alternativa opcional e FimSe encerra o bloco. Para repetir comandos, o manual apresenta rótulos e o comando VaPara, que transfere a execução para uma linha identificada pelo nome.

Memoria Tentativa
Tentativa = 0
INICIO
Tentativa = Tentativa + 1
Escreva "Tentativa ", Tentativa
Se Tentativa < 3
VaPara INICIO
CasoContrario
Escreva "Fim das tentativas"
FimSe

Essa forma permite construir laços, mas exige controlar explicitamente o estado que encerra a repetição. Um salto incorreto pode fazer o programa repetir sem fim.

07 · Reuso

Funções e extensões

O manual descreve rotinas nomeadas fora do fluxo principal. Execute Nome() chama uma rotina e Retorne devolve a execução ao comando seguinte ao ponto de chamada. Uma rotina pode chamar outras rotinas e pode ser recursiva. O material também apresenta painéis de extensão para organizar códigos reutilizáveis.

Escreva "Antes da rotina"
Execute Saudacao()
Escreva "Depois da rotina"
FimPrograma

Saudacao()
Escreva "Olá!"
Retorne

Use nomes de rotina consistentes e garanta que toda execução que entra nela alcance Retorne, evitando que o fluxo continue para instruções que não fazem parte da rotina.

08 · Coleções

Matrizes

Uma memória pode ser declarada com quantidade de posições entre parênteses. Os índices começam em zero. Por exemplo, Memoria Nome(20) cria posições de Nome(0) até Nome(19). Uma variável numérica pode servir como índice dentro de uma rotina de repetição.

Memoria Nome(3), I
Nome(0) = "Ana"
Nome(1) = "Beto"
Nome(2) = "Caio"
I = 0
INICIO
Escreva Nome(I)
I = I + 1
Se I < 3
VaPara INICIO
FimSe

ProcureMatriz procura um valor em uma matriz e retorna o índice correspondente; quando não encontra o valor, o manual descreve o retorno -1.

09 · Recursos visuais

Janela, componentes e multimídia

Os comandos visuais podem posicionar texto, desenhar objetos, exibir imagens e responder a interações. Componente cria controles de formulário; Desenhe apresenta objetos ou recursos visuais; Aguarde pausa a execução ou recebe uma interação conforme os argumentos descritos no manual.

O material também documenta recursos de mouse, som e vídeo. A organização de canais, posições, dimensões e controles depende dos parâmetros de cada comando; consulte a fonte antes de usar as opções avançadas.

LimpaJanela
Posicione 5, 5
Desenhe "personagem"
Aguarde

10 · Dados persistentes

Banco de dados nativo

O manual descreve blocos BD ... FimBD para definir campos e o comando AbreBD para abrir um arquivo de dados. Campos são preenchidos por meio do nome do banco e do campo; AdicionaRegistro grava um registro, LeRegistro lê pela posição, e FechaBD fecha o arquivo. Também são descritos comandos para ordenar, procurar e contar registros.

ComandoFinalidade no manual
BD ... FimBDDefinir os campos de uma tabela.
AbreBD / FechaBDAbrir ou fechar o arquivo associado.
AdicionaRegistroGravar os campos preenchidos como novo registro.
LeRegistroLer um registro pela posição.
OrdemBD, ProcureOrdenar ou localizar registros.
TotalRegistrosObter a quantidade de registros.

O banco usa arquivos próprios e uma definição de campos. Antes de gravar ou ler registros, siga a sequência de abertura e fechamento descrita no manual.

11 · Aplicação

Exemplo integrado

O exemplo usa memórias, entrada e condição para apresentar uma saudação personalizada. Ele reúne os comandos básicos sem depender de recursos gráficos avançados.

Memoria Nome, Pontos
Nome = EntraTexto, "Qual é o seu nome?"
Pontos = 0
LimpaJanela
Posicione 1, 1
Escreva "Bem-vindo, ", Nome
Se Nome = ""
Mensagem "Informe um nome para continuar"
CasoContrario
Pontos = Pontos + 1
Escreva "Pontos: ", Pontos
FimSe
FimPrograma
