01 · Visão geral

Sobre Logic Basic

Logic Basic é uma linguagem de programação associada a um ambiente visual: além do código, o programa pode interagir com uma janela, componentes, desenhos, sons e arquivos de dados. O manual do autor apresenta a linguagem por comandos e exercícios progressivos, com uma abordagem voltada a iniciantes.

Esta referência resume os conceitos e as formas de escrita documentados no manual consultado. Como o material é organizado por comandos e recursos do ambiente, consulte a fonte para obter detalhes de cada opção visual.

02 · Organização

Programa, janela e arquivo

O manual descreve duas áreas de trabalho: o código e a janela em que o programa apresenta resultados e componentes. A execução percorre o código em sequência até o final ou até encontrar FimPrograma ou FimJanela. Arquivos de código são identificados pela extensão .LBC.

Uma linha pode conter vários comandos separados por ponto e vírgula; cada comando separado é tratado como uma linha lógica. O apóstrofo introduz um comentário no código.

Memoria Nome
Nome = "Ana"
Posicione 1, 1
Escreva "Olá, ", Nome
FimPrograma

Ordem do programa e extensões

O arquivo principal é executado em sequência, da primeira instrução à última. FimPrograma encerra essa sequência e mantém a janela aberta para leitura; FimJanela também fecha a janela. As extensões de código funcionam como trechos anexados ao código principal e são um lugar documentado para guardar rotinas chamadas pelo programa. O material consultado recomenda declarar memórias no início do código principal.

ElementoQuando usarEfeito documentado
MemoriaNo cabeçalho do código principal.Cria nomes que podem guardar valores e recursos.
Extensão numeradaPara separar rotinas do fluxo principal.É anexada ao código principal durante a execução.
FimProgramaAo terminar o algoritmo e preservar a janela.Interrompe o programa.
FimJanelaQuando também se deseja fechar a janela.Interrompe o programa e fecha a janela.

03 · Dados

Memórias e valores

Memoria cria os nomes usados para guardar valores. O manual recomenda colocar essas declarações no início do código principal. Uma memória pode conter texto, números e elementos do ambiente visual, como objetos e sons. O mesmo nome pode receber um valor novo durante a execução.

Memoria Nome, Pontos, Fundo
Nome = "Ana"
Pontos = 12
Fundo = "fundo-verde"

Textos ficam entre aspas. Um número sem aspas é tratado como número e pode participar de cálculos; entre aspas, é texto. O manual usa vírgula como separador decimal, por exemplo 3,5. Nomes de memórias não contêm espaços.

Ler a forma do valor

A declaração Memoria lista os nomes que o programa poderá usar; o valor atribuído depois determina como ele participa da expressão. As aspas fazem diferença: texto numérico entre aspas continua sendo texto. O manual consultado não apresenta declarações de tipo para essas memórias.

FormaExemploLeitura
Texto literalNome = "Ana"Guarda caracteres entre aspas.
NúmeroPontos = 12Valor numérico que pode ser usado em cálculos.
Texto que parece númeroPontos = "12"Continua sendo texto; não trate como o número 12.
Memória indexadaNome(0)Consulta uma posição de uma matriz declarada com tamanho.

04 · Expressões

Atribuição e operadores

Fora de uma condição, = atribui um valor. Em uma condição, = compara valores. A linguagem documenta operações aritméticas, atualizações compostas e comparações. SIM e NAO representam valores lógicos nos exemplos do manual.

Aritméticos+ - * / %Cálculo e resto da divisão.
Atualização++ -- += -=Incrementar, decrementar ou atualizar um valor.
Comparação= < > <= >= <>Testar igualdade e ordem dentro de uma condição.
LógicosE OUCombinar condições.
Memoria X, Y, Soma
X = 8
Y = 3
Soma = X + Y
Soma += 1
Se Soma >= 12
Escreva "Atingiu o valor"
FimSe

Os operadores e o tratamento de números seguem o manual do Logic Basic. A grafia dos nomes de comandos nos exemplos acompanha a forma apresentada pelo autor.

05 · Interação

Entrada, mensagens e saída

Escreva apresenta um ou mais itens na janela, na ordem em que aparecem. Posicione define a posição da saída e LimpaJanela limpa a área visual. Mensagem exibe uma mensagem em uma caixa de diálogo.

EntraTexto solicita um texto e retorna o que foi digitado para uma memória. O manual também descreve componentes de interface como caixas de texto, listas, opções e caixas de seleção; seus valores podem ser lidos com Componente Valor.

Memoria Nome
Nome = EntraTexto, "Digite seu nome:"
LimpaJanela
Posicione 1, 1
Escreva "Olá, ", Nome
Mensagem "Cadastro concluído"

Referência dos comandos de interação

Os argumentos de um comando são separados por vírgulas. Em Escreva, cada argumento é apresentado em sequência; aspas distinguem um texto literal do nome de uma memória. A janela padrão usa coordenadas iniciadas em zero, mas o próprio comando Janela pode mudar sua resolução.

FormaResultadoDetalhe importante
Posicione linha, colunaDefine o ponto da próxima saída na janela.Na configuração padrão, a grade tem 27 linhas e 79 colunas, de 0 a 26 e de 0 a 78.
Escreva expressão, ...Apresenta argumentos na janela, na mesma linha lógica.Um texto literal fica entre aspas; uma memória sem aspas fornece seu conteúdo.
Mensagem textoAbre uma caixa de mensagem centralizada.Não usa a posição definida por Posicione.
nome = EntraTexto, perguntaSolicita texto e coloca a resposta na memória.A memória precisa ter sido declarada.
Componente Valor, nomeLê o valor preenchido em um controle.O controle é criado antes com Componente.
AguardePausa até uma interação ou um tempo configurado.Pode aguardar tecla, clique em botão/objeto ou uma quantidade de segundos; o resultado da interação pode ficar em Retorno.

Um ponto e vírgula permite colocar vários comandos na mesma linha física, mas o manual considera cada comando separado como uma linha lógica. Isso importa ao ler o depurador e ao usar saltos para rótulos.

06 · Decisões e repetição

Se, CasoContrario e VaPara

Se executa instruções quando uma condição é verdadeira. CasoContrario define a alternativa opcional e FimSe encerra o bloco. Para repetir comandos, o manual apresenta rótulos e o comando VaPara, que transfere a execução para uma linha identificada pelo nome.

Memoria Tentativa
Tentativa = 0
INICIO
Tentativa = Tentativa + 1
Escreva "Tentativa ", Tentativa
Se Tentativa < 3
VaPara INICIO
CasoContrario
Escreva "Fim das tentativas"
FimSe

Essa forma permite construir laços, mas exige controlar explicitamente o estado que encerra a repetição. Um salto incorreto pode fazer o programa repetir sem fim.

Consulta das formas de controle

FormaEfeitoPonto de atenção
Se condição ... FimSeExecuta o bloco quando a comparação é verdadeira.= compara dentro da condição, embora atribua fora dela.
CasoContrarioMarca o bloco alternativo de um Se.Use-o dentro do bloco correspondente e feche com FimSe.
ROTULO seguido de VaPara ROTULORetoma a execução na linha identificada pelo rótulo.Atualize o valor que controla a condição antes de saltar de novo.

O salto implementa a repetição por meio do fluxo do programa: o rótulo marca o início, e a condição decide se a execução retorna. Antes de executar, percorra uma iteração à mão e confirme que o valor testado muda em direção à saída.

07 · Reuso

Funções e extensões

O manual descreve rotinas nomeadas fora do fluxo principal. Execute Nome() chama uma rotina e Retorne devolve a execução ao comando seguinte ao ponto de chamada. Uma rotina pode chamar outras rotinas e pode ser recursiva. O material também apresenta painéis de extensão para organizar códigos reutilizáveis.

Escreva "Antes da rotina"
Execute Saudacao()
Escreva "Depois da rotina"
FimPrograma

Saudacao()
Escreva "Olá!"
Retorne

Use nomes de rotina consistentes e garanta que toda execução que entra nela alcance Retorne, evitando que o fluxo continue para instruções que não fazem parte da rotina.

Rotinas, chamadas e retorno

Uma rotina nomeada fica depois do encerramento do programa principal ou em uma extensão. A chamada Execute Nome() transfere o controle para ela; Retorne volta ao comando que vem após a chamada. O manual introdutório apresenta esse retorno como fluxo de execução, não como uma expressão que devolve um valor calculado. Para trocar dados nos exemplos básicos, declare memórias e leia ou atualize seu conteúdo dentro da rotina.

Memoria Resultado
Resultado = "pronto"
Execute ExibaResultado()
FimPrograma

ExibaResultado()
Escreva "Estado: ", Resultado
Retorne

Separe uma rotina quando um conjunto de comandos tiver uma responsabilidade reconhecível ou for chamado de mais de um lugar. Em uma rotina recursiva, cada caminho precisa chegar a um caso que pare ou a um Retorne; sem isso, as chamadas podem continuar se acumulando.

08 · Coleções

Matrizes

Uma memória pode ser declarada com quantidade de posições entre parênteses. Os índices começam em zero. Por exemplo, Memoria Nome(20) cria posições de Nome(0) até Nome(19). Uma variável numérica pode servir como índice dentro de uma rotina de repetição.

Memoria Nome(3), I
Nome(0) = "Ana"
Nome(1) = "Beto"
Nome(2) = "Caio"
I = 0
INICIO
Escreva Nome(I)
I = I + 1
Se I < 3
VaPara INICIO
FimSe

ProcureMatriz procura um valor em uma matriz e retorna o índice correspondente; quando não encontra o valor, o manual descreve o retorno -1.

09 · Recursos visuais

Janela, componentes e multimídia

Os comandos visuais podem posicionar texto, desenhar objetos, exibir imagens e responder a interações. Componente cria controles de formulário; Desenhe apresenta objetos ou recursos visuais; Aguarde pausa a execução ou recebe uma interação conforme os argumentos descritos no manual.

O material também documenta recursos de mouse, som e vídeo. A organização de canais, posições, dimensões e controles depende dos parâmetros de cada comando; consulte a fonte antes de usar as opções avançadas.

LimpaJanela
Posicione 5, 5
Desenhe "personagem"
Aguarde

Depurar seguindo o estado do programa

O modo Depurar do ambiente mostra as linhas de comando conforme são executadas. Compare a instrução atual com o resultado na janela e com os valores das memórias usadas. O manual recomenda conferir se toda memória foi declarada e se o comando está escrito corretamente.

SintomaO que conferir primeiro
Um nome é exibido literalmente.Verifique se ele foi declarado com Memoria e recebeu o valor esperado.
O texto aparece em outro ponto.Confira a ordem dos argumentos de Posicione linha, coluna e se as coordenadas cabem na resolução da janela.
O laço não termina.Observe se a memória testada em Se muda antes do salto VaPara.
Uma rotina não retorna ao ponto de chamada.Localize o caminho executado e confirme que alcança Retorne.
Uma interação não atualiza a memória.Confira se o controle foi criado antes da leitura e se a resposta é obtida por Componente Valor ou Retorno, conforme o comando.

10 · Dados persistentes

Banco de dados nativo

O manual descreve blocos BD ... FimBD para definir campos e o comando AbreBD para abrir um arquivo de dados. Campos são preenchidos por meio do nome do banco e do campo; AdicionaRegistro grava um registro, LeRegistro lê pela posição, e FechaBD fecha o arquivo. Também são descritos comandos para ordenar, procurar e contar registros.

ComandoFinalidade no manual
BD ... FimBDDefinir os campos de uma tabela.
AbreBD / FechaBDAbrir ou fechar o arquivo associado.
AdicionaRegistroGravar os campos preenchidos como novo registro.
LeRegistroLer um registro pela posição.
OrdemBD, ProcureOrdenar ou localizar registros.
TotalRegistrosObter a quantidade de registros.

O banco usa arquivos próprios e uma definição de campos. Antes de gravar ou ler registros, siga a sequência de abertura e fechamento descrita no manual.

Esquema, abertura e índices

A declaração BD associa um nome lógico a um caminho e enumera os campos da tabela com seus tamanhos; ela fica no cabeçalho, depois de Memoria. O arquivo de dados recebe a extensão .LBA, que pode ser omitida em AbreBD. Cada banco só pode manter um arquivo aberto por vez: feche-o antes de selecionar outro arquivo para esse mesmo esquema.

Os registros são indexados a partir de zero. Se TotalRegistros devolve T, os índices válidos vão de 0 a T - 1. OrdemBD deve ser executado antes da rotina que usa a ordenação; após definir um índice, as leituras seguem essa ordem até selecionar Sequencial ou outra ordenação. Procure usa o índice atual e devolve -1 quando não encontra o registro.

Uma sequência segura para uma operação é: definir campos, abrir um arquivo, preencher os campos do registro e gravar com AdicionaRegistro; para consultar, obter a contagem ou localizar uma posição, ler com LeRegistro e fechar com FechaBD ao terminar.

11 · Aplicação

Exemplo integrado

O exemplo usa memórias, entrada e condição para apresentar uma saudação personalizada. Ele reúne os comandos básicos sem depender de recursos gráficos avançados.

Memoria Nome, Pontos
Nome = EntraTexto, "Qual é o seu nome?"
Pontos = 0
LimpaJanela
Posicione 1, 1
Escreva "Bem-vindo, ", Nome
Se Nome = ""
Mensagem "Informe um nome para continuar"
CasoContrario
Pontos = Pontos + 1
Escreva "Pontos: ", Pontos
FimSe
FimPrograma
