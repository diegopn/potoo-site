01 · Visão geral

Sobre Linotte

Linotte é um projeto didático cuja sintaxe usa palavras e frases em francês. O projeto oficial apresenta um ambiente para aprender fundamentos de programação e mantém exemplos que percorrem variáveis, interação, condições, repetições, cálculos e funções.

O código desta referência permanece em francês para que os exemplos possam ser comparados com os arquivos originais. Traduzir palavras como affiche, prend ou ferme mudaria a sintaxe.

02 · Organização

Programa e comentários

Um programa Linotte é escrito como um conjunto de instruções no arquivo do projeto. Os exemplos introdutórios não exigem um bloco externo para envolver todo o programa. Uma instrução pode ocupar uma linha; blocos maiores são fechados com ferme.

Comentários de linha começam com //. Comentários de várias linhas ficam entre /* e */.

affiche "Bonjour !"
// Este comentário termina no fim da linha.

/*
Este bloco inteiro é ignorado
durante a interpretação.
*/

03 · Dados

Variáveis e valores

Linotte descreve variáveis como atores: cada ator tem nome, papel (seu tipo) e valor. O guia introdutório apresenta cinco papéis básicos: texte, nombre, drapeau, casier e espèce. Um papel pode ser declarado com est un; se a declaração for omitida, o tipo pode ser inferido pelo primeiro valor atribuído com prend.

prénom est un texte
prénom prend "Clément"
affiche prénom
prénom prend "Jade"

compteur est un nombre
compteur prend 10
compteur prend compteur + 1

actif est un drapeau
actif prend vrai

mois est un casier de textes valant "janvier", "février", "mars"

drapeau guarda um valor lógico, vrai ou faux. As palavras que indicam tipos e valores de texto são escritas em francês. Nomes de atores podem conter acentos, como prénom.

04 · Interação

Entrada e saída

affiche mostra uma expressão. demande solicita ao usuário um valor e o armazena na variável indicada; antes da leitura, a variável é declarada com seu tipo.

prénom est un texte
affiche "Quel est ton prénom ?"
demande prénom
affiche "Bonjour " + prénom

A forma questionne prénom sur "Quel est ton prénom ?" combina a pergunta e a leitura do valor em uma instrução.

Textos e expressões podem ser unidos com +. A exibição de números e textos segue o tipo dos valores e as conversões oferecidas pelo ambiente.

06 · Decisões

Condições

si inicia uma condição e sinon introduz o caminho alternativo. Uma instrução simples pode seguir a condição na mesma linha; blocos com várias instruções terminam com ferme.

note est un nombre
age est un nombre
note prend 12
age prend 20

si note >= 10 affiche "Très bien !"
sinon affiche "Continue à pratiquer"

si age >= 18
    affiche "Adulte"
    affiche "Accès autorisé"
ferme
sinon
    affiche "Mineur"
ferme

As condições podem comparar valores ou testar um valor lógico. Os operadores relacionais mostrados nos exemplos são =, !=, >, <, >= e <=.

07 · Repetição

Repetições

pour percorre uma sequência numérica com os limites inicial e final incluídos. Para um bloco com várias instruções, use a forma em linhas e feche com ferme. Nos exemplos atuais do repositório para a versão 3.14, pour chaque item de casier percorre uma coleção e associa cada item a um ator nomeado. O tutorial geral de Linotte 3 também documenta a forma compacta pour chaque casier, que disponibiliza o item em joker.

compteur est un nombre
pour compteur de 1 à 5 affiche compteur

pour compteur de 1 à 3
    affiche compteur
    attends 200 millisecondes
ferme

mois est un casier de textes valant "janvier", "février", "mars"
mois_courant est un texte
pour chaque mois_courant de mois
    affiche mois_courant
ferme

Escolha limites que correspondam à quantidade de passos pretendida. Nos exemplos desta página, use o ator nomeado ao percorrer uma coleção em Linotte 3.14; reserve joker para reconhecer a forma compacta do tutorial ou os laços numéricos que o utilizam.

08 · Reuso

Funções e valores de retorno

Uma função é introduzida pelo nome seguido de dois-pontos e pelos parâmetros. O corpo pode declarar variáveis locais, executar condições e retornar um resultado com retourne. Funções também podem chamar a si próprias.

double : nombre
    retourne nombre * 2

fibonacci : n
    si n < 2 retourne n
    sinon retourne fibonacci(n - 1) + fibonacci(n - 2)

A chamada de uma função aparece após seu nome, com argumentos entre parênteses. Os exemplos oficiais usam funções para separar cálculos e compor mensagens.

09 · Organização de dados

Coleções e extensões

O casier agrupa valores para percorrê-los com pour chaque item de casier. Os recursos do ambiente Linotte vão além das construções centrais: o repositório oficial inclui exemplos visuais e bibliotecas adicionais. Esses recursos dependem do ambiente e não devem ser confundidos com instruções disponíveis em todos os contextos.

nombres est un casier de nombres valant 2, 4, 6
valeur est un nombre
pour chaque valeur de nombres
    affiche valeur * valeur
ferme

Para compreender um recurso específico, confira o exemplo que o acompanha e a documentação do componente correspondente no projeto original.

10 · Exemplo integrado

Notas, função e média

prénoms est un casier de textes valant "Lia", "Caio", "Noa"
notes est un casier de nombres
indice est un nombre
seuil est un nombre
note est un nombre
total est un nombre
quantite est un nombre
moyenne est un nombre

total prend 0
quantite prend 0
affiche "Quelle note minimale permet d'atteindre l'objectif ?"
demande seuil

pour indice de 0 à 2
    ajoute question(prénoms{indice}) dans notes
ferme

pour chaque note de notes
    total prend total + note
    quantite prend quantite + 1
    si note >= seuil
        affiche note + " : objectif atteint"
    sinon
        affiche note + " : en dessous de l'objectif"
    ferme
ferme

moyenne prend total / quantite
affiche "Moyenne : " + moyenne
si moyenne >= seuil
    affiche "Objectif moyen atteint"
sinon
    affiche "Objectif moyen non atteint"
ferme

question : prénom
    valeur est un nombre
    affiche "Quelle est la note de " + prénom + " ?"
    demande valeur
    retourne valeur

O programa coleta três notas, guarda os valores em um casier, compara cada nota com o limite informado e calcula a média. A função question separa a leitura; o laço explícito associa cada item a um ator nomeado.

11 · Coleções

Acesso a coleções e iteração

Um casier reúne valores com o mesmo papel e permite percorrê-los sem repetir instruções. Nos exemplos oficiais, os índices começam em zero: em um casier com três elementos, as posições são 0, 1 e 2. A forma com chaves lê o valor de uma posição; ajoute insere um resultado em outra coleção.

nomes est un casier de textes valant "Lia", "Caio", "Noa"
indice est un nombre
nom_courant est un texte
pour indice de 0 à 2
    affiche nomes{indice}
ferme

pour chaque nom_courant de nomes
    affiche nom_courant
ferme

Nos exemplos da versão 3.14, pour chaque nom_courant de nomes associa o elemento atual ao ator indicado. O tutorial geral também mostra a forma compacta com joker; ambas devem ser identificadas ao consultar materiais de Linotte 3.

12 · Escrita compacta

Atalhos e interpolação

Além das instruções por extenso, o tutorial oficial apresenta formas compactas para exibir, solicitar e atribuir valores. Elas tornam alguns exemplos menores, mas não mudam o papel da operação. A interpolação coloca o valor de um ator entre chaves no texto.

prénom est un texte
prénom ?                    // pergunta pelo valor
"Bonjour, {prénom} !" !     // mostra o texto interpolado
prénom = "Jules"            // forma compacta de prend
"Bonjour, " & prénom !

O símbolo & pode agrupar ações ou valores em formas abreviadas documentadas; § pode substituir ferme em alguns exemplos. Para explicar um algoritmo ou facilitar a leitura, prefira primeiro as formas completas.

13 · Operações prontas

Funções integradas

Os exemplos oficiais incluem operações numéricas e métodos para transformar ou consultar textos. A notação de algumas funções é prefixada, como carré 4; métodos de texto são chamados depois do valor, com ponto e parênteses.

14 · Modelagem

Espécies e protótipos

Uma espèce define um tipo próprio de ator com atributos. A declaração lista os papéis dos atributos; a criação de um ator fornece seus valores. Para ler um atributo, os exemplos usam tanto a forma atributo de ator quanto atributo@ator.

espèces
    nom & famille est un texte
    pattes est un nombre
    espèce animal contient nom, famille, pattes

principal :
    chat est un animal, nom prend "Mimi", famille prend "félin", pattes prend 4
    affiche nom de chat
    affiche famille@chat

Uma espécie pode herdar de outra e acrescentar atributos. O ambiente também permite anexar funções a protótipos e criar instâncias com comportamento; esses recursos estendem o modelo simples de dados e devem ser lidos na seção avançada do tutorial.

espèces
    couleur est un texte
    espèce fleur hérite de point et contient couleur

15 · Recursos do Atelier

Eventos, gráficos e tarefas

Os recursos gráficos e de interação dependem do Atelier e da versão. O exemplo oficial 17_cassebrique.liv, associado à versão 3.14, combina atores gráficos, um casier de objetos, colisões e repetição. Este trecho reduzido mostra a iteração explícita usada nesses exemplos:

balle est un cercle, x vaut 200, y vaut 60, rayon vaut 10, plein vaut vrai, couleur vaut "rouge"
cibles est un casier de rectangle
position est un nombre
pour position de 0 à 2
    cible est un rectangle, x vaut 30 + 65 * position, y vaut 10, largeur vaut 50, hauteur vaut 20, plein vaut vrai
    ajoute cible dans cibles
ferme
cible est un rectangle, visible vaut faux
pour chaque cible de cibles
    si balle.collision(cible)
        efface cible
    ferme
ferme

O tutorial geral de Linotte 3 também mostra eventos de mouse e tarefas iniciadas com appelle e acompanhadas com observe. A sintaxe e a disponibilidade desses recursos devem ser conferidas no Atelier instalado.

16 · Diagnóstico

Erros e depuração

O tutorial do Atelier mostra um bloco essaie com uma alternativa sinon para tratar um erro durante a execução. A instrução débogue inicia o acompanhamento passo a passo na interface do Atelier.

  • Leia a mensagem de erro e identifique a instrução que estava sendo executada.
  • Avance uma instrução por vez e acompanhe os atores usados pela condição ou pelo cálculo.
  • Em uma repetição, confirme que o estado muda e que a condição de saída pode se tornar verdadeira ou falsa como esperado.
  • Teste coleções vazias, um único elemento e índices de início e fim.

O formato e a disponibilidade desses recursos dependem do Atelier Linotte. Os exemplos servem para explicar o ambiente de referência, não para pressupor uma interface gráfica em toda implementação.

Referência do modelo da linguagem

O parágrafo chamado principal é o nome usado nos exemplos para organizar a sequência principal. A execução começa pelo primeiro parágrafo executável do livro; principal não é uma palavra reservada.

Modelo do programa e referência de conceitos

Linotte usa metáforas de livro, parágrafo, papel e ator para tornar a estrutura visível. Elas também são conceitos operacionais: o livro reúne parágrafos; um parágrafo organiza papéis e ações; o ator guarda um valor; e certas ações percorrem coleções ou devolvem um resultado.

TermoFunção na linguagemForma que aparece nos exemplos

ParágrafoSequência nomeada de ações; principal é o ponto de entrada nos exemplos desta referência.principal : e um nome seguido de dois-pontos.
Papel / atorO papel declara a espécie de valor; o ator é a variável que o recebe.compteur est un nombre
AçãoComando executável que mostra, lê, atribui, compara ou percorre dados.affiche, demande, prend, si, pour.
jokerAtor implícito usado em formas compactas de repetição e em exemplos numéricos.pour chaque casier no tutorial geral; laços 3.14 também podem nomear o ator do item.

Um casier é útil quando vários valores do mesmo papel precisam ser tratados como um conjunto. Nos exemplos de Linotte 3.14, pour chaque item de casier associa o elemento atual a um ator nomeado. O tutorial geral também documenta a forma compacta com joker; laços numéricos podem usar joker como valor corrente.

Exemplo calculado: somar um casier

O acumulador começa em zero e recebe cada um dos três valores:

notes est un casier de nombres valant 7, 10, 12
total est un nombre
note est un nombre
total prend 0
pour chaque note de notes
    total prend total + note
ferme
affiche total
Item atual (note)Total antesTotal depois
707
10717

Se a coleção estiver vazia, o corpo não altera o acumulador, que permanece 0. Na forma explícita, o ator indicado no laço recebe cada elemento; o nome do casier continua representando a coleção inteira.
