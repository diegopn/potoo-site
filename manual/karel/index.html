Karel the Robot

Esta página documenta a referência Java de Karel mantida pela Stanford. Karel aparece em várias implementações educacionais; os nomes de comandos e as regras podem variar entre elas. Os exemplos abaixo usam a sintaxe e os recursos descritos pelo material Java da Stanford.

01 · Visão geral

Sobre Karel

Karel é um robô que recebe instruções para resolver tarefas simples em um mundo de ruas, esquinas e paredes. O modelo foi criado para que os primeiros exercícios de programação enfatizem a decomposição de problemas e a sequência de comandos.

Esta página escolhe a referência Java da Stanford, que define uma classe de programa e um método run. Outras implementações podem usar Python ou sintaxes próprias; não misture exemplos de versões diferentes.

02 · Ambiente

O mundo em grade

O robô ocupa uma esquina, aponta para uma das quatro direções e pode carregar ou deixar beepers. Paredes bloqueiam movimentos entre esquinas. Uma tarefa descreve o estado inicial do mundo e o estado que o programa deve alcançar.

  • Posição: a esquina atual do robô na grade.
  • Direção: norte, sul, leste ou oeste.
  • Beepers: marcadores que o robô pode recolher e colocar.
  • Paredes: obstáculos que impedem o movimento.

Uma tentativa de atravessar uma parede, recolher um beeper inexistente ou colocar um beeper sem tê-lo na bolsa causa uma condição de erro no ambiente.

03 · Organização

Estrutura do programa

Um programa Java de Karel declara uma classe que estende SuperKarel. O método público run() contém as instruções iniciais; métodos privados podem ser declarados dentro da classe para nomear sequências reutilizadas.

import stanford.karel.*;

public class ExemploKarel extends SuperKarel {
    public void run() {
        move();
        turnLeft();
    }
}

O código usa blocos entre chaves, ponto e vírgula ao fim das instruções e comentários Java com // ou entre /* e */.

04 · Ações

Comandos básicos

ComandoAção
move()Avança uma esquina se não houver parede à frente.
turnLeft()Gira 90 graus para a esquerda.
putBeeper()Deixa um beeper na esquina atual.
pickBeeper()Recolhe um beeper da esquina atual.
turnRight()Gira 90 graus para a direita; fornecido por SuperKarel.
turnAround()Gira 180 graus; fornecido por SuperKarel.

Os comandos primitivos são chamados com parênteses vazios e ponto e vírgula. As ações de beeper dependem do conteúdo da esquina e da bolsa do robô.

05 · Observação

Sensores e condições

Karel não recebe o mapa inteiro como um valor. Ele consulta condições locais para decidir o que fazer.

CondiçãoÉ verdadeira quando
frontIsClear()Não há parede imediatamente à frente.
leftIsClear(), rightIsClear()O caminho indicado está livre.
beepersPresent()Há pelo menos um beeper na esquina atual.
noBeepersPresent()Não há beeper na esquina atual.
facingNorth(), facingEast(), facingSouth(), facingWest()O robô aponta para a direção indicada.

As condições aparecem entre parênteses em expressões Java e podem ser combinadas com operadores booleanos do Java.

06 · Fluxo

Decisões e repetições

A referência Java usa as estruturas if, if/else, while e for. Elas permitem reagir às condições do mundo e repetir uma sequência de ações.

if (frontIsClear()) {
    move();
} else {
    turnLeft();
}

while (beepersPresent()) {
    pickBeeper();
}

for (int i = 0; i < 3; i++) {
    move();
}

Um laço baseado em sensor precisa modificar o mundo ou a posição do robô para alcançar uma condição de parada. Confira as paredes e os beepers do cenário antes de executar a sequência.

07 · Reuso

Métodos próprios

Um método privado dá nome a uma ação composta. Depois de declarado na classe, ele pode ser chamado por run() ou por outros métodos da mesma classe.

private void turnRightSafely() {
    turnLeft();
    turnLeft();
    turnLeft();
}

public void run() {
    move();
    turnRightSafely();
    move();
}

O método acima usa apenas três giros à esquerda, o comando primitivo listado na base de Karel. Quando SuperKarel está disponível, turnRight() expressa a mesma intenção diretamente.

08 · Estado

Estado e dados

O problema pode ser resolvido apenas com posição, direção, paredes e beepers, mas a referência Java também oferece construções comuns do Java, como variáveis locais e contadores em laços. O robô mantém o estado físico do mundo; variáveis do programa ajudam a registrar etapas ou quantidades.

int passos = 0;
while (frontIsClear()) {
    move();
    passos++;
}
putBeeper();

Use estado adicional somente quando ele ajudar a descrever a solução. Para exercícios iniciais, muitas tarefas podem ser resolvidas com sensores e métodos bem nomeados.

09 · Exemplo integrado

Avançar e marcar a esquina

O programa avança até encontrar uma parede e deixa um beeper na posição final, caso ainda não exista um:

import stanford.karel.*;

public class MarcarDestino extends SuperKarel {
    public void run() {
        while (frontIsClear()) {
            move();
        }
        if (noBeepersPresent()) {
            putBeeper();
        }
    }
}
