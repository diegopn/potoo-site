01 · A proposta

Um começo mais claro para a lógica

O Potoo IDE já permite experimentar algoritmos com pseudolinguagens da família Portugol e com a linguagem de programação Potigol. O projeto quer tornar esse processo mais claro para estudantes e professores, reunindo escrita e resultados numa interface desktop.

Para quemEstudantes e professores

Um espaço de apoio para aprender e ensinar os fundamentos da programação.

FocoLógica antes da sintaxe

Pseudolinguagens ajudam a concentrar a atenção nos passos do algoritmo.

FormatoAplicativo desktop

Uma IDE nativa planejada para Linux, Windows e macOS.

02 · Recursos atuais e próximos passos

Uma base funcional que continua crescendo

Mesmo no início do desenvolvimento, o Potoo IDE já oferece editor e execução para Portugol Studio 2.0, VisuAlg, G-Portugol e Potigol. A experiência de aprendizagem continua evoluindo.

O Potoo IDE reúne linguagens e pseudolinguagens em um ambiente de aprendizagem.

Portugol

Portugol é uma família de pseudolinguagens didáticas que expressa algoritmos em português. Não há uma sintaxe única: cada variante define suas próprias regras e recursos.

Portugol Studio 2.0VisuAlgG-Portugol
PO

Potigol

Potigol é uma linguagem de programação educacional com sintaxe portuguesa, tipagem estática e inferência. Combina os paradigmas imperativo, funcional e orientado a objetos.
